# UVのないSDFメッシュへの材質適用

このフォルダをルートとして開き、`triplanar.rockscene` を読み込む。

1. `Surface` の `Result` が `Mesh Output` の `Material` に接続されている。
2. Surfaceの「マッピング → 方式」はTriplanar。反復サイズ・位置・回転・混合の鋭さを変更できる。
3. 生成形状を変更してもUV展開をせずに同じ投影を使える。ワールド座標基準なので、形状の移動・回転で模様との位置関係は変わる。

同梱画像はこのサンプル用に数式で生成した検証素材。岩らしい外観の完成例ではない。市松模様と赤・緑の線で方向・混合を、波形の法線マップで陰影を確認する。`surface.png` はRがラフネス、BがAO。

このサンプルのままUVへ切り替えると仮UVが使われ、三角形ごとの模様になる。後段にUV展開・ベイクを追加した例は [UVベイクのサンプル](../uv-bake/README.md)。詳細は [Triplanarの仕様](../../docs/reference/triplanar.md)。
