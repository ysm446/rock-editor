# 薄板を割って積層するサンプル

まずアプリのアセットルートをこのフォルダに設定し、`layered-2d.rockscene` を開きます。

| シーン | 比較する内容 |
| --- | --- |
| `single-plate.rockscene` | 1枚の薄いBoxを既存のメッシュ入力で分割し、側面に接する片を削除 |
| `progressive-peel.rockscene` | 側面と上下の重なり面積から支持を求め、全層で1片ずつ欠く |
| `outer-layer-chipping.rockscene` | 両側から2層を対象とし、内側の層ほど欠けを弱くする |
| `layered-2d.rockscene` | 5枚の板を面内の点で個別に分割し、各板の元の側縁を削除 |
| `layered-3d.rockscene` | 同じ5枚の板で点を厚さ方向にも配置する比較 |

いずれもボリュームを使わず、Pieces to Mesh から Mesh Output へ接続しています。

1. Layered Boxes で厚さ・隙間・ばらつき・ずれを調整します。
2. Scatter Points の点数を変えると欠けの細かさが変わります。点数は板1枚あたりで、合計1024点まで（板1枚あたり512点まで）です。
3. Piece Select の Rim の割合を下げると側縁の一部が残ります。層番号を指定すると、その板だけが欠けます（-1は全層）。
4. Piece Filter の「除外した片」を表示すると、取り除いた部分を確認できます。

Rim は元の板の側縁を選びます。削除後の輪郭から連続的に削っていく機能は含みません。詳しくは [設計メモ](../../docs/reference/layered-pieces.md) を参照してください。

`outer-layer-chipping.rockscene` では Piece Select を選ぶと、外側の層ほどオレンジの選択が多くなる様子を確認できます。「削除後」で比較し、「板を離して表示」で隠れた層も確認してください。層ごとの内訳は設定欄を下へスクロールすると表示されます。これらの表示操作は出力形状を変更しません。

`progressive-peel.rockscene` の Piece Select / Peel は、最上部の「欠けの進行」を増やすと上下の支持を考慮しながら、全層の外周から1片ずつ欠けます。両面を覆われた中間層は外側の支持が欠けるまで残ります。オレンジの線は欠ける片、黄色は削除後に露出している次の候補です。中心保護は各連結部分の奥の1片を残します。詳しくは [隣接面積による侵食](../../docs/reference/piece-erosion.md) を参照してください。

進行を0%へ戻すと最初の形になります。Seed・中心保護・対象層は「詳細設定」にまとめています。「別の欠け方を試す」は進行を保ったままSeedを切り替えます。ばらつきが0だとSeedで結果が変わらないため、別の欠け方を試すにはばらつきを上げてください。
