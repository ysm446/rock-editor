# 平面で切り落とすサンプル

アプリでこのフォルダをルートとして開き、`plane-cuts.rockscene` を開く。

- Random Boxes → To Volume（解像度80）：6個の直方体を重ねた塊。
- Plane Cuts（1段目）：適用範囲は「全体」。主方向3系統の平面5枚で、塊の外側を大きく面取りする。
- Plane Cuts（2段目）：適用範囲は「局所」。256枚を指定し、稜線と角を平面の小面で欠く。丸い壁が残る欠けは自動で除かれるので、実際に使われる枚数はこれより少ない。
- Volume to Mesh（Dual Contouring）→ Mesh Output：稜線を残して表示する。

各ノードの出力ピンをクリックすると、その段までの形を見られる。To Volume と見比べると、切り落とす前の塊が分かる。
1段目の枚数を増やすと、塊の凹みが消えて凸な形へ近づく。2段目は Seed・半径・深さで欠け方が変わる。
`Skies/preview.rocksky` はこのサンプルの照明用アセット。詳しくは [仕様](../../docs/reference/plane-cuts.md) を参照。
