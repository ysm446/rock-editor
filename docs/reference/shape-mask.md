# Shape Mask

作成日時: 2026-09-22 06:25
更新日時: 2026-09-22 12:50

[設計メモ](rock-shaping-nodes.md) の 6（形状からマスクを作る）のノード。UV付きのメッシュから、そのUVに対応するマスク画像を作る。何から作るかは「種類」で選ぶ。溝に錆、上面に埃、接地側に汚れ、といった色の層を Apply Material で重ねるのに使う。

## 接続

```text
… → Decimate → UV Unwrap ─┬→ Apply Material（下地）→ Apply Material（錆）→ … → Mesh Output
                          │        ↑                      ↑      ↑
                          │     Surface               Surface   Mask
                          └→ Shape Mask（種類: オクルージョン）──┘
```

- 入力は Mesh（UV付き。UV Unwrap の出力）、出力は Mask。Apply Material の Mask へつなぐ。白で今回の素材、黒で上流の素材。
- マスクは入力メッシュのUVに対応する画像。Apply Material の Mesh には、**同じ UV Unwrap の出力（またはその下流の Subdivide / Displace）**をつなぐ。UVの無いメッシュや、アトラスの寸法が違うメッシュへつなぐと診断する。
- Shape Mask を使う素材を適用した後で UV Unwrap をやり直すと、UVが変わって画像と合わなくなるので診断する。
- マスクを作る形と、素材を貼る形を分けられる。例えば、Displace で変位する前のメッシュからオクルージョンを作り、変位した後のメッシュへ貼れる（UVは同じ）。

## 選択時の表示

Shape Mask を選ぶと、入力メッシュにマスクを白黒のテクスチャとして貼った状態でプレビューする（UV Unwrap を選ぶとチェッカーが出るのと同じ仕組み）。選択を外すと元のプレビューへ戻る。反転も反映する。黒の全面の上にマスクで白を重ねる2段の素材として、既存の合成の経路で描いている。

## 設定

| 設定 | 内容 |
| --- | --- |
| 種類 | オクルージョン / 上向き度 / 高さ |
| マスク解像度 | 128〜4096（2のべき乗）、既定 1024。UV Unwrap の解像度とは独立 |
| 距離 (m) | オクルージョンのみ。遮蔽物を探す距離。0.001〜1000、既定 0.3。小さいと細い溝だけ、大きいと広いくぼみまで白くなる |
| サンプル数 | オクルージョンのみ。画素ごとのレイの数。8〜128、既定 32 |
| 下限 / 上限 | 元の値（0〜1）のうち、下限以下を 0、上限以上を 1 へ伸ばす。既定 0.2 / 0.8 |
| 反転 | `1 - mask` にする。画像は作り直さず、使う側（描画・ベイク・Displace・選択時の表示）で掛ける |

種類ごとの元の値:

- 向きは、共有頂点で面積重み付き平均した**頂点法線を画素ごとに補間**したもの。面の法線のままだと隣の面との辺で値が段になり、三角形の形がマスクに出る（2026-09-22 に修正）。
- **オクルージョン**: 画素の表面の点から、補間した向きを中心とするコサイン重みの半球へレイを飛ばし、距離以内で同じメッシュに当たった割合。面の平面より下へ向くレイは隣の面に当たるだけなので数えない（分母からも除く）。白は溝・割れ目・入隅。BVH とレイの並びは Material Bake の形状AO（CPU 参照実装）と同じ。
- **上向き度**: `(向き・+Y + 1) / 2`。上を向いた面が 1、垂直な面が 0.5、下を向いた面が 0。下限 0.8・上限 0.95 あたりで「上面だけ」になる。
- **高さ**: 形の外接箱の中での Y の位置。最上部が 1、最下部が 0。反転すると接地側。

## 計算と受け渡し

- `geometry::ShapeMask`（`src/geometry/ShapeMask.h`、実装は `BakeOcclusion.cpp`）。画素の中心がどの面のどこに当たるかを直列で決め（結果を再現させるため）、値の計算を行ごとに並列で行う。キャンセルと進捗に対応。
- UVの島が無い画素は、縦横の歩数で最も近い島の値で全面を埋める。線形補間やミップマップで島の縁がにじまない。
- 評価結果は `geometry::MaskImage`（1チャンネル 8bit）。マスクのノードを評価した結果は入力メッシュに `previewMask` を付けたもので、Apply Material がその画像を `GeneratedRock::maskImages`（マスクのノード → 画像）へ移して下流へ運ぶ。全面置換（Mask 未接続の Apply Material、Mesh Output / Material Bake の Material 入力）で外れる。
- キャッシュはボリューム系と同じ内容キー。Shape Mask のキーは設定（反転を除く）と入力の枝。Apply Material より下流のキャッシュ（Subdivide / Displace / Decimate）のキーにも、つないだ Shape Mask のキーを含める。Displace のキーには反転も含める。
- 描画とベイク: アプリが画像を一時テクスチャにし（`Application::ShapeMaskTextureFor`。画像ごとに1枚、使われなくなったら捨てる。シーンには保存しない）、既存の「画像マスク・UV・反復 1」として渡す。シェーダの変更は無い。
- Displace: 画像を頂点のコーナーUVで線形補間して読み、ハイトの混合の重みに使う。
- ベイクの指紋には画像の画素を含める。形・設定が変わると再ベイク待ちになる。
- Shape Mask を含むグラフは別スレッドで評価する。計算中は Shape Mask のノードに「計算中」が出て、設定欄に進捗バーが出る。

実測（Release）: `examples/shape-mask/`（15万三角形、1024²、オクルージョン32サンプルと上向き度）で、読み込みから表示まで全体で約26秒。大半は UV Unwrap。

## 制限

- UVが必要。UV Unwrap は三角形が多いと遅いので、先に Decimate で減らす。細かさはマスク解像度とUVの密度で決まる。
- オクルージョンの遮蔽物は入力メッシュだけ。Merge した別のメッシュ、モデル、地面は含まない。素材の Normal / Height も数えない。入力は1つのメッシュ（複数ピースは先に UV Unwrap で1つにまとまる）。
- オクルージョンは CPU で計算する。4096² や 128 サンプルは時間がかかる。Material Bake の GPU 形状AOは使っていない（評価は別スレッドで走り、GPU へ触れないため）。
- 曲率（凸稜）・切断面（`Piece::faceOrigins`）の種類、マスクどうしの合成（乗算・加算）ノードは無い。複数の条件を重ねるには Apply Material を重ねる。
- マスク画像の書き出しは無い。

## サンプル

[shape-mask.rockscene](../../examples/shape-mask/shape-mask.rockscene) を同じフォルダをルートとして開く。`examples/volume-noise/` の形を Decimate → UV Unwrap し、灰色の下地、オクルージョンで割れ目に載せた錆色、上向き度で上面に載せた明るい埃色を重ねている。素材は働きを見分けるための定数色で、完成した岩素材ではない。
