## 参考

ユーザー提示の [DSC02801.JPG](../references/DSC02801.JPG) を外観の参考とする。写真そのものの形を自動復元する機能ではなく、観察できる特徴を生成機能へ分解する。周囲の白い部分・背景は岩アセットの対象外。岩種や成因は写真だけから断定しない。

`docs/references/` は既存の `.gitignore` で管理対象外。写真はローカルの参考資料として保持し、この文書を Git 管理する。

## 見た目と必要な処理

| 写真で観察できる特徴 | 生成側の対応 | 段階と不足 |
| --- | --- | --- |
| 非対称の大きな頂部、角張った稜線 | 母岩形状、複数の方向性を持つ分割、片の配置 | P4 は2片の分割と配置、P5 前半は4形状と弱いノイズ。複数節理による多片分割と個別配置を追加。写真との形状比較は引き続き必要 |
| 深い主亀裂、広い平らな割れ面 | 有限亀裂・未破断部・完全分割、面の低周波変形 | P3/P4 は平面。面のうねりは追加検討 |
| 細かい亀裂、分岐・交差、幅の不均一 | 局所亀裂、複数スケールの破砕、幅・深さの変調 | 現 MVP の単純な節理だけでは不足。拡張課題 |
| 縁の欠け、薄く剥がれたような片 | Chip と局所破砕、薄片の厚みと閉包 | Chip は P7。薄片の剥離は別途検証 |
| 灰色を基調にした茶色の色むら、ざらつき | Triplanar、BaseColor / Roughness / Normal / Height / AO | P7。形状に沿うマスクと材質調整が必要 |

## 比較する順序

1. 無地でシルエットと主亀裂の方向・大きさを比較する。表面ノイズで形状の不足を隠さない。
2. 中距離で未破断部、分離片、欠け、亀裂の幅と深さを比較する。
3. 接写で細かな亀裂、ざらつき、灰色/茶色の分布を比較する。
4. 照明や視点を変えても、主要な割れ目と輪郭が立体として成立するか確認する。

この写真に近い方向の岩は目標にできるが、現行の Box 切断だけでは達成しない。MVP の機能完了と、写真に近い外観への到達は別に検証する。細かな分岐亀裂・剥離・材質の調整範囲は、P5/P7 の比較結果を見て具体化する。
