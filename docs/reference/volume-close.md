# Volume Close

作成日時: 2026-09-22 19:50
更新日時: 2026-09-22 19:50

## 位置付け

Volume の幅より狭い隙間（割れ目の奥、細い切れ込み）を埋めるノード。モルフォロジーのクロージング（膨らませてから同じだけ縮める）。Volume Crack の V 字の割れ目は指定の深さまで彫られるので、表面から見えない奥の壁まで格子に残り、Volume to Mesh がそこまで三角形を作ってしまう。このノードを後ろに置くと、幅がこの値を下回る深さから下だけが埋まり、入口の V は残る。2026-09-22 のユーザー依頼「割れた溝の内側を埋めるようなノード」への対応。サンプルは `examples/volume-close/`。

```text
… → Volume Crack → Plane Cuts（局所）→ Volume Noise → Volume Close → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。

## 設定

| 項目 | 内容 |
| --- | --- |
| 幅 | これより狭い隙間を埋める。形の最長辺に対する比。0.005〜0.3、既定 0.05 |

保存名は `volumeClose`。保存・読込と Undo / Redo に対応。

## 処理

半径 r = 幅 × 最長辺 ÷ 2（セル単位）。r が1セル未満なら何もしない。

1. **膨らませる**: 表面から r 以上離れた外部（`d ≥ r`）を「遠い外部」とし、各格子点からそこまでのユークリッド距離を距離変換（Felzenszwalb & Huttenlocher の分離アルゴリズム、軸ごとに並列）で求める。格子の余白は2セルしかないので、格子の中だけでは遠い外部が見つからないことがある。外周の6方向について「外周までのセル数 + 外周の値から r までの不足分」も候補にする（格子の外は外周の値に外へ出た距離を足したものとみなす。`SampleVolume` と同じ規約）。
2. **縮める**: 遠い外部から r + 0.5 セル以上離れた点を内部にする。元から内部の点は必ず残す。半セルの余裕は、表面の点をちょうど r の位置で拾って表面が半セル外へ出るのを防ぐため。
3. **閉じ込められた空洞**: 入口を埋めた結果、外周から届かなくなった外部（入口が狭く奥が広い穴）も内部にする。
4. **値**: 元から内部の点は入力のまま。新しく埋めた点は「外部までの距離 − 半セル」を負にしたもの。外部の点は、入力の値と「埋めた点までの距離 − 半セル」の小さいほう（元の表面までの距離は入力のほうが正確なので、埋めた点だけを見る）。埋めた所の表面はセルの中間に置かれる。

距離変換は3回（遠い外部まで、外部まで、埋めた点まで）。各軸256点の格子でも1秒未満。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Volume 出力を接続してください |
| 幅が範囲外、または非有限 | 幅は 0.005〜0.3 にしてください |

## 制限

- **幅がセル間隔の2倍未満だと何も埋まらない**（半径が1セル未満）。
- 埋めた所の距離は格子の精度になる。埋めた面は元の面より少しなまる。
- 表面の半セルぶんは埋まらない。幅を割れ目の入口より大きくしても、入口に半セル以下の浅いくぼみが残ることがある。
- 凹んだ隅（入隅）も幅より狭ければ埋まる。割れ目だけを狙うなら、割れ目の入口の幅より少し小さい値にする。
- 内部を減らすことはない（クロージングの性質）。細い突起を消すのは別の操作（オープニング）で、このノードには無い。
