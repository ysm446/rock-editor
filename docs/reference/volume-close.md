# Volume Close

作成日時: 2026-09-22 19:50
更新日時: 2026-09-22 21:00

## 位置付け

Volume の、外から見えない隙間（割れ目の奥、狭い入口の奥、細い切れ込み）を埋めるノード。Volume Crack の V 字の割れ目は指定の深さまで彫られるので、表面から見えない奥の壁まで格子に残り、Volume to Mesh がそこまで三角形を作ってしまう。このノードを後ろに置くと、見えない部分だけが埋まる。2026-09-22 のユーザー依頼「割れた溝の内側を埋めるようなノード」への対応。サンプルは `examples/volume-close/`。

判定は2つのモードから選ぶ。既定は「遮蔽」。

- **遮蔽**: 表面近くの外部の点から全方向へレイを飛ばし、距離以内に形へ当たった割合（遮蔽率）がしきい値以上の点を埋める。平らな面の近くは半分しか遮られないので残り、浅いくぼみや切れ込みも半分以上が空に開いているので残る。割れ目の奥や壁の陰、狭い入口の奥だけが埋まる。幅にも深さにも直接は依らない。
- **幅**: モルフォロジーのクロージング（膨らませてから同じだけ縮める）。幅より狭い隙間を埋める。浅い切れ込みや表面の細かいくぼみも、幅が狭ければ埋まる（ユーザー指摘「幅だと表面も閉じてしまう」）。割れ目の入口を残したまま奥だけ埋めるには、割れ目の入口の幅より少し小さい値にする。

```text
… → Volume Crack → Plane Cuts（局所）→ Volume Noise → Volume Close → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。

## 設定

| 項目 | 内容 |
| --- | --- |
| モード | 遮蔽 / 幅。既定は遮蔽。保存名 `occlusion` / `width` |
| 距離 | 遮蔽のみ。レイを追う長さ。形の最長辺に対する比。0.01〜1、既定 0.2 |
| しきい値 | 遮蔽のみ。遮蔽率がこれ以上の点を埋める。0.5〜1、既定 0.75 |
| サンプル数 | 遮蔽のみ。点ごとのレイの数。8〜128、既定 32 |
| なだらかさ | 遮蔽のみ。しきい値のまわりの移り変わり（遮蔽率の幅）。0.02〜0.5、既定 0.1。小さいほど境が鋭い |
| 幅 | 幅のみ。これより狭い隙間を埋める。形の最長辺に対する比。0.005〜0.3、既定 0.05 |

保存名は `volumeClose`。保存・読込と Undo / Redo に対応。

## 処理（遮蔽）

格子点ごとに独立で、`FillSlices` の並列化に乗る。

1. 内部の点（`d < 0`）は入力のまま。距離 L 以上離れた外部の点は、レイが届く範囲に形が無いので遮られず、入力のまま。
2. それ以外の外部の点から、球面に均等に散らした向き（フィボナッチ格子、サンプル数ぶん）へレイを飛ばす。レイはスフィアトレーシング（その位置の距離値のぶんだけ進める。最小で半セル）で、値が負になれば当たり、L を超えれば抜けたとする。格子の外は `SampleVolume` の規約で正の値なので当たらない。
3. 遮蔽率 = 当たった割合。`閉じた値 = (しきい値 − 遮蔽率) ÷ なだらかさ × セル間隔` を求め、入力の値との小さいほうを出力にする。遮蔽率がしきい値を超えると負（内部）になる。平らな面の近く（遮蔽率 0.5 前後）では既定で 2.5 セルより大きな正の値になり、面のそばの入力の値（1〜2セル）を下回らないので、表面は動かない。
4. 入口を埋めて外周から届かなくなった外部（入口が狭く奥が広い穴）も内部にする（幅モードと共通）。

計算量は「表面から L 以内の外部の点 × サンプル数 × ステップ数」。解像度96・32本で1秒以内、128 で数秒。

目安: くぼみの底の遮蔽率は、幅 w・深さ h のくぼみで概ね `1 − (1 − cos θ) / 2`、θ = atan(w / 2h)。深さが幅の 0.35 倍を超えると 0.75 に達して埋まる。浅く広いくぼみは残り、深い割れ目は奥から埋まる。

## 処理（幅）

半径 r = 幅 × 最長辺 ÷ 2（セル単位）。r が1セル未満なら何もしない。

1. **膨らませる**: 表面から r 以上離れた外部（`d ≥ r`）を「遠い外部」とし、各格子点からそこまでのユークリッド距離を距離変換（Felzenszwalb & Huttenlocher の分離アルゴリズム、軸ごとに並列）で求める。格子点は等値面 `d = r` より外にあるので、最も近い格子点の値の超過分 (d − r) を引いて等値面までの連続な距離に直す（距離変換は最も近い点の添字も返す）。格子の余白は2セルしかないので、外周の6方向について「外周までのセル数 + 外周の値から r までの不足分」も候補にする（格子の外は外周の値に外へ出た距離を足したものとみなす。`SampleVolume` と同じ規約）。
2. **縮める**: 閉じた形の符号付き距離は「r − 遠い外部までの距離」。平らな面ではこれが入力の値と一致する。元から内部の点は入力のまま、外部の点は入力とこの値の小さいほう（埋める所だけ負になる）。
3. 閉じ込められた空洞を埋める（遮蔽と共通）。

初版は埋めた点の値を「外部までの格子距離 − 半セル」で作っていたが、埋めた面の等値面がセルの中間に揃い、表面が格子状に角張った。2 の連続な距離に直して解消した。

| 状況 | 表示 |
| --- | --- |

| モードが不明 | 不明なモードです |
| 幅・距離・しきい値・サンプル数・なだらかさが範囲外、または非有限 | それぞれの範囲を示す |

## 制限

- 内部を減らすことはない。細い突起を消すのは別の操作（オープニング）で、このノードには無い。
- 遮蔽: 深さが幅の 0.35 倍を超えるくぼみは底から埋まる（しきい値 0.75 のとき）。表面の細かいくぼみを全て残したい場合は、しきい値を上げる。レイは格子の値で進めるので、セル間隔より細い隙間は当たりとして数えられないことがある。
- 幅: 幅がセル間隔の2倍未満だと何も埋まらない（半径が1セル未満）。表面の半セルぶんは埋まらない。凹んだ隅（入隅）も幅より狭ければ埋まる。
- 埋めた所の距離は近似になる。
