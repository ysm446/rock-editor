# Flow Mask — 表面を流れ下る水の筋のマスク

作成日時: 2026-10-02 23:30
更新日時: 2026-10-02 23:30

## 位置付け

表面を重力で流れ下る水の筋（流れの量）を、UV 付き Mesh のマスクとして作るノード。鉄錆・汚れの流れた筋、濡れ跡、流れ下る土。[岩の種類の網羅](rock-catalog.md) の G5（流れ）と G6（素材）。2026-10-02 追加。

[Volume Erode](volume-erode.md) の流下と同じ筋の追跡（`FlowAccumulation`）を使い、形を削る代わりにマスクへ出す。

```text
… → Volume Clip（接地）─┬→ Volume to Mesh → Decimate → UV Unwrap ─┬→ Apply Material（下地）→ Apply Material（錆）→ Mesh Output
                        │                                          └→ Flow Mask ─(→ Mask Combine × Noise Mask)──↗ Mask
                        └──────────────────────────────────────────→ Flow Mask の Volume
```

右クリックメニューの「マスク」にある。入力は UV 付きの Mesh と、筋を追う格子の Volume（任意）。出力は Mask。選ぶと入力のメッシュにマスクを白黒で貼って見せる（他の画像マスクと同じ）。保存名は `flowMask`。

## 設定

| 項目 | 保存名 | 内容 |
| --- | --- | --- |
| 筋の長さ | `length` | 1 つの出発点から流れを追う長さ。形の最長辺に対する比。0.05〜1、既定 0.5。長いほど下まで筋が伸びる |
| 筋の幅 | `width` | 流れの量をぼかす幅（σ）。最長辺に対する比。0.005〜0.1、既定 0.015 |
| 集中 | `sharpness` | 最も流れが集まる筋を 1 として流れの量の集中乗。1〜8、既定 2。大きいほど太い筋だけ白 |
| 格子の解像度 | `volumeResolution` | Volume 入力が無いときにメッシュを格子にする解像度（最長辺のセル数）。16〜128、既定 96。Volume を繋いだときは使わない |
| マスク解像度 | `resolution` | 128〜4096 の 2 のべき乗、既定 1024 |
| 反転 | `invert` | 使う側で掛ける（他の画像マスクと同じ） |

## 処理

1. 筋を追う格子を決める。Volume 入力があればそれ（Volume to Mesh の前の Volume。メッシュと同じ位置にそろえる。Volume Clip の接地で動かすなら、動かした後から取る）。無ければメッシュを `MeshToVolume` で格子にする。UV 展開や Decimate を経たメッシュは頂点が分かれていて変換できないことがあるので、その場合は Volume を繋ぐよう診断する。
2. 格子の表面に近い格子点を出発点に、重力の面に沿う成分の向きへ筋を追い、通った格子点に流れの量を積む（Volume Erode の流下と同じ。ほぼ水平な面、張り出しの下面、形の底で終える）。筋の幅でぼかす。
3. 表面の格子点の流れの量の上位 5% を 1 とし、画素ごとに表面の位置で三線形補間して読み、`集中` 乗を白黒にする。ラスタライズ・島の余白埋めは Shape Mask と共通。

## 使い方

- 鉄錆の筋: 灰色の下地の上に錆色の Surface を Apply Material し、Mask に Flow Mask。Noise Mask と Mask Combine（乗算、low 0.05・high 0.6）を掛けると筋が途切れてまだらになる（`rust-streaks`）。
- 流れの量は面の上端で 0、下へ行くほど大きい。上端から筋を出したいときは Mask Filter のレベルで low を下げる。
- 上は入力の +Y。
