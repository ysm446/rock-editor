# Volume Clip

作成日時: 2026-09-26 23:53
更新日時: 2026-09-26 23:53

## 位置付け

Volume を水平な平面で切り、片側を捨てるノード。2026-09-26 のユーザー依頼「原点から下をカットするノード」への対応。既定は高さ 0（原点）で、平面より下を捨てる。地面に据える平らな底面を作る用途を想定する。

```text
… → To Volume → （Volume 系の加工） → Volume Clip → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。格子（範囲・セル間隔）は入力のまま変わらない。

## 設定

| 項目 | 内容 |
| --- | --- |
| 高さ (m) | 切る水平な平面の高さ（ワールドの Y）。スライダーは -10〜10、値は -100000〜100000、既定 0 |
| 反転 | オフで平面より下を、オンで平面より上を捨てる。既定オフ |

保存名は `volumeClip`（`height`、`invert`）。保存・読込と Undo / Redo に対応。設定と上流が同じなら、ボリューム枝のキャッシュから再利用する。

## 処理

各格子点の値を、半空間との交差 `max(d, h − y)`（反転時は `max(d, y − h)`）に置き換える。切り口は平らな面になり、角は丸めない。値が 0 に近い点は Plane Cuts と同じく小さな正の値に寄せ、格子頂点上の等値面でゼロ長の辺ができないようにする。

- 切り離された塊は除かずに残す（Plane Cuts と違い、切る位置をユーザーが指定するため）。
- 内部が1点も残らない場合は診断を出す。
- 切り口の近くの距離は、元の距離と平面までの距離の最大値なので近似になる。後段の Volume Smooth などは通常どおり使える。

## 検証

`tests/VolumeClipTests.cpp`。原点を中心とする 2 m の立方体で次を確かめる。

- 既定の設定で下半分が消え、閉じた1つの塊になる（Marching Tetrahedra / Dual Contouring）。
- 体積がほぼ半分になり、上面と横の広がりは変わらない。
- 高さを上げると切り口も上がる。反転すると上が消える。
- 形より下で切ると何も変わらない。
- 不正な値、空の入力、内部が残らない切り方を診断する。
- グラフでの接続、キャッシュ、設定変更での作り直し。
