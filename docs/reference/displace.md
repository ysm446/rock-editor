# Subdivide / Displace

作成日時: 2026-09-22 04:54
更新日時: 2026-09-22 14:05

## 接続

Triplanar素材では次の順に接続する。

```text
Base Shape / Volume to Mesh → Apply Material → Subdivide → Displace
                                                        → UV Unwrap → Material Bake → Mesh Output
```

UV素材では `UV Unwrap → Apply Material → Subdivide → Displace → Material Bake` の順。UV展開は変位前に済ませ、細分化・変位で引き継ぐ。変位後にUVを作り直すとUV素材の位置も変わるため、元の投影を保ちたい場合は再展開しない。

## Subdivide

Mesh入力・Mesh出力。三角形の各辺に中点を作り4分割する。共有辺には同じ頂点を使い、元の面の形は変えない（スムージングやCatmull–Clarkではない）。UVは面コーナーごとに補間して島の境界・アトラス寸法・チャートを保つ。

- 段階数: 0〜6、既定1。0はそのまま。
- 面数: 1段ごとに4倍。UIに倍率と、前回の入力面数から計算した予測値を表示する。
- 上限: ノードの出力合計で100万三角形。増加後の数を検査してから確保する。上限超過はエラーとし、勝手に段階数を下げない。

## Displace

Mesh入力・Mesh出力。入力に引き継がれたApply Materialの素材を使う。Material BakeのMaterial入力で明示されたSurfaceも引き継げる。適用素材がない場合は案内を出す。

`変位距離 = (合成ハイト - 基準ハイト) × 変位量`

- 変位量: −10〜10m、既定0.05m。負なら凹凸を反転し、0なら形状を変えない。
- 基準ハイト: 0〜1、既定0.5。
- 出力合計で100万三角形まで。Displace自体は面数を増やさない。

素材のハイトは既存のGPU合成器で生成する。画像の選択チャンネル・EXR・SurfaceのノイズやUVスケールを同じ経路で評価し、R32_FLOATでCPUへ読み戻す。素材に割り当てた画像があるSurfaceはプレビューと同じく画像ハイトを使う。評価解像度は1024を基準にハイト画像の最大寸法まで引き上げ、4096を上限とする。

Triplanarの回転・オフセット・反復幅・混合の鋭さ、UV投影、素材のHeightチャンネルの有効/無効を反映する。Apply Materialの順にハイトを合成し、Material Maskの定数・リニアR画像・UV/Triplanar・反転を反映する。ハイトがリンク切れならエラーとし、別の値で置き換えない。

頂点の変位はCPUワーカーで実行し、計算中のノード・進捗表示と既存の取消処理を使う。GPUでの素材準備はフレーム外の同期処理で、材質と接続の変更時に更新する。実際のメッシュが変わるため、下流のUV展開・To Volume・AOベイクも変位後の形状を受け取る。

## 境界と制限

- 変位方向は入力メッシュの共有頂点の角度重み付き法線。表示のスムーズシェーディング設定には依存しない。
- UV島ごとの値が違う共有頂点では、ハイトをコーナー角で重み付けして平均する。共有頂点を一度だけ動かすので境界が割れない。ただし不連続なUV柄では境界付近の値が平均される。
- 位置が同じでも頂点IDが別の部分は溶接しない。離れたピースを自動で一体化する機能ではない。
- 面の退化や非有限値は拒否する。自己交差の検出・修復は含まないので、大きすぎる変位では変位量を下げる。
- 細分化が足りなければ高周波のハイトを表現できない。小さな凹凸はNormalと使い分ける。
- モデルアセットのModel型には対応しない。生成メッシュを入力する。
- 下流の上限は別に適用される。現在のUV Unwrapは50万面、一般メッシュのTo Volumeは25万面まで。
- ベイクの一時結果を無効化し、直方体の高速ボリューム変換用の情報も外す。保存・再読込・Undo/Redoはノード設定と接続を保持する。

## キャッシュ

DisplaceとDecimateは上流の形状・接続・設定が同じなら直近の結果を再利用する。Displaceでは合成ハイト、投影、チャンネル、マスクも照合する。素材ハイトのGPU生成とCPU読戻しは参照入力の変更時に行い、下流だけの編集では省略する。同じIDの画像を再読込した場合も更新する。キャッシュ照合と結果の受け渡しの処理は残る。

## Subdivide の Mask 入力（2026-09-22）

- Mask 入力に Shape Mask か Material Mask をつなぐと、面の中心のマスク値が「マスクのしきい値」（既定 0.5）以上の面だけを割る。未接続なら全面。
- 選んだ面は各段で4分割する。隣の面は共有辺の分割に合わせて、1辺なら2分割、2辺なら3分割（短い方の対角線で割る）、3辺なら4分割し、T字の接続を作らない（red-green 分割）。選ばれなかった面から生まれた面は、次の段でも割らない。
- Shape Mask は UV の画像なので、UV Unwrap の後に置き、同じアトラスのメッシュへつなぐ。Material Mask は定数、または画像（UV / Triplanar）。反転を反映する。
- 用途: 反転したオクルージョンで「割れ目の内部は割らず、見える場所だけ細かく」、上向き度で「上面だけ」。
- キャッシュのキーにマスクの設定と画像、しきい値を含める。保存名は `subdivide.threshold`。
