# 岩の種類の網羅（作れる岩と足りないノード）

作成日時: 2026-10-01 08:30
更新日時: 2026-10-01 09:52

## 目的

2026-10-01 のユーザー判断で、「あらゆる種類の岩を作れること」を目標にする。この資料は、岩の種類を見た目の成り立ちで洗い出し、今のノードで作れるかを実際に組んで確かめ、作れないものに足りないノードを整理する。新しいノードやレシピは、この表で「どの種類の岩が作れるようになるか」を基準に優先順位を付ける。

確かめ方は [LLM による岩グラフの作成](ai-authoring.md) の手順（手書きの表記で組み、`rock_cli eval` で数値、`tools/rock_shot.py` で見た目）。作れた岩は `examples/ai-recipes/` のレシピにした。

## 状態の記号

- ○: 今のノードでそれらしく作れる（レシピあり）
- △: 作れるが見た目に不満が残る
- ×: 今のノードでは作れない（足りないノードは下の G 番号）
- 未: まだ試していない

## 形の骨格（成因・節理）

| 岩 | 見た目の特徴 | 状態 | 作り方 / 足りないもの |
| --- | --- | --- | --- |
| 塊状・節理で割れた岩 | 大きな平らな節理面、角張った輪郭 | ○ | `blocky`（Random Boxes → Plane Cuts 3 系統 → 接地）。面が大味 |
| 板状節理 | 平行な板状の割れ目、直交する縦の節理 | △ | `platy-joints`。少しレンガ積みに見える（節理の間隔と深さが均一すぎる） |
| 柱状節理（玄武岩） | 多角柱の束、柱ごとの高さの違い | ○ | `columnar`（縦に 16 倍伸ばした Voronoi、外周の片を除く、柱を細らせて隙間、一部を下げる） |
| 片理（結晶片岩） | 急傾斜の薄い剥がれ、細溝、細長い破片 | ○ | `schist`。斜めの細溝にボクセルの段差が出る |
| スレート・頁岩 | 水平に近い薄板の積み重ね、剥がれた縁 | ○ | `slate`（薄い Layered Boxes → Peel） |
| 層理の段（砂岩・石灰岩） | 水平な層の棚 | ○ | `layered-ledges`（Volume Terrace） |
| 崖錐の角張った岩片 | 鋭い割れ面、小さな欠け | ○ | `talus-fragment`（大きな平面で強く切り、局所の欠け） |
| 河原の丸石・円礫 | 平たく丸い、なめらか | ○ | `river-pebble`（楕円体 + 弱いノイズ、Marching Tetrahedra） |
| 丸い転石・迷子石 | 丸いが大きな面が残る | ○ | `rounded-boulder` |
| 花崗岩のコアストーン・シーティング | 丸い塊に、表面に沿って湾曲した剥離の割れ目 | △ | 平行な面の割れ目は作れるが、表面に沿って曲がらず、座布団を積んだように見える → **G3** |
| 黒曜石・フリントの貝殻状断口 | 滑らかに湾曲した割れ面、鋭い稜 | × | 切り口が平面だけ → **G4** |
| 礫岩 | 丸い礫が埋まって突き出る | ○ | `conglomerate`（Volume Scatter の楕円体・和。G7 で対応）。礫と基質の色の違いは **G6** |
| 角礫岩 | 角張った礫が埋まる | △ | `breccia`（Volume Scatter の箱・和）。形は出るが、礫と基質の色の違いが無いと弱い → **G6** |
| 多孔質の溶岩（玄武岩・軽石） | 表面と内部の丸い気泡の穴 | ○ | `vesicular-basalt`（Volume Scatter の楕円体・差）。蜂の巣状の穴なら `honeycomb` |
| 枕状溶岩 | 丸い袋状の塊が積み重なる | 未 | Random Boxes を大きく丸めれば近いかもしれない |

## 風化・侵食の形

| 岩 | 見た目の特徴 | 状態 | 作り方 / 足りないもの |
| --- | --- | --- | --- |
| 蜂の巣状の風化・タフォニ | 表面の丸いくぼみの群れ | ○ | `honeycomb`（Volume Noise の種類「くぼみ」を粗・細の 2 段。G1 で対応）。今は全面に均一に付く（陰の面に集中させるのは G5 の向き） |
| 石灰岩の溶食（縦溝・ピナクル） | 重力方向に流れる丸い溝、尖った頂 | × | 鉛直の平面の割れ目では溝にならない（斜面に沿って流れない） → **G5** |
| きのこ岩・フードゥー・波食ノッチ | 下部や特定の高さがくびれる | × | 高さで削る量を変えられない → **G2** |
| 玉ねぎ状風化・剥離ドーム | 表面と平行な殻の割れと剥がれ | × | → **G3** |
| 氷河の擦痕・研磨面・羊背岩 | 片側が研磨されて丸く、反対側が引き剥がれて角張る。細い平行な擦痕 | × | 片側だけ丸める向きの指定が無い（上向きだけ） → **G5**。擦痕はボリュームのセル（最長辺÷128 ≒ 3 cm）より細く、形ではなく素材のハイト・法線で表す → **G6** |
| 風食（風上の研磨面） | 一方向から削られた滑らかな面 | × | → **G5** |

## 表面・色（素材）

| 岩 | 見た目の特徴 | 状態 | 作り方 / 足りないもの |
| --- | --- | --- | --- |
| 苔・地衣類・土の堆積 | 窪みや上向きの面に溜まる | ○ | Deposition Mask / Shape Mask（上向き度）+ Apply Material |
| 稜線の明るい摩耗 | 角が白っぽい | ○ | Shape Mask（曲率・山）+ Mask Filter（`rock_flat_2`） |
| 片麻岩の縞・砂岩の色の層 | 構造面に沿った色の縞 | × | 構造面（Parallel Planes）からマスクを作る手段が無い → **G6** |
| 大理石・石英の脈 | 細い脈が網目状に走る | × | 脈の形のマスクが無い → **G6** |
| 鉄錆・汚れの流れた筋 | 上から下へ流れた筋 | × | 流れの方向のマスクが無い → **G5 / G6** |

## 足りないノード（候補）

ノード設計の方針（明示的な入力ピン、種類を選ぶ汎用ノード、選ぶと結果が見える）に合わせ、既存のノードに種類や項目を足す形を優先する。

| 番号 | 足りないもの | 案 | 作れるようになる岩 | 規模 |
| --- | --- | --- | --- | --- |
| G1 | 表面のくぼみの群れ | **2026-10-01 実装**: Volume Noise の種類「くぼみ」（`pits`） | 蜂の巣状の風化、タフォニ、（浅い）気泡 | 小 |
| G2 | 高さで削る量を変える | 高さ方向のカーブで内側へ削るノード（またはボリュームの加工に「高さで効かせる」項目） | きのこ岩、フードゥー、波食ノッチ、台座岩 | 中 |
| G3 | 表面に沿った割れ目 | Volume Crack に「表面からの等距離面」で割る種類を足す（入力の形から面を作る） | 花崗岩のシーティング、玉ねぎ状風化、剥離ドーム | 中 |
| G4 | 曲面の切り口 | Plane Cuts に「曲率」（球面で切る）を足す | 黒曜石・フリントの貝殻状断口、湾曲した割れ面 | 小〜中 |
| G5 | 任意の方向で効かせる | Volume Smooth / Edge Wear の「上向きに集中」を任意の向き（ベクトル）に広げる。流下の溝は別に検討 | 羊背岩、風食、片側の研磨。溶食の溝は一部 | 小（向き）/ 大（流れ） |
| G6 | 構造・細部を素材で表す | 構造面（Planes）を入力に取るマスク（縞・層）、脈のマスク、擦痕のような細い溝を素材のハイトへ | 片麻岩の縞、色の層、大理石の脈、擦痕 | 中 |
| G7 | 小さな形を散らして足す・抜く | **2026-10-01 実装**: [Volume Scatter](volume-scatter.md)（球・楕円体・箱、和・差） | 礫岩・角礫岩、多孔質の溶岩・軽石、気泡 | 中〜大 |

## 試作で分かったこと

- 「作れる」は数値（塊 1 つ・閉じている）では判断できない。蜂の巣状の風化は数値は正常だが、見た目がくぼみではなく膨らみだった。必ず撮って見る。
- ボリュームの解像度の上限（128）で、最長辺 3 m の岩のセルは約 2.5 cm。これより細い溝・擦痕・脈は形では作れず、素材（ハイト・法線）で表す必要がある。形と素材の分担（Macro は形、Meso / Micro は素材）を種類ごとに決める。
- 柱状節理は、Voronoi の伸長（最大 16 倍）と外周の片の除去の組み合わせで作れた。既存のノードの組み合わせで届く種類はまだありそうなので、未の種類も試す。
