# Volume Terrace

作成日時: 2026-09-22 19:05
更新日時: 2026-09-22 19:05

## 位置付け

Volume にある方向の層をなす段（棚）を刻むノード。層状の剥離。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 4 番目にあった Terrace（段化）を独立したノードにしたもの。堆積岩のように、水平に近い層が交互に突き出す／へこむ形になる。サンプルは `examples/volume-smooth-terrace/`。

```text
… → Volume Noise → Volume Terrace → Volume Smooth → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。

## 設定

| 項目 | 内容 |
| --- | --- |
| 段の間隔 | 1層の厚さ。形の最長辺に対する比。0.02〜1、既定 0.15 |
| 深さ | へこませる深さ。最長辺に対する比。0〜0.2、既定 0.03 |
| へこむ割合 | 1層のうち、へこませる部分の割合。0.05〜0.95、既定 0.5 |
| なだらかさ | 段の縁のなだらかさ（間隔に対する比）。0 で直角の棚、大きいほど斜面。0〜0.5、既定 0.05 |
| ばらつき | 層ごとの深さの差。0 で全て同じ深さ、1 で 0〜深さの範囲。0〜1、既定 0.3 |
| ゆらぎ | 層の境をノイズでずらす量の最大（間隔に対する比）。0 で平らな層。0〜1、既定 0.2 |
| ゆらぎの細かさ | 最長辺あたりの山の数。0.5〜16、既定 2 |
| 向き (度) | 層の重なる方向。回した座標系の +Y が層の法線。右手系 Z → X → Y。既定 0（水平な層） |
| Seed | ばらつきとゆらぎの乱数 |

保存名は `volumeTerrace`（`rotation` に向き）。保存・読込と Undo / Redo に対応。

## 処理

格子点ごとに独立で、`FillSlices` の並列化に乗る。

1. 層の位相は、内部の格子点を囲む箱の中心を基準にする（格子の余白に左右されない）。中心からの位置を層の法線に射影し、間隔で割った値 `t` を求める。ゆらぎがあれば、値ノイズ（−1〜1）× ゆらぎ を `t` に足す。
2. `t` の端数 `u`（0〜1）で層の中の位置を決める。`u` が 0〜割合 の範囲がへこむ層。へこむ層の中心からの距離を smoothstep に通し、なだらかさの幅で 1 → 0 へ落とす。
3. 層番号のハッシュで層ごとの深さを `深さ × (1 − ばらつき × 乱数)` に決め、`d + 層の深さ × プロファイル` を足す。**削る方向にだけ効き、形は広がらない。** 外周は空のまま保たれ、格子は入力と同じ。
4. 表面から「深さ + 2セル」より離れた格子点は入力の値を引き継ぐ。
5. 浮いた小片は最大の塊だけ残し、加工でできた閉じた空洞は埋め戻す（他のボリュームノードと共通）。

段の縁で距離値が急に変わるため、等値面がそこで折れて棚の面（層に平行な面）ができる。層に平行な面（水平な層なら上面と下面）はへこむ層の中でも平行移動するだけなので、外形はほぼ変わらない。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Volume 出力を接続してください |
| 間隔・深さ・割合・なだらかさ・ばらつき・ゆらぎ・細かさが範囲外、または回転が非有限 | それぞれの範囲を示す |
| 結果に内部が残らない | 段を刻んだ結果に内部が残りません… |

## 制限

- **段の間隔がセル間隔に近いと格子で潰れる。** 目安は「間隔 × 解像度 ≥ 4」。
- 段はそのままだと機械的に見える。ゆらぎとばらつきで崩すか、後ろに Volume Noise の歪みや [Volume Smooth](volume-smooth.md) を置く。
- 層の厚さは一定（間隔の倍数）。層ごとに厚さを変える設定は無い（ゆらぎで境をずらすことはできる）。
- 結果の距離値は、内外の符号は正しいが、距離としては近似になる。

## 検証

`tests/VolumeTerraceTests.cpp`。深さ 0 で入力と完全に同じになること。平らな層で閉じた1つの塊になること、Dual Contouring、格子の不変、形を広げないこと、削る深さが設定を超えないこと、へこむ層と残す層で面の近くの値が想定どおりに変わること、削る体積が深さと割合に見合うこと、再現性、上面が動かないこと。ばらつきと Seed、なだらかさによる斜面、ゆらぎで層の境が波打つこと、向きを回すと層の方向が変わること、最も細かく深い設定で小片と空洞を残さないこと、不正設定10種と空入力の拒否。グラフでは型制約、未接続の診断、キャッシュの再利用と向きの変更による作り直し、不正設定の診断を確認する。
