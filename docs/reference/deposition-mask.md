# Deposition Mask

作成日時: 2026-09-26 19:19
更新日時: 2026-09-26 19:19

UV付きMeshから、土の堆積候補を白黒のMaskとして生成する。上向きの受け面と近傍の隙間を優先し、上方を塞がれた場所・下向き面・垂直面を抑える。厚みを持つ土の形状は生成しない。

## 接続

```text
岩のMesh → UV Unwrap ─┬→ Apply Material（岩）→ Apply Material（土）→ Mesh Output
                     └→ Deposition Mask ──────────────↑ Mask
```

土のSurfaceを後段のApply Materialへ接続する。Deposition Maskの選択中は入力Meshを白黒で表示し、白い部分ほど土の素材が強く適用される。Noise MaskとMask Combineで乗算すれば、堆積候補にムラを加えられる。

## 設定

| 設定 | 内容 |
| --- | --- |
| 堆積量 | 0〜1。候補マスクの強さ。0なら全面黒 |
| 隙間の範囲 | 周辺の遮蔽物を探す距離（m）。既定0.3 |
| 許容する傾斜 | 水平面からの上限角度（1〜89度、既定60）。水平から上限まで滑らかに減衰 |
| 詳細：隙間を優先 | 0なら開いた上面にも堆積。1なら周囲の遮蔽がある場所だけ。既定0.8 |
| 詳細：マスク解像度 | 128〜4096。既定1024 |
| 詳細：サンプル数 | 近傍遮蔽のレイ数。8〜128、既定32 |
| 詳細：反転 | 消費側で白黒を反転。画像の再計算は不要 |

状態表示はノード共通の固定欄を使う。処理状況によって設定欄へ行を追加・削除しない。

## 判定

Shape Maskと同じUVラスタライズ・BVH・余白埋めを共用する。画素の表面位置と補間法線を計算し、次の重みを掛け合わせる。

- 受け面：補間法線と入力座標の+Yの内積。幾何法線が水平以下の面は対象外。
- 隙間：法線を軸にした半球の近傍遮蔽率を3倍して0〜1へ制限。「隙間を優先」で均一な被覆と補間する。
- 上方の開口：真上と+Yから15度の円錐上の8方向を調べ、塞がれていない割合を使う。探索長は入力外接箱の対角長＋隙間の範囲。近傍探索距離より遠い天井も検出する。
- 堆積量：最終値に掛ける。

固定方向のサンプリングで、同じ入力と設定なら同じ結果になる。風・流体・粒子の輸送を計算する物理シミュレーションではなく、素材の塗り分け用の近似。

## 範囲と保存

入力はUV付きの生成Meshを1つ。複数の岩の相互遮蔽を使う場合は先に1つのMeshにまとめ、UVを展開する。入力に含まれないモデルや地面は遮蔽物として扱わない。上方向は入力のローカル+Yで固定。

重なりのないUVを使う。UV再展開や形状変更後はマスクを再生成する。画像生成はCPU並列処理で、進捗・キャンセルに対応。グラフ保存名は`depositionMask`。全設定を保存し、画像は開いた時に再生成する。設定・入力はキャッシュキーへ含め、反転だけは描画・合成・変位側で適用する。

## 検証

水平面、裏面、垂直面、急斜面、近傍範囲より遠い天井、上に開いた入隅を単体テストで比較。距離・堆積量・反転・再現性・不正値・キャンセル、ノード登録、既存マスクとの合成、Apply Material、Subdivideへの伝播、キャッシュ無効化、Undo / Redoを確認。

実アプリで積層岩の白黒プレビューと素材適用、保存後の設定を確認。サンプルは`examples/deposition-mask/deposition-mask.rockscene`。
