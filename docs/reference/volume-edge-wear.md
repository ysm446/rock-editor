# Volume Edge Wear

作成日時: 2026-09-22 23:05
更新日時: 2026-09-22 23:05

## 位置付け

Volume の凸な稜線と角だけを削り、平らな面と凹な隅は動かさないノード（角の摩耗）。2026-09-22 のユーザー依頼「岩っぽくするためにエッジを削るような処理」への対応。Volume Smooth の「なめらか」はぼかしで面も一緒になまるが、このノードは Plane Cuts の切り口を平らなまま保ち、角だけを丸める・欠けさせる。サンプルは `examples/volume-edge-wear/`。

```text
… → Plane Cuts → Volume Crack → Volume Noise → Volume Terrace → Volume Smooth → Volume Edge Wear → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。格子（範囲・セル間隔）は入力のまま変わらない。

Mesh 側でのベベルではなく Volume 側で持つ理由は、Volume to Mesh の出力に稜線がきれいな折れ線として存在しないため。SDF なら稜線は距離場の曲率として場所ごとに取り出せる。

## 設定

| 項目 | 内容 |
| --- | --- |
| 半径 | 稜線を見つける半径（ガウスの σ）。形の最長辺に対する比。丸まる幅の目安で、これより鈍い稜線は弱くしか削れない。0.005〜0.2、既定 0.03 |
| 量 | 稜線を削る深さの最大。形の最長辺に対する比。直角の稜線と頂点でこの深さ、鈍い稜線では浅い。0〜0.2、既定 0.02 |
| ばらつき | 稜線に沿った削れ方のばらつき。0 で一様。1 ではノイズの低い所が削れず、欠けた角のようになる。0〜1、既定 0.5 |
| ばらつきの細かさ | 最長辺あたりのノイズの山の数。0.5〜16、既定 4 |
| 上向きに集中 | 0 で全ての稜線。1 で上（+Y）を向いた面の稜線だけに効き、下側の角は鋭いまま残る。0〜1、既定 0 |
| Seed | ばらつきの乱数 |

保存名は `volumeEdgeWear`。保存・読込と Undo / Redo に対応。設定と上流が同じなら、ボリューム枝のキャッシュから再利用する。

## 処理

1. **稜線の強さ**: 距離場に 3 軸の分離ガウスぼかし（Volume Smooth と同じ `BlurGrid`。σ = 半径 × 最長辺、格子の外は距離で外挿）を掛け、`(ぼかし − 元) / σ` を求める。この値は凸な稜線で正、平らな面で 0、凹な隅で負になる。直角の稜線で約 0.6、立方体の頂点で約 0.9、150 度の鈍い稜線で約 0.2、120 度で約 0.4。0.05〜0.6 を smoothstep で 0〜1 に写し、直角以上を 1 とする。
2. **表面の点で読む**: 格子点ごとに入力の勾配（中心差分）で最も近い表面の点 `p − d ∇d` を求め、そこで稜線の強さを三線形補間で読む。**格子点そのもので読んではいけない。** 距離場の内部には凸な稜線の二等分面（`max(x, y)` の折れ）に沿ってぼかしとの差が残り、格子点で読むと薄い板の中心面まで削れて板が割れる（テストで確認）。
3. **重み**: `稜線の強さ × 量 × (1 − 集中 × (1 − 上向き度)) × ばらつきの係数`。上向き度は勾配の +Y 成分。ばらつきの係数は表面の点の値ノイズ n（0〜1）から `1 − ばらつき × (1 − n) × 2` を 0〜1 に収めたもの。ばらつき 1 では n < 0.5 の所が削れない。
4. **削る**: `d + 重み × 最長辺` を書く。**削る方向にだけ効き、形は広がらない。** 表面から「量 + 2 セル」より遠い格子点と外周の 1 点は入力のまま。
5. 浮いた小片は最大の塊だけ残し、加工でできた閉じた空洞は埋め戻す（他のボリュームノードと共通）。

削れる深さは稜線で最大、面へ向かって σ 程度の幅で 0 に落ちるので、断面は稜線を中心に丸まった形になる。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Volume 出力を接続してください |
| 半径・量・ばらつき・細かさ・集中が範囲外、または非有限 | それぞれの範囲を示す |
| 結果に内部が残らない | 処理した結果に内部が残りません。量か半径を減らしてください |

## 制限

- **半径がセル間隔に近いと効かない。** σ がセルの 0.3 未満ではぼかしが実質無く、稜線の強さが出ない。解像度 96 で最長辺 2 m ならセルは約 2 cm、半径 0.03（σ = 6 cm）で 3 セル。
- **半径に対して薄い部分は全体が稜線に見える。** 厚さが 2σ 程度の板や細い突起は、面もわずかに削れる（厚さ 0.24 m、σ = 0.1 m で量の 4 % ほど。テストで 1 割未満を確認）。薄い板の角だけを削りたいときは半径を厚さの 1/4 以下にする。
- 鈍い稜線（150 度以上）はほとんど削れない。Volume Noise で崩した面の細かな凹凸も同様で、Plane Cuts の切り口どうしの角のような明確な稜線に効く。
- 削れる断面は稜線の強さの分布で決まり、半径で指定した円弧になるわけではない。
- 結果の距離値は、内外の符号は正しいが、距離としては近似になる。
- 格子より細かい角の欠けや微細な摩耗は、形状ではなく Height / 法線の焼き込み（Shape Mask の曲率）で表す領域。

## 検証

`tests/VolumeEdgeWearTests.cpp`。2 m の立方体で、量 0 で入力と完全に同じになること、閉じた 1 つの塊になること、Dual Contouring でも閉じること、格子の不変、頂点と稜線の近くが削れて面の中央と内部の奥が動かないこと、体積がわずかに減るだけで外接箱が変わらないこと、削る深さが量を超えないこと、形が広がらないこと（値が減る格子点がない）、外周の不変、再現性、量が小さいほど浅いことを確認する。薄い板（厚さ 0.24 m）で、板の中心と面の中ほどが削れず縁だけ削れること、半径が厚さに近いときの面の削れが量の 1 割未満であること。ばらつきで削る量が減り稜線に沿って変わること、Seed、上向きの集中で上の稜線だけ削れること、不正設定 8 種と空入力の拒否。グラフでは型制約、未接続の診断、キャッシュの再利用、設定の変更による作り直し、不正設定の診断を確認する。
