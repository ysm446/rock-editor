# Volume Crack の入力の拡張と割り方の候補（設計メモ）

作成日時: 2026-09-22 22:35
更新日時: 2026-09-22 22:35

2026-09-22 のユーザーとのやり取りをまとめたもの。実装は未着手。計画上の位置は [plan](../plan/plan.md) の「現在の方向」。

## 前提: 面が定義できれば割れる

[Volume Crack](volume-crack.md) の中核は「境界面までの距離 d を求めて `d = max(d, 半幅 − 距離)` を適用する」処理で、V 字断面・割れ目ごとのばらつき・ゆらぎ・空洞の埋め戻しは境界面の出どころに依存しない。境界面の距離を Voronoi の二等分面から三角形メッシュや別の平面群へ差し替えれば、他はそのまま使える。距離は符号なしなので、Voronoi モードと同じく幅は歪まない。

## 1. Points 以外の入力

### Pieces 入力（最有力）

Voronoi Fracture の `Piece` は三角形ごとに `faceOrigins`（0 = 切断面、1 = 元の外面）を持つ。切断面だけを集め、`Piece::transform` を適用した三角形までの距離で彫る。

- 今の Voronoi 割れ目と同じ結果になるうえ、Voronoi Fracture の回転・伸長がそのまま効き、現状の制限「方向性のある割れ目が無い」が解消される。
- Piece Transform で動かした後の隙間に沿った割れ目も彫れる。
- 割れ目ごとの幅の倍率は、切断面の平面（法線と距離）のハッシュで決めると両側から同じ幅になる。
- 深さ 1 で彫ると Voronoi Fracture の分割結果と同じ塊に分かれる。「浮いた塊を除かない」方針と整合する。

### Mesh 入力（板ポリゴン）

手で置いた平面や曲面をそのまま境界にする。Pieces to Mesh の出力を入れると元の外面も含まれ、表面全体が「境界の近く」と判定されて彫られてしまうので、板ポリゴンだけを渡す用途向け。Pieces 入力とは別物として用意する。

### ワイヤーフレーム（辺）入力

線分までの距離になるので、面で切るのではなく線に沿った溝（断面が円の筒）になる。辺が表面上にあるときだけ意味があり、見た目はかなり違う。面ベースを先に作り、必要になったら追加する。

### 実装コスト

三角形までの距離は `src/geometry/MeshVolume.cpp` の `TriangleDistance` と空間分割の走査が既にあり、To Volume と同程度の負荷で済む。変更箇所は `CrackVolume` に距離の供給元を差し替える口を作ること、`RockEvaluator` の入力解決、ノードの入力ピン。ノード設計の好みに沿い、「源」の種類（Points / Pieces / Mesh）を選ばせ、種類に応じた入力ピンを明示する形にする。切断面の数が多いほど格子点あたりの走査は増えるが、空間分割で絞れるため 2N 回の総当たりより有利になる見込み。

## 2. Voronoi 以外の割り方

いずれも「点や面までの距離」で書ける。Volume Crack（と Voronoi Fracture 系の分割）に「分割の種類」を選ぶ設定を持たせ、距離関数を種類ごとに差し替える。

### 柱状節理（Columnar Jointing）

- 柱の軸（例えば Z）に垂直な面上で 2D Voronoi を作り、軸方向に押し出す。3D の点の代わりに「軸に垂直な面上の 2D 点」を使い、距離計算で軸成分を無視すれば、今の二等分面の式がそのまま使える。
- 断面が六角形寄りになるのは、点を格子状に置いてジッターを加えると自然に出る（ランダム配置より整った多角形になる）。
- 追加で欲しい設定: 柱の軸方向（回転）、柱の太さ（点間隔）、ジッター量（整列度）、横方向の節理（柱を輪切りにする面。軸に垂直で高さにばらつきがある平面群。柱ごとに高さのオフセットをハッシュで決めると「ずれた輪切り」になる）。
- Voronoi Fracture の伸長を軸方向に極端に大きくしても近い見た目にはなるが、柱の端が閉じるので押し出し型の方が正しい。
- 最も既存コードに近く、最初に足す候補。

### そのほか

- **層理・板状節理（Layered / Platy）**: 一方向に並ぶ平行平面群。間隔と厚みのばらつき、少しの傾き、うねり（ノイズで面をずらす）。堆積岩や頁岩の割れ方。片理面の岩（下記 4）の「板と板の間の隙間」に使う。
- **直交節理（Blocky）**: 互いに直交する 2〜3 系統の平面群。間隔にばらつき、系統ごとに回転。花崗岩や砂岩の四角い岩塊。Plane Cuts の Directional に近いが、外側を切り落とすのではなく内部を貫く割れ目にする。
- **同心状・玉ねぎ状（Concentric / Exfoliation）**: 中心からの距離で層を切る球殻、または形の表面からの距離（既存の `DistanceToSet`）に沿った殻。風化した丸い岩。
- **放射状（Radial）**: 中心軸の周りに角度で分割する平面群。柱状と組み合わせると玄武岩の花弁状になる。
- **ノイズで歪めた面**: どれも面をノイズで変位させれば直線的でなくなる。Volume Displace の役割と重なるので、分割側に入れるか後段で崩すかは設計の判断。

## 3. 複数の SDF を扱う

Volume ピンを流れるのは `VolumeGrid` 1 つ。ただしグラフは枝分かれできるので、Piece ごとに To Volume を通して別々の SDF にし、違うノードをかけて Volume Boolean（和）で合成する使い方は今すぐ可能。手で枝を作る分ノードが増えるので、2〜3 個までが実用的。

```text
Voronoi Fracture → Piece Filter(A) → Pieces to Mesh → To Volume → Volume Noise(強) ─┐
                 → Piece Filter(B) → Pieces to Mesh → To Volume → Plane Cuts       ─┴ Volume Boolean(和) → …
```

本格的にやるなら Pieces と同じ「集まり」の型を Volume にも作る。

- **Volumes 型**: `PieceCollection` と同様に `VolumeGrid` の配列と ID を持つ。`Pieces to Volumes` で Piece ごとに SDF 化する。
- **既存の Volume ノードを集まりにも対応**: 集まりが入ったら各要素に同じ処理をかける。処理本体は 1 つの格子を扱う関数のままで、ループを足すだけ。要素ごとに Seed をずらせば同じ設定でも岩ごとに違う崩れ方になる。
- **選択で処理を分ける**: `Volume Filter` で ID や体積で選び、別処理をかけて `Volume Merge` で戻す。
- **出力**: `Volumes to Mesh` で各要素をメッシュ化して Model の集まりとして出す（Pieces to Mesh に相当）か、Boolean の和で 1 つに戻す。
- **Split Volume**: 深さ 1 の Volume Crack の結果から連結成分を取り出して集まりにする。Voronoi Fracture を経由せずに SDF の割れ目から直接「別々の塊」を得られ、柱状節理で割ってから柱ごとに違う風化をかける、といった流れが書ける。

注意点:

- **メモリ**: 各軸 192 点で 1 つ約 28 MB。100 個の Piece をそのまま SDF 化すると数 GB になるので、要素ごとに自分の範囲だけの小さな格子（余白付きの AABB）を持たせるのが前提。
- **格子の不一致**: 要素ごとに範囲・原点が違うので、合成時は Volume Boolean のように A の格子を基準に B を再サンプルする。
- **キャッシュ**: 要素単位で持てば 1 つの設定変更で全要素を作り直さずに済む。Pieces の `generation` / `fingerprint` と同じ仕組み。

まずは枝分かれ + Volume Boolean で試し、要素数が増えて手に負えなくなった段階で Volumes 型に進む。

## 4. 片理面の岩（薄い層が階段状に重なる頁岩）の作り方

参考は、薄い層が重なり層ごとに縁の位置が違う階段状の割れ方をした頁岩の写真（化石の渦巻き模様つき）。

### 今のノードでの組み方

```text
Base Shape（平たい Box。厚さは最長辺の 0.2〜0.3）
→ To Volume
→ Plane Cuts（主方向、系統 2、向きの Y を層の法線に合わせる、ばらつき 5〜10 度、深さ小）
→ Volume Terrace（向きを同じ層の法線に、間隔 0.03〜0.05、割合 0.9 前後、深さ 0.1〜0.2、ばらつき 1、なだらかさ 0、ゆらぎ 0.2〜0.4）
→ Volume Noise（Facet、量 0.01 程度、細かさ 8〜16）
→ Volume Close（幅。薄い層の奥の隙間を埋めて三角形を節約）
→ Volume to Mesh → Remesh → …
```

- **Plane Cuts** は輪郭づくり。層の法線に沿う系統で上下面を平らに保ち、面内の系統で縁をギザギザに切り落とす。ばらつきを小さくすると縁が層に沿って直線的に欠けた感じになる。
- **Volume Terrace** が階段の本体。処理は「へこむ層を層ごとにランダムな量だけ一様に削る」なので、割合を 0.9 以上にしてほぼ全部の層をへこむ層にし、ばらつきを 1 にすると各層が別々の大きさの板になる。なだらかさ 0 で縁が直角に立つ。ゆらぎで層境が波打ち、剥がれた面の不規則さが出る。
- **Volume Noise** の Facet で表面の微細な荒れ。量は小さくしないと層の縁が溶ける。
- **薄い層の間の細い線**（側面の細かい層理）は格子の解像度では潰れるので、形状ではなく Height / 法線の焼き込みで表す。層の法線方向の座標を縞にしたハイトを Apply Material で貼ると側面だけに縞が出る。
- **材質**: 化石の模様はベースカラーと Height に描く。灰色の細粒で、層の側面だけ少し暗く粗くすると層の重なりが読める。

### 足りていない部分

- **層ごとの面内のずれ**: Terrace は各層を周囲から一様に削るので、板が斜め方向にずれて重なる形にはならない。層番号ごとにランダムな面内オフセットで格子をサンプルする処理（層ごとの平行移動）を Terrace に足すのが最も小さい変更。
- **層に沿う割れ目（片理面そのもの）**: 上記 2 の「層状」モードがあれば、板と板の間に暗い線の隙間が入り、剥がれかけの表現ができる。Terrace の割合と深さを小さくした薄い溝で代用もできる。
- **縁の欠け**: Plane Cuts の局所モードを層の法線に垂直な向きに限定して小さく多数入れると縁の細かい欠けに近づく。今の局所モードは方向指定がないので、主方向の局所版が欲しくなる可能性がある。
