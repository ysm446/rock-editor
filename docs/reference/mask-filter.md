# Mask Filter

作成日時: 2026-09-26 20:29
更新日時: 2026-09-26 20:29

1つのマスク画像を加工するノード。種類を選ぶ汎用ノードで、「ぼかし」「シャープ」「レベル」を持つ。[Shape Mask](shape-mask.md)・[Noise Mask](noise-mask.md)・[Deposition Mask](deposition-mask.md)・[Mask Combine](mask-combine.md)・別の Mask Filter の後ろに挟み、Apply Material の Mask へ渡す。

## 接続

```text
UV Unwrap ─→ Shape Mask ─→ Mask Filter（ぼかし）─→ Mask Filter（レベル）─→ Apply Material の Mask
```

- 入力は Mask を1本、出力は Mask。直列につないで「ぼかしてからレベルで締める」のように組み合わせる。
- Material Mask（定数 / 画像。面の中心で読む）は加工できない。つなぐと診断する。UV空間の画像を持たないため。
- 出力の解像度とメッシュは入力のマスクのもの。選択時は加工したマスクを白黒で貼ってプレビューする。

## 設定

| 種類 | 設定 |
| --- | --- |
| ぼかし | 半径（m、0.001〜1、対数スライダー）。岩の表面の3D距離 |
| シャープ | 半径（m）、量（0〜4）。`元 + 量 × (元 − ぼかし)` のアンシャープマスク |
| レベル | 入力の黒・白、カーブ（ガンマ、`値 ^ ガンマ`）、出力の黒・白 |
| 共通 | 反転（Mask Combine と同じく画像に焼き込む） |

入力の Shape Mask などの「反転」（画像に掛かっていない分）は、加工の前に掛ける。

## ぼかしの計算（UVの継ぎ目をまたぐ）

UVの画像の上でぼかすと、島の境目の両側でぼけ方が食い違い、継ぎ目に線が出る。Mask Filter は岩の表面の上でぼかす。

1. 入力のメッシュのUVをラスタライズし、各画素の中心が当たる面と3D位置を求める（Shape Mask と同じ手順）。
2. 空間を箱に区切り、画素を集める。箱は半径の 1/4 だが、画素の表面での大きさ（`√(表面積 ÷ 島の画素数)`）より細かくはしない。箱ごとに位置・向き・値の平均と画素数を持つ。
3. 箱の単位でガウスぼかしを掛ける。σ は半径の半分（半径 = 2σ）で、半径より遠い箱は使わない。重みは画素数 × ガウス × 向きの重み。
4. 各画素へ、近くの箱（前後左右上下 1 つ）の値をガウスで補間して戻す。補間の幅は箱の半分とσの小さいほう（補間自体がぼかしになるので、半径が画素ほどのときににじみすぎないように）。
5. 島の無い画素は、Shape Mask と同じく最も近い島の値で埋める。

向きの重みは `clamp((n₁·n₂ + 0.5) / 1.5, 0, 1)`。裏合わせの面（薄い板の表と裏）は混ぜず、直角の角は 1/3 の重みで混ぜる。距離は表面に沿った距離ではなく3Dの直線距離なので、深い溝の向かい合う壁どうしは、向きが揃っていれば混ざる。

Release の実測（Sphere・分割16・3072三角形、UV 1024²）：半径 0.01 / 0.03 m で約 240 ms、0.1 / 0.3 m で 45〜65 ms。箱が画素の大きさで止まる小さな半径のほうが箱の数が多く、重い。

## 計算と受け渡し

- `geometry::FilterMask`（`src/geometry/MaskFilter.cpp`）。レベルは画素ごとで、メッシュを使わない。
- 評価結果は Mask Combine と同じく、入力のメッシュに `previewMask` を付けたもの。`previewMaskInvert` は常に false。
- キャッシュは内容キー。設定（種類・半径・量・レベルの5値・反転）と入力のマスクのキーに、入力の反転を加える。
- 保存は `maskFilter` オブジェクト（`type` は `blur` / `sharpen` / `levels`、`radius` / `amount` / `inputLow` / `inputHigh` / `gamma` / `outputLow` / `outputHigh` / `invert`）。
- `IsImageMaskNodeKind` に含めるので、Apply Material / Subdivide / Displace / Mask Combine などの使う側は既存の経路で受ける。

## 検証

- 単体テスト（`tests/ShapeMaskTests.cpp` の `RunMaskFilterTests`）：レベルの写像・反転・入力の反転・ガンマ、床と壁のメッシュで継ぎ目をまたぐぼかし（3Dで壁に近い床は灰色、UVで壁に接していても3Dで遠い床は黒）、一定値の保存、半径による広がり、並列の再現性、シャープ（量0で元のまま、角の両側の差が開く、遠い所は変わらない）、不正設定・空入力・UVの無いメッシュ・キャンセルの診断、ノード定義と接続、Material Mask の診断、直列、入力の反転による作り直し。
- 実アプリでサンプルを開き、選択時のプレビューで割れ目のマスクがぼけ、継ぎ目の線が出ないことを確認。
- サンプルは `examples/mask-filter/`。

## 制限

- 距離は3Dの直線距離。表面に沿った（測地線の）距離ではないので、薄い壁の向こう側でも向きが揃っていれば混ざる。
- 出力は入力と同じくUV空間の画像で、UV Unwrap をやり直すと合わなくなる（Shape Mask と同じ診断）。
