# Remesh

作成日時: 2026-09-22 22:10
更新日時: 2026-09-22 22:40

## 位置付け

Mesh の三角形を、一様な大きさの正三角形に近い形へ作り直すノード（等方リメッシュ）。Volume to Mesh の三角形は不揃いで（Marching Tetrahedra は細長い面が多く、Dual Contouring も大きさがばらつく）、Subdivide で細分化しても不揃いのまま密になる。Remesh を UV Unwrap の前に置くと、一様な三角形の上で UV 展開と Displace ができ、Displace の密度も均一になる。2026-09-22 のユーザー依頼「Subdivide の替わりに Remesh のようなノード」への対応。サンプルは `examples/remesh/`。

```text
Volume to Mesh → Remesh → UV Unwrap → Apply Material → Displace → Mesh Output
```

Decimate と同じ場所に置く。Remesh 自体が面数を決めるので Decimate の代わりにもなるが、Decimate は形の細部を残しつつ減らすのに対し、Remesh は辺の長さより細かい凹凸を均す。右クリックメニューの「メッシュ」にある。入力・出力とも Mesh 型。UV は引き継がない（UV付きの入力は診断する）。

## 設定

| 項目 | 内容 |
| --- | --- |
| 辺の長さ | 目標の辺の長さ。形の最長辺に対する比。0.002〜0.2、既定 0.02（対数スライダー） |
| 繰り返し | 分割 → 縮約 → 反転 → 平滑化を繰り返す回数。1〜20、既定 5 |
| 特徴辺の角度 | これより大きく折れた辺を稜線として保つ。0〜180 度、既定 40。180 で稜線を保たず、角も丸くなる |

三角形数は概ね `表面積 ÷ (√3/4 × 辺の長さ²)`。300万面を超える設定は診断する。保存名は `remesh`。保存・読込と Undo / Redo に対応。

## 処理

Botsch & Kobbelt の増分リメッシュ。目標の辺の長さを L とする。

0. **前処理**: L × 2 より長い辺を持つ面を、Subdivide と同じ 1→4 分割（隣は共有辺に合わせて 2〜4 分割）で先に細かくする（最大16回）。辺を割るたびに中点から向かいの頂点へ辺を張る増分の分割だけでは、大きな三角形が扇状の細長い面に割れて面数が爆発する（実装時に 12 面の直方体で当時の上限 100 万面を超えた）。1→4 分割なら辺が毎回半分になり、形も保たれる。
1. **特徴辺の決定**: 折れ角が「特徴辺の角度」より大きく、両側の面の形が悪くない（面積の2倍 ÷ 最長辺² ≥ 0.1）辺を候補にする。候補をつないだ鎖ごとに長さを合計し、L × 3 未満の鎖は格子の段差とみなして捨てる。残った鎖が稜線になる。特徴辺は最初に決めて、分割・縮約で引き継ぐ（分割で中点も特徴に、縮約で消える頂点の特徴辺は残す頂点へ付け替える）。毎回の折れ角で判定すると、格子から作ったメッシュでは稜線でない所まで特徴になり、頂点が動けずに細長い面が残る（実装時に Marching Tetrahedra の直方体で形の悪い面が 4% 残った。静的にして 0.4%）。
2. 各繰り返しで:
   - **分割**: L × 4/3 より長い辺を中点で割る（辺の一覧を1回だけ走査）。
   - **縮約**: L × 4/5 より短い辺をまとめる。閉じた多様体のまま（リンク条件）、面が裏返らず、新しい辺が L × 4/3 を超えず、形の悪い面を新しく作らない（もとから形の悪い場所では悪化しない限り許す）ときだけ行う。特徴辺は両端が角（特徴辺が3本以上）でなければ中点へ、片方が角ならそこへまとめる。特徴でない辺は、片方が稜線上ならそこへまとめ、両方が稜線上なら稜線どうしを混ぜないので行わない。
   - **反転**: 頂点の次数が 6 に近づくとき、または細長い面（形の良さ 0.2 未満）が2倍以上良くなるときに辺を反転する。特徴辺は反転しない。反転先の頂点どうしが既につながっている場合と、面が裏返る場合は行わない。
   - **平滑化と投影**: 各頂点を隣接頂点の重心へ、頂点法線に垂直な成分だけ動かし（接線方向の平滑化）、元の表面の最近点へ投影する。稜線上の頂点（特徴辺2本）は稜線に沿ってだけ動かし、角（3本以上）と稜線の端（1本）は動かさない。動かして面が裏返る頂点は元に戻す。
3. 生きている頂点と面を詰めて出力し、閉じていることを確かめる。

最近点の検索は、入力の三角形を一様格子（セルは L × 2 と最長辺 ÷ 128 の大きいほう）に登録し、近いセルから順に探す。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Mesh出力を接続してください |
| 辺の長さ・繰り返し・角度が範囲外 | それぞれの範囲を示す |
| UV付きの入力 | UVは引き継げません。Remesh は UV Unwrap の前に置いてください |
| 閉じていない入力、多様体でない入力 | 入力は閉じた向き付きのメッシュにしてください |
| 300万面を超える設定 | 出力が300万面を超えます。辺の長さを大きくしてください |

## 制限

- UV を引き継がないので、UV Unwrap の後には置けない。Shape Mask の画像とも対応しない。
- 辺の長さより細かい凹凸は均される。細部を残したまま面数を減らすのは Decimate の役割。
- 特徴辺は L × 3 以上の鎖だけを保つ。短い稜線や、格子の段差程度の折れは丸くなる。
- 頂点数の異なる複数のメッシュ（Merge の後）にはメッシュごとに掛かる。
- マスクによる場所ごとの辺の長さ（適応リメッシュ）は無い。
