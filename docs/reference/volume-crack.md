# Volume Crack

作成日時: 2026-09-22 01:55
更新日時: 2026-10-01 13:40

## 位置付け

点群の Voronoi 境界面、または [Parallel Planes](parallel-planes.md) の構造面に沿って、Volume の表面から割れ目を彫るノード。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 3 番目。サンプルは `examples/volume-crack/`。

```text
… → To Volume → Plane Cuts ───────────┐
                                       ├ Volume Crack → Plane Cuts（局所）→ Volume to Mesh → Mesh Output
Base Shape（囲む Box）→ Scatter Points ─┘
```

右クリックメニューの「ボリューム」にある。入力は Volume と、Points / Planes のどちらか一方、出力は Volume。格子（範囲・セル間隔）は入力のまま変わらない。

**Points の作り方**: Scatter Points は凸な Mesh を必要とする。割れ目を入れたい形が凸でないとき（直方体の塊など）は、形を囲む Base Shape の Box に Scatter Points をつなぐ。点は形の外にあってもよく、境界面が形を通るところだけが割れ目になる。

## 設定

| 項目 | 内容 |
| --- | --- |
| 幅 | 表面での割れ目の幅。形の最長辺に対する比。0〜0.2、既定 0.03 |
| 深さ | 割れ目が届く深さ。形の最長辺に対する比。0.01〜1、既定 0.15。1 で形を貫く |
| ばらつき | 割れ目ごとの幅の差。0 で全て同じ幅。1 では半分ほどの割れ目が閉じ、残りは 0〜1 倍に散らばる。既定 0.6 |
| ゆらぎ | 割れ目に沿った幅の変化。大きいほど途中で細くなり、途切れる。0〜1、既定 0.5 |
| ゆらぎの細かさ | 最長辺あたりのノイズの山の数。0.5〜16、既定 3 |
| Seed | ばらつきとゆらぎの乱数。割れ目の配置は変えない（有限の割れ目では、割れ目を置くセルと形も変わる） |
| 割れ目の長さ | Planes 入力用。0（既定）なら面全体が割れ目で端から端まで続く。正なら面をこの長さ（最長辺に対する比）のセルに分け、先端の閉じた割れ目を置く。0〜1 |
| 割れている割合 | 長さ > 0 のとき。割れ目を置くセルの割合。0〜1、既定 0.6 |
| 段違い | 長さ > 0 のとき。割れ目ごとに面の法線方向へずらす量。最大で面の間隔の ±45%。0〜1、既定 0 |

保存名は `volumeCrack`。保存・読込と Undo / Redo に対応。割れ目の配置は上流の Scatter Points、または Parallel Planes で決まる。

## 処理

Points 入力では、格子点ごとに最も近い点 i を求め、他の点 j との垂直二等分面までの距離 `(|p − s_j|² − |p − s_i|²) / (2 |s_j − s_i|)` を計算する。Voronoi のセルは凸なので、この距離の最小がセルの境界面までの厳密な距離になる。近似の F2 − F1 と違い、割れ目の幅が場所によって歪まない。

Planes 入力では `abs(dot(normal, p) - offset)` を面までの距離として使い、面番号で幅の倍率を決める。以下の処理は両方で共用する。

距離場へ `d = max(d, 半幅 − 境界面までの距離)` を適用する。半幅は次の積で決まる。

- **V 字の断面**: `1 + d / 深さ` を 0〜1 に収めた値。表面（と外側）で 1、指定の深さで 0 になる。深さの制限と断面の形を同じ式で扱う。
- **割れ目ごとの倍率**: 点の対 (i, j) から固定のハッシュで決める。対で決まるので、境界面のどちら側から見ても同じ幅になる。割れ目ごとに幅が違うため、距離の最小ではなく「半幅 − 距離」の最大を取る。
- **ゆらぎ**: 位置から求める 3D の値ノイズ。ゆらぎ 1 ではノイズの低い場所で幅が 0 になり、割れ目が途切れる。

最大の幅でも届かない格子点（形の外側の遠くと、深さより奥）は、境界面までの距離を求めずに入力の値を引き継ぐ。格子点ごとに独立した計算で、Z スライス単位で並列に処理する。設定・Volume 側・Points 側の上流が同じなら、ボリューム枝のキャッシュから再利用する。

### 内部の空洞の埋め戻し

重なった立体から作ったボリューム（Pieces to Mesh や Merge を To Volume へ入れた場合）は、内部に残る面の近くでも距離が小さい。そこは「表面の近く」と見なされて彫られ、外へつながらない空洞になる。彫ったあとで格子の外周から外部をたどり、届かない彫り跡は入力の値へ戻す。入力にもとからある空洞は残す。

Plane Cuts と違い、**浮いた塊は除かない。** 深さ 1 の割れ目で形を分けるのは意図した使い方である。

## 診断

| 状況 | 表示 |
| --- | --- |
| Volume または割れ目の源が未接続 | Volume と、Points または Planes の一方を接続してください |
| Points と Planes の両方が接続 | 一方を外すよう診断 |
| 評価範囲が512面を超える | 平行面の間隔を広げるよう診断 |
| 点が1個以下、または512個超 | 割れ目には2～512個の点が必要です |
| 重複した点、非有限の点 | 重複または近接しすぎた点があります / 点が不正です |
| 幅・深さ・ばらつき・ゆらぎ・細かさが範囲外、または非有限 | それぞれの範囲を示す |
| 結果に内部が残らない | 割れ目を彫った結果に内部が残りません… |

## 制限

- **セル間隔より細い割れ目は格子で潰れる。** 幅 0.03 は解像度96で約3セル。ばらつきとゆらぎで細くなった部分は、消えるか、点々と途切れて見える。髪の毛ほどの線は形状ではなく、法線や Height の焼き込み（設計メモの 7）で表す領域になる。
- 割れ目は平面の組み合わせで、直線的に見える。崩すのは Volume Displace（設計メモの 4）の役割。
- 方向性のある平行な割れ目は Planes 入力で指定する。Points 入力は引き続き点の配置で決まる。
- 有限の割れ目（割れ目の長さ）は Planes 入力だけ。Points 入力と殻では使わない。
- 結果の距離値は、内外の符号は正しいが、距離としては近似になる（Volume Boolean と同じ）。
- 点数 N に対して格子点あたり 2N 回の計算を行う。512点・各軸192点の格子では重くなる。
- Parallel Planes 選択時は面の矩形ガイドを表示する。Points 入力の割れ目にはガイドは無い。
- 割れ目は深さまで彫られ、表面から見えない奥の壁まで格子に残る（メッシュの三角形が増える）。奥を埋めるには後ろに [Volume Close](volume-close.md) を置く。

## 検証

`tests/VolumeCrackTests.cpp`。2 m の立方体と2点（境界面は x = 0）で、浅い割れ目が形を分けずに全ての面から溝を彫ること、指定の深さより奥が残ること、V 字に狭まること、左右の対称、格子の不変、形を広げないこと、割れ目から離れた格子点が入力と完全に一致すること、深さ 1 で2つの塊に分かれること、幅 0 で入力と完全に同じになることを確認する。ほかに再現性と Seed、Dual Contouring、ばらつき・ゆらぎで彫る量が減ること、形の外の点、重なった立体で内部に空洞を作らないこと、不正設定と不正な点11種の拒否を確認する。グラフでは型制約、未接続の診断、キャッシュの再利用、点・設定の変更による作り直し、Volume 側の再利用を確認する。

## 表面に沿う殻（2026-10-01 追加）

割り方（`source`）を「表面に沿う殻」（`shells`）にすると、Points と Planes を使わずに、入力の形の表面に平行な殻で割る。花崗岩のシーティング・玉ねぎ状の風化・剥離ドーム（[岩の種類の網羅](rock-catalog.md) の G3）。Points・Planes を繋いだままだと診断する。

| 項目 | 保存名 | 内容 |
| --- | --- | --- |
| 殻の間隔 | `shellSpacing` | 板の厚さ。最長辺に対する比。0.01〜0.5、既定 0.05 |
| 殻の枚数 | `shellCount` | 表面から何枚目の殻まで。1〜32、既定 4 |
| 剥がれ | `shellPeel` | 一番外の板が剥がれ落ちている割合。0〜1、既定 0.5。内側の板ほど剥がれにくい（k 枚目は 0.6^(k−1) 倍）。まだらの大きさは「ゆらぎの細かさ」 |
| なめらかさ | `shellSmoothing` | 殻の形を表面の細かな凹凸からならす半径。最長辺に対する比。0〜0.3、既定 0.02 |

- 殻 k は、ならした距離場（箱ぼかし 3 回。格子の外は距離として延ばす）の深さが「間隔 × k」の面。殻に沿う割れ目は、他の割り方と同じ幅・深さ・ばらつきで彫る。
- **凸な形では殻は表面と平行で交わらないので、割れ目だけでは見えない**（最初の試作では、ならした殻を表面の凹凸に横切らせようとしたが、凸な形をぼかした場は元の場以上になり、殻は常に内側に閉じて空洞の埋め戻しで消えた）。見えるのは外側の板がまだらに剥がれ落ちた所。剥がれは、殻 k より外の点でノイズがしきい値より小さい所を外部にする。跡の底は殻 k、縁は段の壁になる。
- 平らな面では、剥がれた跡の底にボクセルの格子模様が出やすい。
- テストは `tests/VolumeCrackTests.cpp` の「表面に沿う殻」。レシピは `examples/ai-recipes/granite-sheeting.rockgraph`。

## 有限の割れ目（2026-10-01 追加）

Planes 入力の割れ目は、構造面を無限に延ばして彫るので、岩の端から端まで同じ溝が通る。板状節理や花崗岩の岩峰では、溝が格子に並んでレンガ積み・石積みに見えた。ゆらぎ（3D ノイズで幅を絞る）で途切れさせると、割れ目が点線のように細切れになる。実物の節理は、ある長さで先端が閉じて止まり、隣の割れ目は少しずれた位置から始まる（雁行・段違い）。

「割れ目の長さ」を正にすると、面ごとに次のように彫る。

1. 面の上の座標 (u, v)（法線に直交する 2 軸）を、一辺「長さ × 最長辺」のセルに分ける。
2. セルごとに、面番号・セル番号・Seed のハッシュで、割れ目を置くか（割れている割合）、楕円の中心（セルの中で ±0.3 セル）・半径（0.35〜0.75 セル、2 軸別々）・面内の向き・法線方向のずれ（段違い）を決める。
3. 楕円の内側で、開口を `幅 × sqrt(1 − r²)`（r は楕円の正規化半径）とする。中心で最も広く、縁で 0 になり、先端が閉じる。V 字の断面・割れ目ごとの幅のばらつき・ゆらぎは従来どおり掛ける。
4. 距離場へ `max(d, 開口 − |t − (面の位置 + ずれ)|)` を適用する（t は法線方向の位置）。楕円は隣のセルまでしか届かないので、3×3 のセルを見る。

ずれた割れ目が評価範囲の外の面から入ってくる分も、面を展開する範囲を広げて拾う。長さ 0 では従来と同じ計算で、既存のグラフの結果は変わらない（テストで値の一致を確かめている）。

保存名は `extent` / `coverage` / `stagger`。無ければ 0 / 0.6 / 0。

使用例: `granite-buttress`（主な節理 長さ 0.3・割合 0.55・段違い 0.8、横の節理は短く少なめ）、`platy-joints`（板の割れ目は長く途切れがち、縦の節理は短く段違い）。

### 検証（有限の割れ目）

`tests/VolumeCrackTests.cpp` の「有限の割れ目（Planes）」。2 m の立方体と 80° に傾いた 0.4 m 間隔の面で、長さ 0 では割合・段違いに関係なく従来の値と完全に一致すること、貫く深さでも無限の面ほど形が分かれないこと、彫る量が無限の面より少なく 0 ではないこと、閉じた表面（Dual Contouring も）、格子の不変、形を広げないこと、割合 0 で入力のまま、割合を上げると彫る量が増えること、再現性と Seed、段違いで結果が変わり閉じた表面を保つこと、長さで割れ目の大きさが変わること、範囲外・非有限の拒否を確かめる。
