# Volume Crack

作成日時: 2026-09-22 01:55
更新日時: 2026-09-22 01:55

## 位置付け

点の群が作る Voronoi の境界面に沿って、Volume の表面から割れ目を彫るノード。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 3 番目。サンプルは `examples/volume-crack/`。

```text
… → To Volume → Plane Cuts ───────────┐
                                       ├ Volume Crack → Plane Cuts（局所）→ Volume to Mesh → Mesh Output
Base Shape（囲む Box）→ Scatter Points ─┘
```

右クリックメニューの「ボリューム」にある。入力は Volume と Points、出力は Volume。格子（範囲・セル間隔）は入力のまま変わらない。

**Points の作り方**: Scatter Points は凸な Mesh を必要とする。割れ目を入れたい形が凸でないとき（直方体の塊など）は、形を囲む Base Shape の Box に Scatter Points をつなぐ。点は形の外にあってもよく、境界面が形を通るところだけが割れ目になる。

## 設定

| 項目 | 内容 |
| --- | --- |
| 幅 | 表面での割れ目の幅。形の最長辺に対する比。0〜0.2、既定 0.03 |
| 深さ | 割れ目が届く深さ。形の最長辺に対する比。0.01〜1、既定 0.15。1 で形を貫く |
| ばらつき | 割れ目ごとの幅の差。0 で全て同じ幅。1 では半分ほどの割れ目が閉じ、残りは 0〜1 倍に散らばる。既定 0.6 |
| ゆらぎ | 割れ目に沿った幅の変化。大きいほど途中で細くなり、途切れる。0〜1、既定 0.5 |
| ゆらぎの細かさ | 最長辺あたりのノイズの山の数。0.5〜16、既定 3 |
| Seed | ばらつきとゆらぎの乱数。割れ目の配置は変えない |

保存名は `volumeCrack`。保存・読込と Undo / Redo に対応。割れ目の配置は上流の Scatter Points（点数と Seed）で決まる。

## 処理

格子点ごとに最も近い点 i を求め、他の点 j との垂直二等分面までの距離 `(|p − s_j|² − |p − s_i|²) / (2 |s_j − s_i|)` を計算する。Voronoi のセルは凸なので、この距離の最小がセルの境界面までの厳密な距離になる。近似の F2 − F1 と違い、割れ目の幅が場所によって歪まない。

距離場へ `d = max(d, 半幅 − 境界面までの距離)` を適用する。半幅は次の積で決まる。

- **V 字の断面**: `1 + d / 深さ` を 0〜1 に収めた値。表面（と外側）で 1、指定の深さで 0 になる。深さの制限と断面の形を同じ式で扱う。
- **割れ目ごとの倍率**: 点の対 (i, j) から固定のハッシュで決める。対で決まるので、境界面のどちら側から見ても同じ幅になる。割れ目ごとに幅が違うため、距離の最小ではなく「半幅 − 距離」の最大を取る。
- **ゆらぎ**: 位置から求める 3D の値ノイズ。ゆらぎ 1 ではノイズの低い場所で幅が 0 になり、割れ目が途切れる。

最大の幅でも届かない格子点（形の外側の遠くと、深さより奥）は、境界面までの距離を求めずに入力の値を引き継ぐ。格子点ごとに独立した計算で、Z スライス単位で並列に処理する。設定・Volume 側・Points 側の上流が同じなら、ボリューム枝のキャッシュから再利用する。

### 内部の空洞の埋め戻し

重なった立体から作ったボリューム（Pieces to Mesh や Merge を To Volume へ入れた場合）は、内部に残る面の近くでも距離が小さい。そこは「表面の近く」と見なされて彫られ、外へつながらない空洞になる。彫ったあとで格子の外周から外部をたどり、届かない彫り跡は入力の値へ戻す。入力にもとからある空洞は残す。

Plane Cuts と違い、**浮いた塊は除かない。** 深さ 1 の割れ目で形を分けるのは意図した使い方である。

## 診断

| 状況 | 表示 |
| --- | --- |
| Volume か Points が未接続 | Volume と Points の両方を接続してください |
| 点が1個以下、または512個超 | 割れ目には2～512個の点が必要です |
| 重複した点、非有限の点 | 重複または近接しすぎた点があります / 点が不正です |
| 幅・深さ・ばらつき・ゆらぎ・細かさが範囲外、または非有限 | それぞれの範囲を示す |
| 結果に内部が残らない | 割れ目を彫った結果に内部が残りません… |

## 制限

- **セル間隔より細い割れ目は格子で潰れる。** 幅 0.03 は解像度96で約3セル。ばらつきとゆらぎで細くなった部分は、消えるか、点々と途切れて見える。髪の毛ほどの線は形状ではなく、法線や Height の焼き込み（設計メモの 7）で表す領域になる。
- 割れ目は平面の組み合わせで、直線的に見える。崩すのは Volume Displace（設計メモの 4）の役割。
- 方向性のある割れ目（Voronoi Fracture の回転・伸長にあたる設定）は無い。点の配置で決まる。
- 結果の距離値は、内外の符号は正しいが、距離としては近似になる（Volume Boolean と同じ）。
- 点数 N に対して格子点あたり 2N 回の計算を行う。512点・各軸192点の格子では重くなる。
- 割れ目の位置を画面で示すガイドは無い。

## 検証

`tests/VolumeCrackTests.cpp`。2 m の立方体と2点（境界面は x = 0）で、浅い割れ目が形を分けずに全ての面から溝を彫ること、指定の深さより奥が残ること、V 字に狭まること、左右の対称、格子の不変、形を広げないこと、割れ目から離れた格子点が入力と完全に一致すること、深さ 1 で2つの塊に分かれること、幅 0 で入力と完全に同じになることを確認する。ほかに再現性と Seed、Dual Contouring、ばらつき・ゆらぎで彫る量が減ること、形の外の点、重なった立体で内部に空洞を作らないこと、不正設定と不正な点11種の拒否を確認する。グラフでは型制約、未接続の診断、キャッシュの再利用、点・設定の変更による作り直し、Volume 側の再利用を確認する。
