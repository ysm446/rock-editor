# Volume Erode — 向きで削る量を変える侵食

作成日時: 2026-10-02 20:30
更新日時: 2026-10-02 22:10

## 位置付け

Volume の表面を、向き（風・波・氷が来る向き）や流れ（重力で斜面を流れ下る水の筋）で削る量を変えながら削るノード。[岩の種類の網羅](rock-catalog.md) の G5（流れ）。2026-10-02 追加。

Volume Smooth / Edge Wear の「集中する向き」は面を丸める・角を落とすだけで、面そのものは後退しない。このノードは面を後退させるので、風上の面がえぐれ、流れの筋に沿った溝が彫れる。

```text
… → To Volume → Volume Clip（接地）→ Volume Smooth → Volume Erode → Volume Undercut → … → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。格子は入力のまま。保存名は `volumeErode`。

## 設定

| 項目 | 保存名 | 内容 |
| --- | --- | --- |
| 種類 | `type` | `exposure`（さらされた面。既定）/ `flow`（流下） |
| 量 | `amount` | 削る深さの合計の最大（全ての回を足して）。最長辺に対する比。0〜0.3、既定 0.05 |
| 来る向き | `direction` | `exposure` 用。風・波・氷が来る向き（風上）。既定 [-1, 0, 0]。長さ 0 なら -X |
| 集中 | `sharpness` | 1 で向き（流れ）に広く効き、8 で正面（最も流れが集まる筋）だけ。1〜8、既定 2 |
| 陰の距離 | `shadow` | `exposure` 用。風上へこの距離の中に形があれば陰（風下）として削らない。最長辺に対する比。0 で陰を見ない。0〜1、既定 0.5 |
| 筋の長さ | `length` | `flow` 用。1 つの出発点から流れを追う長さ。最長辺に対する比。0.05〜1、既定 0.5 |
| 溝の幅 | `width` | `flow` 用。流れをぼかす幅（σ）。最長辺に対する比。0.005〜0.1、既定 0.02。セルより細いと溝にならない |
| 回数 | `iterations` | 削ってから向き（流れ）を取り直す回数。1〜8、既定 3。多いほど風上の面が後退して丸まり、流れが溝に集まる |
| ばらつき / ばらつきの細かさ | `noise` / `noiseScale` | 削る深さを場所でばらつかせる。0〜1 / 0.5〜16 |
| Seed | `seed` | |

## 処理

回数ぶん繰り返す。各回で「量 ÷ 回数」だけ削る。

1. **内部の距離を測り直す**（最初の回の前）。削った後の表面は入力の内部の「深さ = 削る量」の等値面になるので、重なった立体（Random Boxes）の内部の歪んだ距離をそのまま使うと、削った面に隠れた箱の面が迷路のような段として出る。
2. **重み**を格子点ごとに求める。向きは格子点ではなく最も近い表面の点 `p − d ∇d` で読む（格子点で読むと、深い格子点ほど表面と違う向きになり、削った面が段々になる）。
   - `exposure`: ぼかした場（σ = 最長辺の 2%）の法線と「来る向き」の内積を 0〜1 に写した値（正面 1、横向き 0.5、裏 0）の `集中` 乗。横向きの面と縁にも弱く効かせ、風下は陰で守るので、鼻先が最も後退し側面がゆっくり削れる。陰の距離が 0 より大きければ、表面の点から来る向きを中心に半頂角 50° の円錐へ 16 本のレイ（フィボナッチ格子）をスフィアトレーシングし、形に当たった割合だけ弱める（風上側の開放度。くぼみの中や風下は閉じていて削れない）。表面のすぐ近く（3 セル）の当たりは自分の面なので数えない。
   - `flow`: 表面に近い格子点を出発点に、重力の面に沿う成分の向きへ 0.75 セルずつ進み、表面へ戻しながら筋を追う。通った格子点に流れの量を積み、溝の幅でぼかす。ほぼ水平な面（溜まる）、張り出しの下面（水が離れる）、形の底（岩を離れる）で筋を終える。表面の格子点の流れの量の上位 5% を 1 として `集中` 乗。
   - ばらつき: 表面の点の値ノイズで `1 − ばらつき × (1 − n) × 2` を掛ける。
3. **重みをぼかす**（σ = 1.5 セル）。陰の判定やノイズが格子点ごとに飛ぶと削った面が段々になる。
4. **削る**: 表面から「1 回の深さ + 2 セル」までの格子点に `重み × 1 回の深さ` を足す。削る方向にだけ効き、形は広がらない。
5. **再距離化**（次の回がある場合）: 削った帯より内側の値は新しい表面より深いまま残るので、`RedistanceInterior` の両方向モードで測り直す。測り直さないと次の回の法線が帯の境で壊れ、ボクセルのゴミが出る（試作で確認）。
6. 最後に浮いた小片を捨て、閉じた空洞を埋める（[Plane Cuts と共通の規則](plane-cuts.md#浮いた小片の除去)）。

## 注意

- `exposure` は、平らな面は一様に後退し、角と縁は開けているので多めに丸まる（立方体で確認）。風上を向いた平らな面がくぼんで見えるときは、前段の Volume Smooth（向きに集中・大きな半径）が面の中央を皿状にしている。Smooth の半径が厚さの 1/3 を超えると起きるので、丸めは Erode に任せる。ヤルダンのような流線形（風上が鈍く風下へ細る）は、まだ楔のようになる程度。
- `flow` は流れが集まる所を広く削るので、Plane Cuts の平らな面がなまる。溝だけを彫るなら `集中` を 3 以上、量を小さく。
- 評価の時間: 解像度 128 で `exposure` 4 回が約 0.5 秒、`flow` 4 回が約 1 秒。
