# Volume Smooth

作成日時: 2026-09-22 19:05
更新日時: 2026-09-22 19:05

## 位置付け

Volume の表面をなまらせる（なめらか）か、角を立てる（シャープ）ノード。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 5 番目（Volume Smooth / Sharpen）。面の向きで量を変えられるので、「上面は風化で丸く、側面の割れ口は鋭いまま」という差を作れる。全体を一様に処理するとこの差が消える。サンプルは `examples/volume-smooth-terrace/`。

```text
… → Volume Noise → Volume Terrace → Volume Smooth（上向きに集中）→ Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。

## 設定

| 項目 | 内容 |
| --- | --- |
| モード | なめらか / シャープ。既定はなめらか。保存名 `smooth` / `sharpen` |
| 半径 | ぼかしの半径（ガウスの σ）。形の最長辺に対する比。0.005〜0.2、既定 0.03 |
| 量 | なめらかは入力とぼかしの混合比、シャープはぼかしとの差を足す強さ。0〜1、既定 1 |
| 上向きに集中 | 0 で全面に同じ量。1 で上（+Y）を向いた面だけに効き、垂直な面と下面には効かない。0〜1、既定 0 |

保存名は `volumeSmooth`。保存・読込と Undo / Redo に対応。

## 処理

1. **ぼかし**: 距離場に 3 軸の分離ガウスぼかしを掛ける。σ = 半径 × 最長辺、±3σ で打ち切る。**格子の外は、端の値に外へ出た距離を足して外挿する**（`SampleVolume` と同じ規約）。端の値で延長すると、外側の余白（2セル）で距離が頭打ちになり、ぼかしが面を外へ押し出してしまう（実装時にこれで形が膨らんだ）。
2. **合成**: 格子点ごとに重み `w = 量 × (1 − 集中 × (1 − 上向き度))` を求める。上向き度は入力の勾配（中心差分）から求めた外向き法線の +Y 成分を 0〜1 に丸めたもの。
   - なめらか: `d' = d + w × (ぼかし − d)`
   - シャープ: `d' = d + 2w × (d − ぼかし)`（アンシャープマスク）
3. 外周の1点は入力のまま（外周は空のまま）。浮いた小片は最大の塊だけ残し、加工でできた閉じた空洞は埋め戻す（他のボリュームノードと共通）。

なめらかは凸な角を削り、凹な隅を埋める。距離場の性質から、平らな面の中央は動かない。体積はわずかに減る（2 m の立方体に半径 0.05 で 8.0 → 約 7.6 m³）。シャープは丸めた角を戻す方向に動き、体積は減らない。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Volume 出力を接続してください |
| 半径・量・集中・モードが範囲外、または非有限 | それぞれの範囲を示す |
| 結果に内部が残らない | 処理した結果に内部が残りません… |

## 制限

- 半径がセル間隔の 0.3 倍未満だと、ぼかしは実質効かない（カーネルが1点になる）。
- 上向き度は入力の勾配で決めるので、σ が大きいと、上面の近くの側面にも少し効く。
- シャープはぼかしとの差を増幅するので、格子由来の階段の陰影も強くなる。量を控えめに使う。
- 結果の距離値は、内外の符号は正しいが、距離としては近似になる。

## 検証

`tests/VolumeSmoothTests.cpp`。量 0 で入力と完全に同じになること。なめらかで閉じた1つの塊になること、Dual Contouring、格子の不変、凸な角の値が増えて丸くなること、体積がわずかに減るだけなこと、面の中央が残ること、外周が入力のままなこと、再現性、量の混合比、半径による深さ。上向きの集中で上の角だけが丸くなり下の角が残ること。シャープで丸めた角が戻り体積が減らないこと。保存名の往復、不正設定6種と空入力の拒否。グラフでは型制約、未接続の診断、キャッシュの再利用と設定変更による作り直し、不正設定の診断を確認する。
