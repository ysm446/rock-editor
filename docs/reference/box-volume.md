# 直方体の塊とボリューム

作成日時: 2026-09-21 01:02
更新日時: 2026-10-03 01:25

## 使い方

グラフの右クリックメニューは扱う型ごとに「メッシュ（ポリゴン）」「ボリューム」「モデル」「共通」「材質」へ分かれている。見出しは出力する型で選び、変換ノードは変換後の型の側に置く（Volume to Mesh はメッシュ側）。

Random Boxes、To Volume、Volume to Mesh、Mesh Output を追加し、次の順でつなぐ。

```text
Random Boxes [Mesh] → [Mesh] To Volume [Volume]
  → [Volume] Volume to Mesh [Mesh] → [Geometry] Mesh Output
```

ボリュームのまま加工するノードは To Volume と Volume to Mesh の間に挟む。

```text
To Volume [Volume] → [Volume] Volume Transform [Volume] → [Volume] Volume to Mesh
```

Random Boxes の出力ピンをクリックすると変換前の直方体集合を見られる。To Volume の出力ピンでは変換後の表面を確認できる。Random Boxes を直接 Mesh Output へつないでも表示できる。

サンプルは [random-boxes.rockgraph](../../examples/random-boxes/random-boxes.rockgraph) と [volume-transform.rockgraph](../../examples/volume-transform/volume-transform.rockgraph)。アプリでそれぞれのフォルダをルートとして開き、そのシーンを開く。サンプル用の空アセットも同じフォルダに含む。

## Random Boxes

| 設定 | 範囲・意味 |
| --- | --- |
| 個数 | 1～32、既定8 |
| 基準寸法 X/Y/Z | 最初の直方体の辺長。0.1～100m、既定2/2.4/1.8 |
| サイズばらつき | 0～0.8。追加 Box の各辺は基準寸法の `(1 - ばらつき)`～1倍 |
| 配置の広がり | 0～0.95。最初の Box の各半辺に対する中心位置の範囲 |
| 回転幅 | 各軸に ±0～90度。0なら全ての軸が揃う |
| Seed | 同じ設定から同じ塊を再生成する |

追加 Box の中心は、回転を考慮した最初の Box の内部に置く。この段階では重なった直方体集合であり、内部面を除去した Boolean Mesh ではない。

## To Volume

Mesh入力を受け、負が内部、正が外部の距離グリッドへ変換する。Base Shape、Random Boxes、Pieces to Meshなどを接続できる。Random Boxes由来の直方体情報が残っている場合は従来の解析距離による高速経路を使用する。その他は三角形BVHによる最近距離と、向き付き走査線の交差数で内外を判定する。

閉じた向きの揃ったメッシュが必要。凹形状、貫通穴、離れた複数の立体を扱い、外向き立体の重なりは和集合、内向きの内殻は空洞として扱う。開いた面や逆向きの外殻は診断する。自己交差の修復は行わない。一般メッシュ入力は25万三角形・100万頂点まで。

**セルより細い閉じた隙間（泡）を埋める（2026-10-03）**: ずらした片の集合（Piece Transform の 0.01 m 程度のずれ）は、片の間にセルより細い隙間ができ、格子ではその中の数点だけが外部になって、閉じた微小な空洞として残る。置き換え前の `granite-buttress` では To Volume 直後に 1142 個（合計 0.011 m³）あり、Volume Close（幅 0.005）でも消えず、Volume Noise のあとで 14 個、最終形に 6 個残って「内側のゴミのポリゴン」に見えていた（ユーザー報告）。To Volume で、外周から届かない外部のうち 27 点以下の塊は解像度で表せない隙間として内部（−セル × 0.5）に戻す。大きな閉じた空洞（内向きの殻で作った洞）は残す。4 m の箱の中の 0.05 m の空洞が埋まり、2 m の空洞が残ることをテストする。

**隠れた接触面を距離の計算から外す（2026-10-03）**: 隙間なく接触する片の集合（Pieces to Mesh の分割片など）は、共有面の三角形が表裏で重なり、巻き数は相殺して内外には効かないが、三角形までの最近距離には効いてしまう。内側の値が接触面までの浅い距離になり、符号が切り替わる位置（線形補間）が外へずれて、接触面に沿った筋が表面に出ていた。再距離化は符号の切り替わる位置を信用するので直らない。To Volume では、各三角形の重心と頂点へ 2/3 寄った 3 点について、面の表裏に 1e-6（外接寸法比）だけ離れた点の巻き数を調べ、全部が内部なら「隠れた面」として最近距離の BVH から外す（内外の判定は全部の面で行う）。一部だけ隠れた面（隣が欠けて半分だけ露出）は残す。隙間なく接触させた 2 つの箱の距離場が一体の箱と 1% セル以内で一致することをテストする。副作用として、ずれの無い分割片の集合は継ぎ目が完全に消える。節理の線を見せたいときは Piece Transform のわずかなずれか Volume Crack で付ける。

**内部の距離の再距離化（2026-10-01）**: 重なった立体は、三角形までの距離が内部に埋もれた面までになり、Random Boxes の解析距離（箱の距離の最小）は重なった所で一つの箱の中での深さになる。どちらも内部の値が表面からの深さより浅く歪み、殻・割れ目の深さ・Undercut など内部の値を使う後段が内部の面に沿って崩れた（剥がれた跡の縞やえぐれ）。重なりがある入力（箱が 2 個以上、または走査線の巻き数が 2 以上のメッシュ）だけ、内部を測り直す（`RedistanceInterior`）。

1. 内外が切り替わる格子の辺の交点を、値の線形補間で表面の標本点にする（外側の値は正確なので交点もほぼ正確）。
2. Jump Flooding（幅を半分ずつにして、周りの 26 点が持つ最も近い標本点を引き継ぐ。最後に幅 1 をもう一度）で、格子点ごとに最も近い標本点を求める。
3. 内側だけ、標本点までの距離が元の値より深ければそれへ移す。表面の近くは標本点の間隔ぶん深めに出るので元の値を残し、1～3 セルの深さで少しずつ移す（判定で置き換えると隣の格子点で値が跳び、その面を通る殻の底が縞になった）。

外側の値と内外の符号は変えないので、表面の形は変わらない（後段の結果は内部の値の分だけ変わる）。重なりのない入力（Base Shape、単独の箱）は従来と同じ結果。手元とサンプルの 64 件で比べ、28 件は完全に同じ、ほかの多くは体積の差 1% 未満、閉じた空洞はサンプルの volume-edge-wear で 10 → 5、volume-smooth-terrace で 12 → 5 に減った。

To Volumeを含むグラフは非同期で評価し、設定と上流形状が同じならキャッシュを再利用する。

解像度は最長辺のセル数（16～128、既定48。2026-09-22 に 96 から引き上げ）。各軸共通のセル寸法で、周囲に2セル以上の空の余白を確保する。128 で最大約240万点、スカラー値は約9.6MB。表示用メッシュと作業メモリは別に必要。細い形・鋭い角は格子の解像度に応じて近似される。

## Volume Transform

Volume 型を受け、倍率 → 回転 → 平行移動の順に原点まわりで動かした Volume 型を返す。回転は右手系で Z → X → Y の順（Crack / Model と同じ規約）。

| 設定 | 範囲・意味 |
| --- | --- |
| 移動 | 各軸 -10000～10000 m |
| 回転 | 各軸 -360～360 度 |
| 倍率 | 0.05～20。全軸共通 |

格子を作り直して実装する。出力の各サンプル点を逆変換して入力の格子をトリリニア補間で読み、距離の単位を保つため倍率を掛け戻す。入力の範囲外は外周の正値に外へ出た距離を足して返すので、符号は外部のまま保たれる。

- セル間隔は倍率に比例させる。拡大・縮小しても格子の数は変わらず、解像度は保たれる。
- 範囲は入力の格子の8隅を変換した AABB に2セルの余白を足して決める。回転すると AABB が広がるためセル数が増える。内部格子は各軸256点まで許容し、To Volume の最大解像度128からの単一回転でも解像度を落とさない。変換を何度も重ねて上限を超えた場合は、変換をまとめるか上流の解像度を下げるよう診断する。距離配列の最大サイズは約64MiB（256³）で、メッシュ等のメモリは別途必要。
- 生成エラーはノード設定欄とビューポート下部に表示する。表示が消えた場合も、入力不足や格子上限などの理由を確認できる。
- 再サンプルのため、回転すると境界がセル1個ぶん程度なまる。軸に沿う90度単位の回転と平行移動でも、格子の位相がずれる分だけ再サンプルの誤差が出る。
- 変換後に内部が1点も残らない場合は診断する。非有限値・範囲外の設定は入力を変えずに拒否する。

このノードを選ぶと、ビューポートにギズモが出る（Model / Transform / Chunk と同じもの）。`W` 移動、`E` 回転、`R` 倍率で持ち替え、`Ctrl` を押しながらで刻み（移動は軸の目盛り、回転15度、倍率0.1）、ドラッグ中の `Esc` で掴む前へ戻す。ギズモの中心は移動量の位置で、回転と倍率もその点が中心になる（原点を移動量の位置へ写すため）。数値欄とギズモは同じ設定を編集し、1回のドラッグが Undo の1段になる。

ギズモは、表示中の岩がこのノードを通っているときだけ出す。設定を変えるたびに格子を作り直すので、ドラッグ中は毎フレーム上流から再評価する。解像度を上げると重くなる。

## Volume to Mesh

Volume 型を受け取り、ゼロ等値面を通常の Mesh 型へ変換する。「変換方式」で Marching Tetrahedra（既定・従来方式）と Dual Contouring を選択する。細かさは上流の To Volume の解像度で調整する。Mesh Output や Merge へ接続できる。

Marching Tetrahedra は各セルを共通の6四面体に分けてゼロ等値面を抽出する。交点は格子辺の ID で共有し、内外に合わせて面を外向きにする。グリッドの点と等値面がほぼ一致する場合はセル寸法の1e-4を許容幅として外側へ寄せる。

Dual Contouring は格子辺の交点とトリリニア補間の勾配から法線を推定し、セル内の頂点をQEF（交点の接平面からの距離の二乗和）で決める。セル内で分離した表面には別の頂点を置き、符号が変わる辺を囲むセルをつないで三角形化する。適応格子やメッシュ簡略化は行わない。詳細は [メッシュ変換方式](volume-meshing.md)。

両方式とも閉包と正の体積を確認する。内部空洞の壁は負の向きの表面成分として保持し、離れた複数の外皮も保持する。細い接続が格子解像度によって失われる場合がある。曖昧なセルの補間方法が違うため、セル程度の細い穴の接続や空洞の数が方式間で変わる場合がある。

旧シーンや設定がない場合は Marching Tetrahedra。保存はノード内の `volumeToMesh.method` に `marchingTetrahedra` または `dualContouring` を記録する。方式変更はメッシュのキャッシュだけを更新し、同じ上流SDFを再利用する。Undo/Redoで方式と形状が戻る。比較用の同一設定のシーンは [volume-meshing](../../examples/volume-meshing/README.md)。

表示の法線は、ビューポートの「表示」メニューで切り替える。既定は面法線（面ごとの陰影）で、**スムーズシェーディング（折れ角 40 度）**を入れると、隣り合う面の向きが40度以内で揃うところだけ法線を面積で重み付けして平均する。岩の割れ面の角は残したまま、格子由来の細かい段差の陰影だけがなだらかになる。形そのものは変わらないので、輪郭の段差は残る。法線は頂点に焼くため、切り替えるとメッシュを作り直す。設定はアプリの設定（`settings.json`）に残り、シーンには保存しない。

To Volume はグリッドを生成し、Volume to Mesh はメッシュを生成する。Volume を Mesh Output へ直接接続した場合や出力ピンを選んだ場合は、「プレビュー設定 → SDFプレビュー（共通）→ 変換方式」で外皮の抽出方式を選ぶ。既定は Marching Tetrahedra。この共通設定はアプリに保存し、内部グリッドやシーンの設定は変更しない。Volume to Mesh の出力はノード側の方式を使い、Volume/Boxes を持たない Mesh となる。ノード設定はシーンへ保存し、読込時にグリッドを再生成する。生成済みグリッドやメッシュをシーンに埋め込まない。

## 今回の範囲

- CPU 上の密なグリッドと表示用の外皮。新しい外部ライブラリは不要。
- 閉じたMeshを変換できる。Modelの直接変換、VDB、Sparse Grid、平滑化は未対応。
- Volume Transform は全軸共通の倍率のみ。VolumeGrid が単一のセル間隔を持つため、軸ごとの倍率は異方的なセル間隔の対応が要る。平面を境に片側だけずらす操作も未対応。
- Random BoxesはMesh型を出力する。VolumeはMeshと異なる型。Volume to Mesh を通して Mesh 入力へ接続する。Crack/Fracture には未加工 Box・三角形数などの入力制約があり、接続できても全ての加工に対応するわけではない。
- 単純な塊を編集する基盤として使う。今回の出力を参考写真のような岩の完成形とはしない。
