## 実行方針

[実装計画](../plan/plan.md) の各段階で、追加した実処理を呼ぶテストとビューポート確認を行う。P0～P4 では Debug ビルドと CTest、Release での Box・有限パッチ・軸に沿う部分切断・平面分割・Chunk 操作の表示と保存復元を確認した。詳細と未検証事項は [進捗](../plan/progress.md) を参照。

```powershell
cmake --preset x64
cmake --build --preset x64-debug
ctest --test-dir build -C Debug --output-on-failure
```

本リポジトリは C++ / CMake 構成で package.json はない。フロントエンド用 npm run build は使用しない。新規テスト用の一時データは既存 data/ の内容と衝突しない専用サブディレクトリに隔離する。

## 自動検証

| 対象 | 確認事項 |
| --- | --- |
| 母岩 | 有効な index、有限座標、非縮退面、法線、閉包、正の体積、指定寸法 |
| 平面交差 | 非交差、通常交差、頂点/辺を通る面、同一平面、向き反転、許容誤差付近 |
| 有限亀裂 | extent 外は不変、depth の上限、表面からの侵入、終端と taper、幅ゼロの扱い |
| Rock Bridge | 正の残存厚さ、1連結成分、閉じた表面。Bridge 消失時の状態更新 |
| 完全分割 | 2つの閉じた成分、切断面の向き、重複/穴なし。幅・ノイズなしなら分割前後の体積和が許容誤差内 |
| 複数節理 | 2～3系統の交差、極小片、接続対の重複なし、正しい親・世代 |
| 決定性 | 同じグラフ・seed・設定でメッシュ、ID、選択が一致。再読込とキャッシュ有無でも一致 |
| グラフ | 型不一致・循環を拒否、下流 dirty、未変更枝のキャッシュ、削除済み選択参照の診断 |
| 保存・Undo | 岩ノード設定、seed、Locked、選択、変換の往復。既存 Model / Surface も回帰確認 |
| OBJ | index、座標系、法線、出力範囲。別ビューアで読み直して形状確認 |

UV やハードエッジで描画頂点が分かれていても、それだけで別連結成分と判定しない。逆に同じ位置にある完全分離面を勝手に溶接しない。判定には形状トポロジーを使う。

## P3 の追加検証

- 単一切り込みの全三角形について、外向き法線側が固体の外、反対側が固体内であることを検証。亀裂壁と平らな終端があることを確認する。
- 全頂点の周囲の面が一つの環になることを検証し、辺の閉包だけでは検出できない接続異常を調べる。
- 160組の寸法・U 範囲・深さ、64組の90度回転、最小/最大寸法、薄い Bridge を検証。
- 部分切断後も上流 Box は不変。加工前/加工後を Merge しても別の結果として保持する。
- 幅ゼロ・非交差は無変更、Bridge 消失・斜めの入力・内部空洞・複数切断は診断する。
- 保存版の新しい applyCut/showBridge フィールドを往復確認。旧P2シーンは切断を有効にしない。

一般メッシュに対する自己交差検出は未実装。P3 は直交分割から境界を組み立てる制約により面の交差を避ける。任意角度・複数切り込みへ拡張するときは、この保証をそのまま流用しない。

## P4 の追加検証

- 160組の寸法・斜め平面、法線反転、頂点/辺上、最小/最大 Box、薄い片、非交差/接触、極小片、非有限入力、開いた入力を検証する。
- 両側の閉包・連結性・体積保存、中央断面の面積と逆向きの法線、描画データの有効性を確認する。
- 全幅と有限長の部分切断から分割し、残存断面のみが閉じることを確認する。穴のある断面は空の出力と診断にする。
- Chunk ID・親・Locked、片方だけの移動/回転、Merge の重複除去、再帰分割の診断、Undo/Redo を検証する。
- Release の組み込み `--test-drag` 入力でクリック選択、移動・回転ギズモ、Esc 取消、Locked 中の操作抑止を検証。保存 JSON で片方だけが変わったことを確認する。
- 実アプリの保存→再読込→再保存で Fracture / Crack / Base Rock の設定と接続が一致することを確認する。

選択中の片番号の保存と実マウスによる手動受入は未実施。一般メッシュの自己交差を検出・修復する保証はなく、複数断面/穴への対応は P5 以降に別途検証する。写真に近い外観は [外観目標](visual-target.md) の順で後続評価する。
