# 隣接面積によるピースの侵食

作成日時: 2026-09-26 06:25
更新日時: 2026-09-26 17:29

## 使い方

Voronoi Fracture の Pieces を Piece Select へ接続し、**外周から順に欠く**（Peel） にする。Selection を Piece Filter / Delete へ渡して取り除く。

普段の操作は **欠けの進行（0〜100%）・ばらつき・別の欠け方を試す** の3つ。進行を右へ動かすと同じ削除順の続きを選び、左へ戻すと以前の形に戻る。ばらつき0では面積比を優先し、同点はID順。「別の欠け方を試す」はSeedを1つ進める。進行操作ではSeedを変えない。自動再生は含まない。

Seed、中心保護、対象の側・層数・層番号、反転は「詳細設定」にまとめる。層別の集計も初期状態では折りたたむ。中心保護は、各板の側面隣接による連結部分で、露出面から最も遠い片を1つ残す。同距離なら体積、同体積ならIDで選ぶ。反転時は保護対象も選択する。

プレビューは欠ける片をオレンジのワイヤーフレーム、次の候補を黄色、その他をグレーで表示する。「削除後」で残る形を確認できる。サンプルは [progressive-peel.rockscene](../../examples/layered-pieces/progressive-peel.rockscene)。

## 支持の記録

同じ板の隣接は、Voronoiの切断面に残る共有面積と相手IDから記録する。重心間距離で推測せず、点・辺だけの接触は含めない。両側で対称な面積ベクトルを持つ。Layered Boxesでは元の板の上下面を侵食の入口から除き、側縁から始める。単体Meshでは元の外面全体を入口にする。

上下の支持は、隣り合う層の片の実際の上面・下面を共通平面に投影し、凸多角形の交差面積で記録する。外接矩形で重ならない組を除外する。片全体の投影ではないため、立体分割で板の上下面に届かない片を誤接続しない。層番号が連続する相手だけを扱い、欠けた層を飛び越えて接続しない。

Layered Boxesの表示上の隙間（gap）があっても、平面内の重なりを積層の支持として扱う。実際に接触しているかを解く物理計算ではない。板全体が同じ向きに傾いた配置にも対応する。

支持は分割時に一度計算してPiecesとともにキャッシュする。進行・ばらつきの変更では交差面積を再計算しない。座標は固定とし、後段で変換された入力には古い支持を使わず診断する。PeelをPiece Transformより前へ置く。

## 全層で1片ずつ欠ける順序

1. 側縁または削除された同じ板の隣に面で接する片を候補にする。
2. 上面と下面がともにほぼ全面（面積比1−1e−6以上）覆われている片は候補から外す。中間層は上下いずれかの支持が欠けるまで待つ。
3. `残る側面・上下の支持面積 /（元の側面の総面積 + 上下面の面積）` にSeedとIDから決まる固定のばらつきを加える。全層の候補で最も小さい片を1つ選ぶ。
4. 側面の隣を露出させ、上下の支持面積を減らす。全対象片数×進行（端数切り捨て）まで繰り返す。候補が尽きたら終了する。

全対象片数に対する割合であり、体積比ではない。層ごとの削除予算は設けない。同じ入力・Seed・その他の条件なら、進行を増やすと同じ削除順を延長する。中心保護や対象層の制限により100%でも残る片がある。上下の支持だけを失っても、側面の露出していない内部片を候補にはしない。

Piece Filterは消えた相手への支持記録も残す。後段のPeelでも失われた支持を反映する。中心保護は入力ごとに再計算するため、Filterを挟むと保護対象が変わる場合がある。

## 互換性と範囲

- 保存項目は既存のfraction・peelNoise・seed等を使う。旧Peelシーンも読めるが、新しい支持と全層共通の順序により結果は変わる。
- 旧PeelのrimFalloff（内側ほど弱く）は使わない。Rimでは従来どおり有効。Peelの対象層範囲は引き続き使える。
- 親をまたぐ再分割の接続は未対応。不完全な隣接情報を診断する。
- 残った全片の連結性、物理的な安定、空気が外部へつながるかは保証しない。
- 保存するのはノード設定。隣接グラフは入力から再生成する。
