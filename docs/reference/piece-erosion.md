# 隣接面積によるピースの侵食

作成日時: 2026-09-26 06:25
更新日時: 2026-09-26 06:25

## 使い方

Voronoi Fracture の Pieces を Piece Select へ接続し、選別方法を **Peel — 外周から侵食** にする。「外周から内側へ侵食」ボタンで初期設定を入れられる。Selection を Piece Filter / Delete へ渡して実際に取り除く。

- **削除量**：入力に残る各層のピース数に対する割合。体積比ではない。層ごとに端数を切り捨てる。
- **欠けのばらつき / Seed**：同じように支持された候補の削除順序を変える。0なら面積比を優先し、同点はピースID順。
- **中心の片を保護**：入力の各連結部分で、露出面から隣接グラフ上で最も遠い片を1つ保護する。同距離なら大きい片、同体積なら小さいIDを選ぶ。既定はオン。
- **積層の外側 / 外側から何層 / 内側ほど弱く**：Rim と同じ層範囲を使う。Peelでは層ごとの削除量を減衰させる。
- **対象の層 / 反転**：対象範囲の指定と反転。反転すると、保護した中心も選択側になる。

プレビューでは、選択された片をオレンジのワイヤーフレーム、削除後に露出している次の候補を黄色、内部・保護対象・範囲外をグレーで表示する。次の候補には、元から露出していてまだ削られていない片も含む。設定欄には、入力に残る隣接の組数、共有面積の合計、次の候補数も表示する。

サンプルは [progressive-peel.rockscene](../../examples/layered-pieces/progressive-peel.rockscene)。まず削除量を0から増やして変化を見る。

## 隣接情報

Voronoiの切断面に相手の母点IDを持たせ、切断後に残る面から隣接IDと面積ベクトルを記録する。重心間距離で接続を推測しない。点や辺だけの接触は含めない。両側の切断結果を照合し、共有面積が一致する対称なグラフにする。

面積ベクトルはローカル座標の単位法線に面積を掛けたもの。Pieceの変換の余因子行列で変換して、非均等倍率でも現在の共有面積を求める。分割の計算とともにキャッシュし、選択設定を変えるたびに接触面を再探索しない。

Layered Boxesからの分割では、同じ板の子ピースだけを接続する。上下面を侵食の入口から除き、側縁から始める。通常の単体MeshのVoronoi分割では、元の外面全体を入口にする。

## 削除順序

1. 元の外面、または既に削除された隣との面を持つ片を、露出した候補にする。
2. 候補ごとに、`残る隣との共有面積 /（元の露出面積 + 元の共有面積）` を求める。
3. 小さい比率を優先し、SeedとピースIDに基づく固定のばらつきを加える。保護対象は除外する。
4. 1片を選び、隣の支持面積を減らして露出候補へ追加する。層ごとの削除予算に達するまで繰り返す。

分母を削除のたびに変えないことで、失われた支持を保持する。同じ入力・Seedなら、削除量を増やすと各層の同じ順序を延長する。中心保護などで候補が尽きた場合は予算前でも止まる。

Piece Filterは消した隣への記録も残す。後段のPeelで欠落したIDとの面を露出面として扱える。中心保護の対象は各Peelの入力で再計算するため、Filterを挟むと保護する片は変わる場合がある。

## 初版の範囲

- 上下の板同士の接触・重なり面積による支持はまだ計算しない。外側の層の優先は層番号による指定を使う。
- 親ピースを再分割した場合、親をまたぐ新しい共有面の照合は未対応。Peelは不完全な隣接情報を診断し、誤ったグラフでは進めない。
- 接続する片を別々に移動・回転・拡大した後の接触判定は未対応。Peelを個別のPiece Transformより前に置く。同じ板の全片が同じ変換を持つ場合は面積変換に対応する。
- 中心保護は1片を残す機能であり、残った全片の連結性や物理的な安定を保証するものではない。途中のFilterで作った内部の空洞も侵食の入口になる。空気が外部へつながるかの判定は行わない。
- 保存するのはノード設定。隣接グラフと侵食順序は入力から再生成する。旧Rimの選択方法は維持する。
