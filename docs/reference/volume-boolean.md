# Volume Boolean

作成日時: 2026-09-22 00:35
更新日時: 2026-09-22 13:20

## 位置付け

2つの Volume の和・交差・差を取り、Volume を返すノード。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 1 番目で、平面で削る・割れ目を彫るといった後続の操作の土台になる。サンプルは `examples/volume-boolean/`。

```text
（A）… → To Volume ───────────────────┐
                                       ├ Volume Boolean → Volume to Mesh → Mesh Output
（B）… → To Volume → Volume Transform ─┘
```

右クリックメニューの「ボリューム」にある。入力ピンは A と B、どちらも Volume 型。Mesh は直接つなげないので、To Volume を通す。B の位置を変えるには、B の上流に Volume Transform を置く。

## 設定

| 項目 | 内容 |
| --- | --- |
| 演算 | 和 (A ∪ B) / 交差 (A ∩ B) / 差 (A − B)。既定は和。保存名は `union` / `intersection` / `difference` |
| なめらかさ (m) | つなぎ目を丸める幅。0 で角を残す。0〜10。スライダーは 2 まで、Ctrl + クリックでそれ以上を入力できる |

保存名は `volumeBoolean`。保存・読込と Undo / Redo に対応。不明な演算名は和として読む。

## 処理

- 距離場の演算は、和が `min(a, b)`、交差が `max(a, b)`、差が `max(a, -b)`。なめらかさ k が正のときは多項式のなめらかな最小値・最大値を使う（`h = max(k - |a - b|, 0) / k`、補正量は `h² k / 4`）。2つの距離の差が k 以上の場所は、k が 0 のときと同じ値になる。
- **結果は A の格子を引き継ぐ。** セル間隔は A と同じで、出力の格子点は A の格子点の上に置く。A の値は補間せずそのまま使うので、B の影響がない場所は A と完全に同じ値になる。B は三線形補間で読む。B の格子の外は、外周の正値に外へ出た距離を足して読む（Volume Transform と同じ規約）。
- 範囲は演算で変わる。和は B を含むところまで A の格子を延ばし、なめらかさの 1/4 ぶんの余白を足す（なめらかな和は外へ最大でその量ふくらむため）。交差は A と B の範囲が重なるところへ狭める。差は A の範囲のまま。
- 格子点ごとに独立した計算で、Z スライス単位で並列に処理する。設定と上流の内容が同じなら、ボリューム枝のキャッシュから再利用する。

## 診断

| 状況 | 表示 |
| --- | --- |
| A か B が未接続 | A と B の両方に Volume 出力を接続してください |
| 和の範囲が各軸256点を超える | 結果の格子が各軸256点の上限を超えます… |
| 交差で A と B の範囲が重ならない | A と B が重なっていません |
| 結果に内部が残らない（B が A を覆う差など） | 演算の結果に内部が残りません… |
| なめらかさが負・非有限・10 超 | なめらかさは 0～10 m にしてください |

差で B が A に触れない場合は、A をそのまま返す。

## 制限

- 結果の距離値は、内外の符号は正しいが、距離としては近似になる（`min` / `max` は真の距離場を返さない）。後続でオフセットや平滑化を行うノードを足すときは、距離の再計算（再初期化）が要る。
- 細部は A のセル間隔までしか残らない。B のほうが細かくても同じ。細かく彫りたいときは A の解像度を上げる。
- なめらかさ 0 のつなぎ目は、距離場の勾配が不連続になる線である。格子がこの線をまたぐので、Dual Contouring でも縁がセル程度にギザつくことがある。
- 入力は2つ。3つ以上の合成はノードを直列につなぐ。
- ビューポートのギズモは無い。B の配置は Volume Transform で行う。

## 検証

`tests/VolumeBooleanTests.cpp`。2 m の立方体と、+X へ 1 m ずらした 1 m の立方体で、和 8.5 / 交差 0.5 / 差 7.5 m³ の体積、外接範囲、格子の広がり方、A の値の完全一致、再現性、なめらかさによる体積の増減、幅の広いなめらかな和の閉包、離れた B（2成分の和、交差の診断、差は A のまま）、上限・不正設定の診断、保存名の往復を確認する。グラフでは接続の型制約、未接続の診断、キャッシュの再利用、設定と B 側上流の変更による作り直し、A 側の再利用を確認する。
