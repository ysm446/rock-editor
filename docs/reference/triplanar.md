# 生成メッシュへの材質とTriplanar

作成日時: 2026-09-21 17:38
更新日時: 2026-09-21 17:40

## 使い方

`Mesh Output` の `Geometry` に形状、`Material` に `Surface.Result` を接続する。Surfaceで既存のPBRマテリアルを選び、「マッピング → 方式」をTriplanarにする。材質未接続時は従来の単色・Chunk色分けを維持する。

| 設定 | 意味 |
| --- | --- |
| 方式 | UVは既存の頂点UV、Triplanarは位置と法線から3方向投影 |
| 反復サイズ | 1タイルの実寸。0.001〜10000 m。小さくすると模様が細かくなる |
| 位置 | 投影原点のワールド座標（m） |
| 回転 | 投影フレームのX/Y/Z回転（度）。Z → X → Y |
| 混合の鋭さ | 1〜16。大きいほど面の向きに近い投影を優先し、混合幅が狭くなる |

設定はSurfaceの`layer.mapping`に保存し、Undo/Redoで戻せる。同じSurfaceを複数のMesh Outputへ接続すると設定を共有する。別々の投影にはSurfaceを分ける。設定なし・未知の方式を持つ旧シーンはUVとして読む。旧Mesh OutputのGeometryピンIDは保持し、新しいMaterialピンだけ未接続で補う。

## 描画と境界

- 対象はRockEvaluatorで生成したメッシュ。Boxes/VolumeをMesh Outputへ直接つないだ場合の表示用メッシュにも適用する。モデルは既存のモデル側材質を使い、今回のMaterial入力では上書きしない。
- SurfaceはMesh Outputで適用するため、上流の出力ピンを直接プレビューすると、その上流形状は従来の単色で表示する。材質を見るときはMesh Output表示へ戻す。
- Base Color、Normal、Roughness、Metallic、AOを既存の合成器から読み、ラップサンプラーで3方向投影する。Normalは既存の緑反転設定を尊重する。
- 法線は各投影の右手系接線方向へ戻し、勾配として混ぜて元の面へ投影する。平坦な法線マップなら、混合の鋭さによらず元の面法線を維持する。投影回転は位置と法線の両方へ適用する。
- ワールド座標基準。物体を動かすと模様との位置関係が変わる。物体に追従するローカル座標・ピースごとの追従は未対応。
- Heightチャンネルの確認表示にも同じ投影を使う。Heightによる形状変位・バンプ生成、マスク抜き・半透明の生成岩への適用は今回の対象外。
- 生成岩のUVは三角形ごとの仮座標で、UV展開ではない。Triplanarは内部SDFやメッシュの頂点・面構成を変更しない。UV展開・ベイク・外部アプリへの材質再現は後続。
- 模様に方向性が強い場合、混合部で重なりが見えることがある。3方向のサンプルを使うためUVより描画負荷が増える。共通SDFプレビュー方式やスムーズシェーディングとは別の設定。

## 検証

- Debug/Releaseビルド、Release単体テスト、Debug CTest（1/1、52.99秒）が成功。実アプリでMeshPbrの頂点・ピクセルシェーダもコンパイル成功。
- 回帰テスト：MaterialとGeometryの型分離、材質を付けても形状不変、材質削除、材質変更時の上流SDF再利用、投影設定と接続のUndo/Redo、不正な投影サイズ・回転・混合値の拒否。
- Release実画面：色・ラフネス・AO・法線を持つ検証素材、正面と背面からの表示、UIのUV切り替え・保存。保存→再読込→再保存でグラフが一致し、対象メッシュ部分の画像も一致。
- 平坦法線マップと法線なしを比較し、8bit画像の中立値128による量子化差は最大2/255。波形法線では陰影が変わることを確認。
- 旧シーンでMaterialピンが未接続のまま補われ、形状が表示されることを確認。
