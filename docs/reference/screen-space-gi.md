# スクリーンスペース GI

作成日時: 2026-10-02 06:28
更新日時: 2026-10-02 06:28

ビューポートの表示専用の照り返し（1 回の反射）。画面内の光っている面から、近くの面へ光を足す。岩どうし・岩と土の間の照り返しで、日なたの面に向き合う陰の面が、その面の色でほんのり照らされる。テクスチャ・ベイク・岩アセットには焼き込まない（照り返しは周りの岩と照明で変わり、エンジンでは GI が受け持つ）。

ライティングの「スクリーンスペースGI」でオン・オフする。シーンの `preview.screenSpaceGi` に保存する。

| 設定 | 内容 |
| --- | --- |
| 有効 | 既定はオフ |
| 半径 | 照り返しを集める距離（m、0.01〜20、既定 1） |
| 強さ | 0〜4、既定 1 |

## 仕組み

1. 不透明のメッシュ（岩グラフの出力）を描くとき、2 枚目の描画先に「照り返しを受ける拡散の素材色」（拡散の割合 × ベースカラー × 素材の AO）を書く（`MeshPbr.hlsl` の `PsMainGi`）。モデル・空・ガイド線は書かない（照り返しを受けない）。
2. 後処理（`ScreenSpaceGi.hlsl`）で、画素ごとに半径の円盤から 32 点を拾う。深度から位置と法線を作り、受ける側から見て前にあり、こちらを向いている面の色を、受ける側の向き（余弦）と距離で重み付けして集める。受ける側の素材色を掛けて足す。背景（空）からは集めない（空の光は環境光が受け持つ）。
3. その後に SSAO を掛ける（照り返しも凹部で遮られる）。

円盤の向きは画素ごとに回し、固定のサンプルで縞やちらつきを抑える。

## 限界

- 画面内に映っている面からしか光を集めない。画面外・手前の物に隠れた面・カメラから見て裏の面からの照り返しは入らない。カメラを回すと照り返しが変わる。光がカメラの後ろから当たる構図では、照り返しの元（日なたの面）と受け手（陰の面）が同時に映りにくく、効きが弱い。
- 1 回の反射だけ。暗い岩どうし（ベースカラー 0.3 前後）の照り返しは物理的にも弱いので、見栄えのためには強さを上げる。
- 地面（グリッド）はメッシュではないので照り返さない。地面からの照り返しは、空の「下半球: 地面反射」が受け持つ。
