# Volume Noise

作成日時: 2026-09-22 02:25
更新日時: 2026-09-22 19:10

## 位置付け

Volume の表面をノイズで削り、サンプル位置をずらして直線的な面や割れ目を崩すノード。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 4 番目（Volume Displace / Noise）。Plane Cuts の平面と Volume Crack の割れ目は、そのままでは機械的に見える。このノードを後ろに置いて崩す。サンプルは `examples/volume-noise/`。

```text
… → Plane Cuts → Volume Crack → Plane Cuts（局所）→ Volume Noise → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。

## 設定

| 項目 | 内容 |
| --- | --- |
| 種類 | なめらか / セル状 / 小面。既定は小面。保存名 `smooth` / `cellular` / `facet` |
| 量 | 削る量の最大。形の最長辺に対する比。0〜0.2、既定 0.02 |
| 細かさ | 最長辺あたりのノイズの山の数。0.5〜64、既定 8 |
| 重ねる数 | 細かさを倍、量を半分にしながら重ねる数。1〜5、既定 2 |
| 歪み | サンプル位置をずらす量の最大。最長辺に対する比。0〜0.2、既定 0 |
| 歪みの細かさ | 0.5〜16、既定 2 |
| Seed | ノイズと歪みの乱数 |

保存名は `volumeNoise`。保存・読込と Undo / Redo に対応。

## 処理

格子点ごとに、まず歪み、次にノイズの順で適用する。

1. **歪み（domain warp）**: 位置 p の値を、`p + ずれ(p)` で入力を読んだ値に置き換える。ずれは3本の値ノイズ（−1〜1）に歪みの量を掛けたもの。形そのものがゆれるので、平面は波打ち、直線的な割れ目は曲がる。入力は三線形補間で読む（格子の外は Volume Transform と同じ規約）。
2. **ノイズ**: `d + 量 × ノイズ(0〜1)` を足す。**削る方向にだけ効き、形は広がらない。** 外周は空のまま保たれるので、ノイズだけなら格子は入力と同じになる。

種類は次の3つ。

- **なめらか**: 整数格子の値を滑らかに補間する値ノイズ。緩やかな起伏。
- **セル状**: 各セルに特徴点を1つ置き、最も近い特徴点までの距離を使う（Worley F1）。特徴点のまわりが盛り上がり、セルの境が谷になる。
- **小面**: 最も近い特徴点ごとにランダムな向きの平面を持たせ、その平面からの高さを使う。セルの中は平らな小面、セルの境は段差になり、割れ肌に近い。

### 格子

歪みが 0 なら格子は入力のまま。歪みがあると表面が外へも動くので、動く量（歪み × 1.75）とセル1個ぶんだけ、各軸の両側へ格子を広げる。各軸256点を超えると診断する。

### 計算を省く範囲

表面から「歪み × 1.75 + 量 + 2セル」より離れた格子点は、どう加工しても同じ側に残り、隣の点も同じ側にある。表面の抽出に関わらないので、入力の値をそのまま引き継ぐ。セル状・小面は1点あたり27セル × 重ねる数の計算を行うため、この省略が効く。

### 後始末

細かいノイズは、浮いた小片や閉じた空洞を作ることがある。最大の塊だけを残し（Plane Cuts と共通）、加工で新しくできた閉じた空洞は埋め戻す（Volume Crack と共通）。入力にもとからある空洞は残す。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Volume 出力を接続してください |
| 量・歪み・細かさ・重ねる数・種類が範囲外、または非有限 | それぞれの範囲を示す |
| 歪みで広げた格子が各軸256点を超える | 歪みで広げた格子が各軸256点の上限を超えます… |
| 結果に内部が残らない | ノイズで削った結果に内部が残りません… |

## 制限

- **セル間隔より細かい凹凸は格子で潰れる。** 細かさ 64 は解像度96でセル1.5個ぶんになり、形にならない。目安は「細かさ ≤ 解像度 ÷ 4」。それより細かい質感は、形状ではなく法線や Height（設計メモの 7）で表す領域になる。
- 歪みは格子を作り直すので、境界がセル1個ぶん程度なまる。Plane Cuts の鋭い稜線も少し丸くなる。
- 盛り上げる方向のノイズは無い（外周を空に保つため、削る方向に限っている）。
- 結果の距離値は、内外の符号は正しいが、距離としては近似になる。
- ノイズは位置だけで決まる。面の向きや曲率で量を変えること（上面だけ強く、など）はできない。面の向きで量を変えるのは [Volume Smooth](volume-smooth.md) が持つ。
- 段化（Terrace）は含めていない。独立したノード [Volume Terrace](volume-terrace.md) を使う。

## 検証

`tests/VolumeNoiseTests.cpp`。量も歪みも 0 で入力と完全に同じになること。3種類それぞれで、閉じた1つの塊になること、Dual Contouring、格子の不変、形を広げないこと、削る深さが量の最大を超えないこと、削る体積が量に見合うこと、再現性と Seed を確認する。ほかに重ねる数、最も細かく深い設定で小片と空洞を残さないこと、歪みが体積をほぼ保つこと、格子が広がること、表面が外へも動き設定の範囲に収まること、平らな面が波打つこと、格子の上限と不正設定9種の拒否、保存名の往復を確認する。グラフでは型制約、未接続の診断、キャッシュの再利用と設定変更による作り直しを確認する。
