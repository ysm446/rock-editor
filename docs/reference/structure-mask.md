# Structure Mask — 岩の構造から素材の模様を作る

作成日時: 2026-10-01 12:46
更新日時: 2026-10-01 12:46

## 位置付け

岩の構造から素材の模様のマスクを作るノード。片麻岩の縞・砂岩の色の層（縞）と、大理石・石英の脈（脈）。[岩の種類の網羅](rock-catalog.md) の G6。2026-10-01 追加。

```text
UV Unwrap ─┬─────────────→ Apply Material（下地）─→ Apply Material（縞の素材）─→ …
           └→ Structure Mask ──────────────────────↗ Mask
Parallel Planes ─→ Structure Mask の Planes（縞のとき。形の Volume Crack と同じノードに繋ぐと向きが揃う）
```

右クリックメニューの「マスク」にある。入力は UV 付きの Mesh と Planes（縞のとき）、出力は Mask。選ぶと入力のメッシュにマスクを白黒で貼って見せる（他の画像マスクと同じ）。保存名は `structureMask`。

## 設定

| 項目 | 保存名 | 内容 |
| --- | --- | --- |
| 種類 | `type` | 縞（`bands`）/ 脈（`veins`） |
| 塗る割合 | `fill` | 縞: 層のうち白にする割合。脈: 網目のうち残す割合（残りは途切れる）。0〜1、既定 0.4 |
| ぼかし | `softness` | 縞: 層の境のぼかし（間隔に対する比）。脈: 線の縁のぼかし（線の幅に対する比）。0〜1 |
| 網目の大きさ | `scale` | 脈: 網目 1 つの大きさ (m)。0.01〜100 |
| 線の幅 | `width` | 脈: 網目に対する比。0.005〜0.5 |
| ゆがみ / ゆがみの大きさ | `warp` / `warpScale` | 縞は間隔、脈は網目に対する比のゆがみ / ノイズの大きさ (m) |
| マスク解像度 | `resolution` | 128〜4096 の 2 のべき乗 |
| Seed / 反転 | `seed` / `invert` | 反転は使う側で掛ける（他の画像マスクと同じ） |

## 処理

Noise Mask と同じく、UV の画素ごとに表面の 3D 位置を求め、そこから値を作る（`SurfaceMask` に位置から値を返す関数を渡す）。

- **縞**: Planes の構造面を `ExpandParallelPlanes` で形の範囲に展開し（Volume Crack と同じ位置・ばらつき）、表面の点を挟む 2 枚の面の間を 1 つの層とする。層ごとに乱数で白か黒を決め（白の割合 = 塗る割合）、近い方の面の付近で隣の層となめらかにつなぐ。法線方向の位置をノイズでゆがめる。
- **脈**: 3D の Voronoi（セルに 1 点）の、最も近い点と 2 番目の点の距離の差を境界面までの距離として、線の幅より近い所を白にする。そのままでは閉じた多角形の網目（亀甲模様）になるので、大きめのノイズで網目の一部だけを残して途切れさせる。

## 注意

- 縞は、形の割れ目（Volume Crack の Planes）と同じ Parallel Planes を繋ぐと、割れ目と色の層の向きが揃う（`gneiss`）。
- 脈はまだ網目の感じが残る（枝分かれや太さの変化は未）。
- 擦痕のような細い溝は、色だけならこのノードの縞（細い間隔）で表せるが、凹凸（ハイト）にするには素材のハイトとして扱う必要がある（未）。
