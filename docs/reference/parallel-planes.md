# Parallel Planes — 平行な構造面

作成日時: 2026-09-26 05:13
更新日時: 2026-09-26 05:13

## 目的

母岩と独立に面の向き・間隔・位置を定義し、Volume Crack でその面に沿って割る。内部まで続く構造で板や岩塊の形を決める初版。旧 Joint Set は復活させない。

```text
Parallel Planes ──────────────────┐
                                 ↓ Planes
Base Shape → To Volume → Volume Crack → Volume to Mesh → Mesh Output
```

右クリックの「ボリューム」から追加する。入力なし、出力は専用の `Planes` 型。形状を生成するノードではないため、選択時も既存の Mesh Output を見ながら面を調整する。

## 設定

| 設定 | 内容 |
| --- | --- |
| 向き (度) | 回転した +Y が法線。0 は水平面。既存と同じ Z → X → Y の順 |
| 間隔 (m) | 0.001〜1000、既定0.4。母岩の寸法から独立した基準間隔 |
| 位置 (m) | 原点から法線方向への移動。±100000、既定0 |
| 間隔のばらつき | 0〜1。面を基準位置から間隔の±45%以内でずらす。隣の面との順序は保つ |
| Seed | 面番号に対応する乱数。ばらつき0では配置に影響しない |
| 平面を表示 | 選択時に緑の矩形ガイド。表示専用で保存・Undo対象外 |

面は無限平面で、矩形は表示中の岩の範囲から作る表示枠。岩がなければ原点周囲の2mを基準に表示する。枠は有限な剥離範囲を意味しない。

## 割り方

Volume Crack の Volume 入力に母岩、Planes 入力に Parallel Planes を接続する。Points は未接続にする。Points と Planes を両方接続すると診断を出す。

最初は Volume Crack の「ばらつき」「ゆらぎ」を0にして構造を確認する。深さ1で全体を割り、深さを小さくすると表面側だけを彫る。**浅くても面と外面が近ければ薄片が分離する。** 全ての面でつながりが残ることを保証する設定ではない。

別方向の Parallel Planes と Volume Crack を追加し、Volume Crack を直列につなぐと複数系統で割れる。二段目は一段目の加工面も表面として扱う。地質の形成順序を厳密にシミュレーションするものではない。

## 実装・互換性

- `StructurePlanes` は法線、間隔、位置、ばらつき、Seed を保持。`ExpandParallelPlanes` が評価範囲に必要な面だけを展開する。
- 面番号は原点基準の符号付き整数。母岩の範囲を変えても同じ面の位置と幅の乱数は変わらない。
- 面距離 `abs(dot(normal, p) - offset)` を使い、既存のV字断面・幅のばらつき・ゆらぎ・内部空洞の埋め戻しを共用する。幅0の面は距離を適用せず、格子上の偽の隙間を避ける。
- 分離した塊は保持する。格子の範囲・セル間隔は維持する。
- 保存名 `parallelPlanes`。設定・接続の保存/読込、既存スナップショットによるUndo/Redo、上流変更に応じたキャッシュ無効化に対応。
- Volume Crack の第1・第2入力と出力の並びを保ち、第3入力に Planes を追加。旧2入力シーンには未接続の第3入力を補完し、既存のIDとリンクを保つ。

## 制限と次の段階

- 1回の評価範囲は512面まで。超える場合は間隔を広げる診断を出す。
- セルより細い隙間や薄片は失われ得る。To Volume の解像度と割れ目の幅を合わせる。
- 斜めの細い稜線には格子・メッシュ抽出由来の段差が出ることがある。
- 面のうねり、有限範囲の局所剥離、層ごとの硬さや材質マスク、分離片の個別選択は未実装。
- Volume Terrace は既存シーンのため残す。次はこの構造面を使う局所剥離を試し、Terrace の役割を見直す。
