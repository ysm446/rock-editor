# Rock と Rock Scatter（岩を撒く）

作成日時: 2026-09-30 18:30
更新日時: 2026-10-03 09:05

## 位置付け

[岩アセットと山グラフ](rock-asset-mountain-graph.md) の M2。山グラフで、岩グラフの焼いた岩アセットを地形に撒く。

```text
Heightmap ─┬→ Mesh Output ← Material ← Surface          （地形）
           ├→ Shape Mask（上向き度・反転）──┐ Mask
           └──────────────────────────────┤ Terrain
[Rock: boulder.rockgraph] ─────────────────┤ Rock 1
[Rock: cliff.rockgraph] ───────────────────┤ Rock 2 …
                                           └→ Rock Scatter → Mesh Output （岩）
```

- 地形とマスクは今の Mesh と Mask（UV の画像）をそのまま使う（[山グラフと Heightmap](heightmap.md) の判断）。
- 撒いた結果は新しい型 **Instances** で、Mesh Output へつなぐと描く。地形は別の Mesh Output で出す（Rock Scatter は、それ自身を選んで見ているときだけ地形も一緒に出す。Mesh Output へ地形を通すと二重に描くため）。
- 大・中・小の階層は Rock Scatter を分けて撒き、それぞれ Mesh Output へつなぐ。設計資料の Instance Merge / Mountain Output は作っていない（複数の Mesh Output で足りるため。必要になったら足す）。

## Rock ノード

入力なし、出力は **Rock**（岩グラフへの参照）。

| 項目 | 内容 |
| --- | --- |
| 岩グラフ | 「岩グラフを選ぶ…」で `.rockgraph` を選ぶ。シーンからの相対パスで保存する |
| 倍率 | 岩アセットに掛ける（0.01〜10、既定 1） |
| 重み | Rock Scatter に複数の Rock をつないだとき、この岩を選ぶ割合（既定 1） |

- 岩グラフの付属フォルダ（`<岩グラフ>.bake/`、[Rock Asset](rock-asset.md) の「岩アセットを焼く」で作る）を読む。未焼成なら固定欄に「岩グラフを開いて「岩アセットを焼く」を押してください」と出す。
- 「読み直す」で読み直す（目録の更新時刻が変わっていれば、評価のときにも読み直す）。「岩グラフを開く」でその岩グラフへ切り替える。
- 選ぶと、原点に 1 つ置いて見せる。

## Rock Scatter ノード

入力は Terrain（Mesh）、Mask（任意）、Rock（可変本数。つなぐたびに空きが 1 本増える）。出力は **Instances** と **Coverage**（被覆マスク。2026-10-03 追加、下記）。

| 項目 | 内容 |
| --- | --- |
| 間隔 (m) | 岩どうしの最小の間隔（中心どうしの 3D の距離）。既定 6 |
| 上限の数 | 置く数の上限（1〜50000、既定 5000） |
| Seed | 配置の乱数 |
| 最小・最大の倍率 | 岩ごとの倍率の範囲（Rock の倍率に掛ける）。既定 0.8〜1.3 |
| 法線に合わせる | 0 で真上、1 で地形の面に垂直に立てる。既定 0.5 |
| 沈める量 | 岩の高さに対する比で地形へ沈める（0〜0.9、既定 0.15）。接地の継ぎ目を隠す |
| 大きさの間隔 (倍) | 2 つの岩の足元の半径（底の投影を包む円、倍率込み）の和にこの倍率を掛けた距離より近づけない。「間隔」との大きい方で判定する。0 で無効。既定 1（2026-10-03 追加） |
| 浮きの補正 | 底の 4 隅で地形の高さを読み、どの隅も浮かない深さまで追加で沈める強さ（0〜1、既定 1）。急斜面で谷側の底が浮くのを防ぐ（2026-10-03 追加） |
| 補正の上限 | 浮きの補正で追加で沈める量の上限。岩の高さに対する比（0〜0.9、既定 0.5） |
| 目標の被覆率 | 置いた岩の足元の面積の合計が地形の面積のこの割合に達したら止める（0〜1）。0 で無効（上限の数まで置く）（2026-10-03 追加） |
| 沈める量のばらつき | 岩ごとに沈める量を `沈める量 × (1 ± ばらつき)` で変える（0〜1、既定 0）。向きの乱数から派生させるので配置と向きは変わらない。土に埋まった破片と転がった破片が混ざる崖錐に（2026-10-03 追加） |
| 向き (度) / 向きのばらつき (度) | 上向きのまわりの向きの中心と、± の乱数の幅。ばらつき 180（既定）で全周の乱数（従来どおり。乱数の消費も同じなので配置は変わらない）。露岩の走向を全体でそろえるときに 10〜20 にする（M3 の 4 の「層の向き」。2026-10-03 追加） |

大きさの間隔・浮きの補正・被覆率は、焼いた岩アセットの目録（`asset.json` の `minimum` / `maximum`、LOD0 の範囲）から岩の大きさを読んで使う。未焼成の岩には効かない（間隔だけで判定し、沈める量は固定、被覆は 0）。

固定欄に「置いた岩の数」「推定の被覆率」と「描画の数（画面で小さく省いた数、段ごとの数）」を出す。保存名は `rock` / `rockScatter`。保存・読込と Undo / Redo に対応。評価は別スレッドで行う。

### 置き方（`geometry::ScatterRocks`）

1. 地形の面を面積に比例して選び、面の中の点を一様に選ぶ（候補）。候補の数は、間隔の円が表面を覆う数のおよそ 3 倍（上限 200 万）。
2. マスクがあれば、その点の UV でマスクを読み、値を置く確率にする（反転はマスクのノードの設定に従う）。
3. すでに置いた岩から間隔より近ければ捨てる（空間の格子で近傍だけを調べる、ダーツ投げのポアソンディスク）。
4. 向き（上向き = 真上と面の法線を「法線に合わせる」で混ぜる、上向きのまわりの回転は乱数）、倍率、どの岩か（重み）を決める。

同じ入力と Seed なら同じ配置になる。マスクを変えても、残った場所の岩の向きや大きさは変わらない（候補ごとの乱数の数を揃えている）。

### 大きさを考えた間隔と浮きの補正（2026-10-03 追加。M3 の 1）

- 候補ごとに向き・倍率・どの岩かを先に決め、その岩の足元の半径 r = ½√(幅² + 奥行き²) × 倍率（Rock の倍率込み）を求める。すでに置いた岩 q との距離が `max(間隔, (r + r_q) × 大きさの間隔)` より近ければ捨てる。近傍の格子の一辺は、いちばん大きい岩の 2r × 大きさの間隔と間隔の大きい方。
- 浮きの補正は、置く点・向き・倍率・沈める量から底の長方形の 4 隅をワールド座標で求め（描画の行列と同じ順: 底面の中心を原点 → 倍率 → 沈める → 上向きのまわりに回す → 上向きへ傾ける → 置く点へ）、各隅の XZ で地形の高さを読む（XZ の格子で面を引く。地形の外に出た隅は読まない）。最も浮いている隅の鉛直の浮きを `up.y` で割って上向きに沿う量にし、岩の高さに対する比にして、`浮きの補正` を掛け `補正の上限` で止めた分を沈める量へ足す。沈める量の合計は 0.95 まで。
- `geometry::RockFootprint` が足元の 4 隅を返す（被覆マスクとテストで共用）。

### 被覆マスク Coverage（2026-10-03 追加。M3 の 2）

- 置いた岩の足元（底の長方形）を地形の UV の画像に白で描いたマスク。解像度は地形の UV のアトラス寸法（Heightmap の「テクスチャ解像度」）。足元の隅の UV は、置く点の真下の面の重心座標を XZ で外挿して求める（格子の地形は局所的にアフィン）。
- Rock Scatter の評価結果は、Instances とともに地形（被覆マスクを `previewMask` に載せたもの）を持つ。Mesh Output / Merge は Rock Scatter から来た地形を捨てる（地形は別の Mesh Output で出す）。Rock Scatter を選んで見ているときは、地形に被覆マスクを貼って見せる。
- Coverage は Mask 型なので、次の段の Rock Scatter の Mask、Mask Filter、Mask Combine、Apply Material の Mask につなげる。「前の段の隙間にだけ撒く」は Mask Filter の反転を挟む。ぼかして広げれば「大岩の足元に小石を溜める」（崖錐）にも使える。Mask を受ける側の判定は `graph::IsMaskSourceNodeKind`（UV の画像のマスクのノードと Rock Scatter）。
- 目標の被覆率は、置くたびに足元の面積（幅 × 奥行き × 倍率²。重なりは数えない）を足し、地形の面積に対する割合が目標に達したら止める。マスクで撒く範囲を絞っても、割合は地形全体に対して測る。

## 描画

- 岩アセットを読み、段ごとの部品 1 つのモデル（`renderer::ModelAsset`）にする。材質は焼いたテクスチャ 4 枚からの一時の材質（シーンには保存しない）。LOD0 の UV を共有する段は直下のテクスチャ、UV を共有しない段はその段の `lodN/` のテクスチャを使う（テクスチャのフォルダごとにスロットを分け、スロットごとに材質を持たせる。2026-09-30）。
- `ModelPreview::PrepareAllLods` で全ての段の GPU メッシュを用意し、`RenderInstancedInScene` で**インスタンス描画**する。行列はフレームごとのアップロードバッファ（`CreateUploadStructuredBuffer`、SRV 付き）に段ごとにまとめて並べ、`ModelPreview.hlsl` の頂点シェーダが `SV_InstanceID` で読む。
- 段は毎フレーム、インスタンスごとに選ぶ。岩を包む球の直径が画面の高さに占める割合を求め、Rock Asset の「LODnの切替」と比べる（Rock Asset のビューポートと同じ基準）。0.002 より小さい岩は描かない。
- 本描画とシャドウパスで同じ段を使う。表示モード「LOD（色分け）」では段の色で塗る。
- 視錐台での省略はしていない（山一つの規模では、段と小さい岩の省略で足りている）。

## 制限

- 岩どうしの重なりは、中心の間隔と足元の半径（底の投影を包む円）で避ける。岩の形そのものは見ない。「避ける」入力は作らず、Coverage を Mask につなぐ経路で表す。
- 被覆マスクの足元は底の長方形で近似する（楕円や輪郭ではない）。張り出した上部や傾けた岩の影は入らない。
- 浮きの補正は底の 4 隅だけを読む。縁の中央が尾根に乗って浮く形は補正しない。地形が高さ場でない（庇や洞）場合は最も高い面を読む。
- 傾き（Tilt）の上限・倍率と縦横比の分離、傾斜と曲率での岩の選び分けは未実装（M3 の 3・4 の残り）。向き（Yaw）をそろえるのは 2026-10-03 に実装した。
- 被覆マスクを距離で広げるには Mask Filter の「広げる」（2026-10-03 追加）を使う。`examples/nasu-asahidake/` では刃の足元を 6 m 広げて崖錐の範囲にしている。
- 同じ岩グラフを倍率違いの Rock で複数つないだときは、岩グラフごとに 1 組にまとめ、Rock の倍率をインスタンスの倍率に畳む（組の倍率は 1。2026-10-03）。
- 置く点は地形の上に限る。岩の上に岩を乗せる・寄りかからせることはできない。
- 岩アセットの変種（Seed 違い）は無い（A3）。岩グラフを分けて Rock を増やす。
- 置いたインスタンスを手で動かす・消すことはできない。
- 岩アセットを焼き直したら、山グラフでは「読み直す」を押すか、グラフを編集すると読み直す（目録の更新時刻で判定）。

## 検証

`tests/RockScatterTests.cpp`。平らな地形で間隔の保証、地形の上・上向き・倍率の範囲、再現性、上限、マスクと反転、重み（0 は選ばない）、重みの合計 0 の診断、沈める量、グラフ（ピン、Rock の空きが増える、Mesh Output へつながる、Rock は直接つながらない、岩グラフごとのまとめ、選んだときの地形と Rock の 1 つ置き、未選択の診断）を確認する。2026-10-03 に追加: 大きさの間隔（半径の和、大小の混在、範囲の無い岩、無効化、足元の 4 隅の位置と回転・沈み）、浮きの補正（平らでは変えない、45° の斜面で谷側の隅が浮かない、上限、無効化、補正後の隅が地形から浮かない）、被覆（被覆率の値、マスクの寸法と白の割合、中心が白、目標で止まる、範囲の無い岩では止まらない、UV の無い地形の診断）、グラフ（Coverage ピン、Mesh Output へはつなげない、選択時の被覆マスク、Mask Filter の反転を通した 2 段目、未焼成の黒い被覆、焼いた目録の範囲の読み取りと白い足元）。

実アプリ（RelWithDebInfo）では、2 つの岩グラフを焼き、傾斜のマスクで 365 個を撒いた山を確認した。描画は 8 ドローコール・120 FPS。遠景（330 m）は全て LOD3、中景では LOD1〜3 が距離で混ざり、近くは LOD0 になることを「LOD（色分け）」で確認した。`examples/mountain/` でも、`boulder.rockgraph` を焼いてから山グラフを開くと岩が撒かれることを確認した（`build/rock-asset-validation/`）。「岩グラフを選ぶ…」のダイアログと、Rock Scatter の設定を変える操作は実マウスで未確認。
