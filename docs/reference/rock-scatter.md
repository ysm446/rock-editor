# Rock と Rock Scatter（岩を撒く）

作成日時: 2026-09-30 18:30
更新日時: 2026-09-30 18:30

## 位置付け

[岩アセットと山グラフ](rock-asset-mountain-graph.md) の M2。山グラフで、岩グラフの焼いた岩アセットを地形に撒く。

```text
Heightmap ─┬→ Mesh Output ← Material ← Surface          （地形）
           ├→ Shape Mask（上向き度・反転）──┐ Mask
           └──────────────────────────────┤ Terrain
[Rock: boulder.rockscene] ─────────────────┤ Rock 1
[Rock: cliff.rockscene] ───────────────────┤ Rock 2 …
                                           └→ Rock Scatter → Mesh Output （岩）
```

- 地形とマスクは今の Mesh と Mask（UV の画像）をそのまま使う（[山グラフと Heightmap](heightmap.md) の判断）。
- 撒いた結果は新しい型 **Instances** で、Mesh Output へつなぐと描く。地形は別の Mesh Output で出す（Rock Scatter は、それ自身を選んで見ているときだけ地形も一緒に出す。Mesh Output へ地形を通すと二重に描くため）。
- 大・中・小の階層は Rock Scatter を分けて撒き、それぞれ Mesh Output へつなぐ。設計資料の Instance Merge / Mountain Output は作っていない（複数の Mesh Output で足りるため。必要になったら足す）。

## Rock ノード

入力なし、出力は **Rock**（岩グラフへの参照）。

| 項目 | 内容 |
| --- | --- |
| 岩グラフ | 「岩グラフを選ぶ…」で `.rockscene` を選ぶ。シーンからの相対パスで保存する |
| 倍率 | 岩アセットに掛ける（0.01〜10、既定 1） |
| 重み | Rock Scatter に複数の Rock をつないだとき、この岩を選ぶ割合（既定 1） |

- 岩グラフの付属フォルダ（`<岩グラフ>.bake/`、[Rock Asset](rock-asset.md) の「岩アセットを焼く」で作る）を読む。未焼成なら固定欄に「岩グラフを開いて「岩アセットを焼く」を押してください」と出す。
- 「読み直す」で読み直す（目録の更新時刻が変わっていれば、評価のときにも読み直す）。「岩グラフを開く」でその岩グラフへ切り替える。
- 選ぶと、原点に 1 つ置いて見せる。

## Rock Scatter ノード

入力は Terrain（Mesh）、Mask（任意）、Rock（可変本数。つなぐたびに空きが 1 本増える）。出力は **Instances**。

| 項目 | 内容 |
| --- | --- |
| 間隔 (m) | 岩どうしの最小の間隔（中心どうしの 3D の距離）。既定 6 |
| 上限の数 | 置く数の上限（1〜50000、既定 5000） |
| Seed | 配置の乱数 |
| 最小・最大の倍率 | 岩ごとの倍率の範囲（Rock の倍率に掛ける）。既定 0.8〜1.3 |
| 法線に合わせる | 0 で真上、1 で地形の面に垂直に立てる。既定 0.5 |
| 沈める量 | 岩の高さに対する比で地形へ沈める（0〜0.9、既定 0.15）。接地の継ぎ目を隠す |

固定欄に「置いた岩の数」と「描画の数（画面で小さく省いた数、段ごとの数）」を出す。保存名は `rock` / `rockScatter`。保存・読込と Undo / Redo に対応。評価は別スレッドで行う。

### 置き方（`geometry::ScatterRocks`）

1. 地形の面を面積に比例して選び、面の中の点を一様に選ぶ（候補）。候補の数は、間隔の円が表面を覆う数のおよそ 3 倍（上限 200 万）。
2. マスクがあれば、その点の UV でマスクを読み、値を置く確率にする（反転はマスクのノードの設定に従う）。
3. すでに置いた岩から間隔より近ければ捨てる（空間の格子で近傍だけを調べる、ダーツ投げのポアソンディスク）。
4. 向き（上向き = 真上と面の法線を「法線に合わせる」で混ぜる、上向きのまわりの回転は乱数）、倍率、どの岩か（重み）を決める。

同じ入力と Seed なら同じ配置になる。マスクを変えても、残った場所の岩の向きや大きさは変わらない（候補ごとの乱数の数を揃えている）。

## 描画

- 岩アセットを読み、段ごとの部品 1 つのモデル（`renderer::ModelAsset`）にする。材質は焼いたテクスチャ 4 枚からの一時の材質（シーンには保存しない）。
- `ModelPreview::PrepareAllLods` で全ての段の GPU メッシュを用意し、`RenderInstancedInScene` で**インスタンス描画**する。行列はフレームごとのアップロードバッファ（`CreateUploadStructuredBuffer`、SRV 付き）に段ごとにまとめて並べ、`ModelPreview.hlsl` の頂点シェーダが `SV_InstanceID` で読む。
- 段は毎フレーム、インスタンスごとに選ぶ。岩を包む球の直径が画面の高さに占める割合を求め、Rock Asset の「LODnの切替」と比べる（Rock Asset のビューポートと同じ基準）。0.002 より小さい岩は描かない。
- 本描画とシャドウパスで同じ段を使う。表示モード「LOD（色分け）」では段の色で塗る。
- 視錐台での省略はしていない（山一つの規模では、段と小さい岩の省略で足りている）。

## 制限

- 岩どうしの重なりは、中心の間隔だけで避ける（大きな岩と小さな岩の形は見ない）。大きさの違う岩は Rock Scatter を分ける。「避ける」入力（前の Scatter の結果を避ける）は未実装。
- 層の向き（地層に合わせて傾きを揃える）、傾斜と曲率での岩の選び分けは未実装（M3）。
- 岩アセットの変種（Seed 違い）は無い（A3）。岩グラフを分けて Rock を増やす。
- 置いたインスタンスを手で動かす・消すことはできない。
- 岩アセットを焼き直したら、山グラフでは「読み直す」を押すか、グラフを編集すると読み直す（目録の更新時刻で判定）。

## 検証

`tests/RockScatterTests.cpp`。平らな地形で間隔の保証、地形の上・上向き・倍率の範囲、再現性、上限、マスクと反転、重み（0 は選ばない）、重みの合計 0 の診断、沈める量、グラフ（ピン、Rock の空きが増える、Mesh Output へつながる、Rock は直接つながらない、岩グラフごとのまとめ、選んだときの地形と Rock の 1 つ置き、未選択の診断）を確認する。

実アプリ（RelWithDebInfo）では、2 つの岩グラフを焼き、傾斜のマスクで 365 個を撒いた山を確認した。描画は 8 ドローコール・120 FPS。遠景（330 m）は全て LOD3、中景では LOD1〜3 が距離で混ざり、近くは LOD0 になることを「LOD（色分け）」で確認した。`examples/mountain/` でも、`boulder.rockscene` を焼いてから山グラフを開くと岩が撒かれることを確認した（`build/rock-asset-validation/`）。「岩グラフを選ぶ…」のダイアログと、Rock Scatter の設定を変える操作は実マウスで未確認。
