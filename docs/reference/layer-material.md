# 岩用レイヤーマテリアル

作成日時: 2026-09-26 18:43
更新日時: 2026-09-26 20:02

## 操作

アセット欄の余白を右クリックし「レイヤーマテリアルを作成」を選ぶ。マテリアルプレビューの窓は左右に分かれ、左にプレビューと表示の設定、右に層一覧と選んだ層の設定を置く（スクロールは右だけ、境界はドラッグで移動）。右の層一覧から編集する層を選ぶ。下地を含め最大4層。各層は通常のPBRマテリアルか単色を使い、表示切替・追加・削除ができる。

一覧はterrain-graphと同じく上の行が上の層で、一番下が下地。各行は目のアイコン（表示切替）、素材のサムネイル（単色なら色）、見える範囲の白黒画像、名前の順。白黒画像は合成後にその層が見えている割合で、被覆のマスクだけでなく、高さ合成と上の層による隠れも含む。範囲はサムネイルと同じ素材座標0〜1。各層64²を4枚並べた画像をサムネイルと一緒にGPUで作り直す。

行をドラッグして並べ替える。被覆の無い層（元の下地など）を上へ動かしたときは、消えないよう全面を覆う均一の被覆を付ける。マテリアル一覧から行へ素材をドロップすると、その層へ割り当てる（レイヤーマテリアルは受けない）。

選んだ層の設定では、被覆方式・被覆量の次に「合成（通常／高さ）」を置く。高さを選ぶと「境界の幅」（全層共通のlayerBlendRange）を出す。新しく追加する層の既定は高さで合成。下地の高さによる条件は「詳細」に残す。

マテリアルプレビューは「形（球／平面）」「タイル」「大きさ (m)」「変位 (m)」を持つ（どれも表示設定で保存しない）。変位が0より大きいと、合成後のハイトを形の座標へ1024²で焼き、ハイトフィールドをレイマーチして輪郭・太陽の影まで凸凹させる。平面は上の面だけを描き、側面と底面は描かない（外から面へ入った所だけを当たりにする）。変位はハイト0〜1の差の高さで、0.5が元の面。普通のPBRマテリアルはハイトマップを使う。ノードの計算やビューポートとは切り離した、プレビューの中だけの表示。

プレビューでL＋左ドラッグすると、プレビュー専用の光源の方位角・仰角を変える（ビューポートと同じ感度とギズモ）。一度も動かしていなければシーンの太陽の向きに従い、強さと色は常にシーンに合わせる。「光源を戻す」でシーンの太陽の向きへ戻す。設定は保存しない。

上層の被覆方式は「均一」「ムラ」。被覆量、ムラのサイズ、しきい値、ぼかし、Seed、反転を調整する。詳細には高さ合成と、下地の高い部分／低い部分への条件を置く。診断欄は常に1行分を確保する。処理状況で設定の位置を変えない。

作ったアセットはSurfaceのマテリアル欄へ指定し、Apply Materialで岩に適用する。通常のPBR素材と同じように、球・アセットのサムネイル・メッシュ・ベイクに合成結果を表示する。Displaceは各素材の高さマップを同じ被覆で合成して使う。

## 保存と再利用

`.tglayer`は共有アセット。各層が参照する通常素材は`.rockmat`の永続IDで保存する。素材のファイル名を変更しても参照を追跡する。シーンを開く時は依存素材も読み込む。保存表で合成素材が通常素材より前にあっても解決する。編集内容はUndo / Redoの対象。

素材選択は通常のPBR素材に限り、レイヤーマテリアルの入れ子は受け入れない。`.rockmat`単体書き出しには依存素材を収録できないため、合成素材ではそのメニューを表示しない。持ち運ぶ場合は`.tglayer`と参照する素材・画像を含むルートを使う。

## 岩向けの変更と範囲

`terrain-graph`のLayerMaterial、SurfacePresetGraph、LayerMaterialIo、GPU素材評価を基に移植した。合成は層順を尊重し、被覆0は下の結果を保ち、均一の被覆1は上の素材に一致する。ムラは素材タイルの境界でつながる2Dノイズ。

道路幅・道路端・轍・車線・道路沿いの座標設定は移植しない。旧内部グラフは検証後に非表示層も保持して編集用のリストへ変換する。旧道路マスクは無効として扱う。terrain-graphのプロジェクト全体を読み込む互換機能ではない。

内部マスクは素材座標に従う。岩の3D位置に応じた大きな汚れや色ムラは、既存のNoise MaskをApply MaterialのMaskへ接続して扱う。Shape Maskの傾斜・高さなども同じ経路を使う。合成素材内へメッシュ依存のマスクを保存する仕組みは含めない。

## 検証

JSON往復、不正値・道路マスク・過剰な層の拒否、非表示層の保持、Undo / Redo、依存素材の展開、UID改名追跡、シーン保存後の再読込、入れ子拒否を単体テストで確認する。

実アプリでも保存・再読込と球／サムネイル／岩への表示を確認。描画画像の比較で被覆0・被覆1の一致、同じSeedの再現性、Seed変更による差を確認した。サンプルは`examples/layer-material/`。
