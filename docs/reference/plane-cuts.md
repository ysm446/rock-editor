# Plane Cuts

作成日時: 2026-09-22 01:20
更新日時: 2026-09-22 17:20

## 位置付け

平面の群で Volume を切り落とし、割れた岩のような角張った面（ファセット）を作るノード。[岩らしい形のためのノード設計メモ](rock-shaping-nodes.md) の 2 番目。サンプルは `examples/plane-cuts/`。

```text
… → To Volume → Plane Cuts（全体・少数）→ Plane Cuts（局所・多数）→ Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型で、格子（範囲・セル間隔）は入力のまま変わらない。稜線を残すには、Volume to Mesh の変換方式を Dual Contouring にする。

## 設定

| 項目 | 内容 |
| --- | --- |
| 枚数 | 1〜256。既定 12 |
| Seed | 平面の向き・深さ・欠けの位置を決める。同じ入力と Seed から同じ結果を得る |
| 適用範囲 | 全体 / 局所。既定は全体。保存名 `global` / `local` |
| 半径 | 局所のみ。欠け1つが届く範囲。形の最長辺に対する比。0.02〜1、既定 0.2 |
| 深さ 最小・最大 | 0〜0.45。全体では平面の向きに測った形の幅に対する比、局所では欠けの半径に対する比 |
| 法線の分布 | 等方 / 主方向。保存名 `isotropic` / `directional` |
| 系統数・向き・ばらつき | 主方向のみ。向き（度、右手系 Z → X → Y）で回した座標系の X / Y / Z 軸を、系統数（1〜3）だけ主方向に使う。ばらつき（0〜90度）は主方向まわりの円錐の開き |
| なめらかさ (m) | 稜線を丸める幅。0 で角を残す。0〜10 |

保存名は `planeCuts`。保存・読込と Undo / Redo に対応。寸法や解像度を変えても見た目が保たれるよう、長さの設定は比で持つ（なめらかさだけは m）。

## 処理

距離場へ `d = max(d, 平面までの距離)` を枚数分適用する。なめらかさが正なら、Volume Boolean と同じ多項式のなめらかな最大値を使う。格子点ごとに独立した計算で、Z スライス単位で並列に処理する。設定と上流が同じならボリューム枝のキャッシュから再利用する。

形の幅と表面の点は、「隣に外部の点を持つ内部の格子点」から求める。距離の小ささでは選ばない。重なった立体から作ったボリュームは、内部に残る面の近くでも距離が小さく、距離で選ぶと形の内側を拾ってしまう。

乱数は固定の数列（splitmix64）で、平面1枚あたり同じ個数を使う。枚数を増やしても既存の平面は変わらず、設定を切り替えても他の平面の乱数はずれない。

### 全体

形全体を半空間で切る。平面は、その法線方向の形の端から「深さ × 幅」だけ内側に置く。

**枚数を増やすほど凸な形に近づき、凹みが消える。** 半空間の共通部分は凸なので、これは方式の性質である。3〜8枚ほどの大きな面取りに使う。主方向にすると、節理に沿って割れたような向きの揃った面になる。

### 局所

表面の点を中心とする球の中だけを切る（`d = max(d, min(平面, 半径 − 中心からの距離))`）。凹凸を残したまま小面を増やせる。見た目を保つため、次の選び方をする。

- **中心は凸な場所から選ぶ。** 26近傍にある外部の点の数で凸さを測り（平面で約9、稜線で約15、角で約19）、13以上の点を候補にする。凸な点が無い形では表面全体から選ぶ。
- **法線は表面の外向きへ寄せる。** 等方では、外向きの法線にランダムな向きを 0.75 の割合で混ぜる（傾きは最大で約50度）。主方向では外を向く側へ反転し、それでも表面と合わない（余弦 0.35 未満）ときは最も合う系統の軸を使う。表面に対して急な平面は、浅い欠けにならず半径いっぱいまで食い込むため。
- **丸い壁が残る欠けは使わない。** 切り取る材料が球の縁に多く掛かると、球の壁が丸いくぼみとして残る。縁（幅1.5セル）に掛かる割合を半径で正規化した値は、平らな面のくぼみで約2、稜線の面取りで約1、角の欠けで約0になる。1.3 以下だけを採用し、超える欠けは深さを半分にして最大4回試す。それでも超えるものは捨てる。**このため、実際に使われる枚数は設定より少なくなる。** 滑らかな球ではほとんどが捨てられる。

### 浮いた小片の除去

重なった切り落としが角を切り離すと、浮いた小片ができる。内部の格子点を6近傍でつないだ塊のうち、最大のものだけを残す。全体・局所の両方で行う。

## 表示（平面の枠）

Plane Cuts を選んでいる間、そのノードで使った平面の枠をビューポートに深度付きの線で重ねる。設定欄の末尾「表示」の「平面を表示」でオン/オフする（既定オン）。この切り替えは表示用の状態で、ノードの設定・保存・Undo には含めない。

- 枠は、その平面の**切り口を囲む平面上の矩形**。結果の表面のすぐ内側の格子点のうち、平面の近く（内側 1.5 セル〜外側 0.5 セル。局所なら欠けの球の中）にあるものを集め、平面上の2軸に投影した範囲を半セル広げる。大きな面取りには大きな枠、小さな欠けには小さな枠が付き、形の大きさや解像度に追従する。格子点で拾うので、枠は切り口より各辺で1セル程度大きい。
- 矩形の辺はワールドの上方向（Y）を基準に揃える。平面が水平に近いときは X を基準にする。
- 他の平面に切り口ごと削られた平面（拾える点が4つ未満）は枠を出さない。局所で捨てられた欠けも出ないので、実際に効いている平面の数が見える。
- 色は平面の番号から色相を黄金比で刻んで決める（ピースの色分けと同じ）。
- 枠は評価結果（`GeneratedRock::planeCuts`）に載り、評価キャッシュから読む。ビューポートに出ている形が下流（局所の欠けや Volume Noise の後）でも、枠はこのノードの結果に対するものなので、形に隠れる部分がある。評価中は前回の枠を出し続ける。
- Plane Cuts がプレビュー中の枝の上流に無く、評価されていないときは出ない。

## 診断

| 状況 | 表示 |
| --- | --- |
| 入力が未接続 | Volume 出力を接続してください |
| 枚数・深さ・半径・系統数・向き・ばらつき・なめらかさが範囲外、または非有限 | それぞれの範囲を示す |
| 結果に内部が残らない | 切り落とした結果に内部が残りません… |

## 制限

- 結果の距離値は、内外の符号は正しいが、距離としては近似になる（Volume Boolean と同じ）。
- 小面の大きさはセル間隔より十分大きくする。セル程度の欠けは格子で潰れる。稜線は Dual Contouring でもセル程度にギザつくことがある。
- 局所の欠けは稜線と角に集まる。平らな面の中央を欠くことはできない（丸い壁が残るため除外している）。平らな面に変化を付けるのは、設計メモの Volume Displace / Noise の役割。
- 平面の位置や向きを個別に指定する手段は無い（表示は上の枠のみ）。

## 検証

`tests/PlaneCutsTests.cpp`。半径 1 m の球で、1枚の切り落としが球冠の体積に一致すること、格子が変わらないこと、形を広げないこと、平面の影響がない格子点が入力と完全に一致することを確認する。枠が平面上にあって切り口の円を少しの余白で囲む正方形になること、切り口の残らない平面が枠を持たないことも確認する。ほかに再現性と Seed、枚数を増やしても既存の平面が変わらないこと、等方の法線に偏りがないこと、深さの範囲、最大枚数、主方向の円錐・系統・表裏、平行な平面、なめらかさ、不正設定12種の拒否、保存名の往復、薄い板を確認する。局所では、中心が表面にあること、外向きの法線、深さの半減、内外が変わる範囲、十字形で腕の張り出しが残り全体より削りが少ないこと、最大枚数でも1つの塊だけが残ることを確認する。グラフでは型制約、未接続の診断、2段の直列、キャッシュの再利用と上流変更の伝播を確認する。
