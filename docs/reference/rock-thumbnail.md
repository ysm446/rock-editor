# 岩グラフのアセットサムネイル

作成日時: 2026-10-03 18:07
更新日時: 2026-10-03 20:39

`.rockgraph` を保存すると、評価済みの岩を専用のレンダラで撮影する。
アセット一覧で形と材質を比べやすいよう、撮影条件を固定する。
既存の画像は次回の保存で更新される。山グラフは従来どおりビューポートの構図を使う。

## 撮影条件

- 正方形 512×512 で描画して 256×256 PNG に縮小する。
- 方位 35°、見下ろし 20°、焦点距離 50 mm。形状の境界球を中心に、全体が収まる距離へ自動調整する。
- 白色の主光源（方位 -20°、仰角 50°、100000 lux）と、無彩色の固定環境光で照らす。陰側を持ち上げるため、環境光の強さは 30000、天頂・水平・地面の色はそれぞれ 0.65・0.55・0.30 とする。
- 手動露出 EV100 = 15、ACES、透明背景。シーンの天球や太陽、自動露出は使わない。
- 深度が無い背景をアルファ 0 にする。縮小時はアルファで RGB を重み付けし、輪郭に黒がにじむのを防ぐ。
- グリッド・人物・選択枠・オーバーレイ・UV チェッカー・デバッグ表示・被写界深度は含めない。
- 材質と実際の変位を保持する。撮影用レンダラの表示 LOD は 0。

## 保存と実装

通常の保存は撮影要求を積み、グラフと材質の評価が終わったフレームの後で実行する。
待機中に別の文書へ移った場合は要求を破棄し、別の文書の絵を保存しない。
評価中・空のシーン・撮影失敗時でもグラフ本体の保存は成功扱いにする。

`PreviewRenderer::SaveAssetThumbnail` は、シーンの CPU/GPU メッシュと材質評価器を撮影中だけ借りる。
形状の再評価・転送・材質の再合成を避け、撮影後は必ず元へ戻す。
作業用レンダラのカメラ・照明・出力画像は変更しない。
撮影対象は保存時に表示しているメッシュ結果。途中ノードをプレビューしている場合も、その形を撮る。

画像は既存の `io::SceneThumbnailPath` が示すルート内の
`.rock-editor/scene-thumbnails/` に保存する。アセット一覧のキャッシュを無効化して更新を反映する。

## 検証

- Debug ビルド、ProjectWorkspace / MeshScene / ShadowCascade の 3 群が成功。
- Release の別名実行ファイルで岩グラフを保存し、256×256 の画像を確認。
- 作業用カメラを 130°/60° と -80°/5°、光量を 1000 と 200000 lux、露出補正を +3 と -2 EV に変えた 2 回の画像がピクセル単位で一致した。
- 通常の Release 実行ファイルは起動中で上書きできなかったため、検証には `rock_editor_thumbnail_test.exe` を使った。初回確認時点では全テスト未実行。

### 陰側の明るさと透明背景の確認

- Debug と別名の Release ビルド、ProjectWorkspace / MeshScene / ShadowCascade の 3 群が成功。
- blocky の保存画像を目視確認。256×256 RGBA で、透明 44053 画素、不透明 21156 画素、輪郭の半透明 327 画素を確認した。
- Debug での撮影は初期化に時間がかかったため中断し、Release で確認した。通常の Release 実行ファイルは起動中のため更新せず、rock_editor_thumbnail_test.exe に出力した。コミット前に `ctest --test-dir build -C Debug --output-on-failure` を低優先度で実行し、全テスト成功（約 541 秒）。
