# 岩らしい形と色のためのノード設計メモ

作成日時: 2026-09-22 00:30
更新日時: 2026-09-22 01:22

## 目的

参考画像（`docs/references/thumbnail_bea6868d-…​.webp`。Git 対象外の手元資料）のような岩塊を、現在のノードを土台にして作るために、足りない処理と概念を整理する。ここに書く内容は候補であり、実装済みかどうかは各項の「状態」に書く。実装順と現在地は [plan](../plan/plan.md) と [progress](../plan/progress.md) を正とする。

## 参考画像の分解

| 層 | 画像で見えるもの | 現状 |
| --- | --- | --- |
| Macro（全体形） | 非対称な塊。数個の大きなブロックの集合 | Random Boxes / Voronoi で近いものを作れる |
| Meso-大（割れ目） | ブロック間の深く暗い溝、斜めに走る割れ | 無い。ピースを結合すると接触面が消えるか、隙間がそのまま残る |
| Meso-小（面の質） | 平面的に欠けた小面の連続、鋭い稜線、段状の剥離 | 無い。格子由来のなまった面だけ |
| Micro と色 | 細かい凹凸、溝に溜まる橙の錆、凸部の灰色の風化、面の向きで変わる色 | 材質はあるが、形状に連動するマスクが無い |

効果が大きいのは、SDF 上で形を「面で削る」操作と、形状から材質マスクを作る仕組みの2つ。

## ノードの候補

効果が大きいと見込む順に並べる。1〜5 は格子点ごとに独立した計算で、`Volume.cpp` の `FillSlices` による並列化にそのまま乗る。

### 1. Volume Boolean

状態: **実装済み**（2026-09-22）。仕様は [Volume Boolean](volume-boolean.md)。

SDF どうしの和・交差・差。なめらかさの係数で、つなぎ目の角を残すか丸めるかを選ぶ。2・3 の「面で削る」「割れ目を彫る」の土台になる。To Volume が Mesh 入力に対応しているので、`Voronoi Fracture → Piece Filter / Transform → Pieces to Mesh → To Volume` を B 側へ入れれば、分割結果で本体を彫れる。

### 2. Plane Cuts（平面群によるファセット化）

状態: **実装済み**（2026-09-22）。仕様は [Plane Cuts](plane-cuts.md)。参考画像の印象の中核。

画像の岩は丸い塊ではなく、多数の平面で切り落とされた形をしている。SDF に対して `d = max(d, dot(n, p) - h)` を N 枚分繰り返す。

- 法線は等方か、主方向1〜3系統（向きを回した直交座標系の軸 ± ばらつき）。主方向は節理に沿って割れた方向性を出す。削除した Joint Set の考え方を、メッシュ切断ではなく SDF 上の安価な操作として戻した形で、[goals](../plan/goals.md) の「主破砕は方向性を持つ Joint Set に基づく」と整合する。
- 「全体」を少数（Macro の面取り）と、「局所」を多数（Meso の欠け）の2段で使う。
- 実装して分かったこと: 形全体を切る半空間だけでは、枚数を増やすほど凸包へ近づいて凹凸が消える。Meso の欠けには範囲を限った切り落としが要る。範囲を球で区切ると球の壁が丸いくぼみとして残るので、稜線と角の欠けだけを選別している。平らな面の中央に変化を付けるのは 4 の役割になる。

### 3. Volume Crack（割れ目を彫る）

状態: 未着手。

Voronoi の境界面からの距離を使って溝を彫る。`d = max(d, w - |境界までの距離|)` の形。

- 幅を一様にしない。低周波ノイズで幅を変え、深さも途中で閉じるようにする。画像では深く開いた割れ目と、髪の毛ほどの線が混在している。
- 実装は2通り。(a) Scatter Points の点を SDF 側へ渡し、F2−F1 距離で評価する。(b) ピースを縮めて再ボリューム化し、Volume Boolean で差を取る。(a) のほうが速く、幅の制御もしやすい。Points 型は既にあるので `Volume Crack(Volume, Points)` というノードになる。(b) は Volume Boolean だけで今すぐ試せる。

### 4. Volume Displace / Noise

状態: 未着手。

- Domain warp: サンプル位置を低周波ノイズでずらす。Voronoi の直線的すぎる境界や、平面カットの機械的な印象が崩れる。Volume Transform と同じ再サンプルの構造で実装できる。
- Cellular（Worley）ノイズの加算: 平面的な小面の連続は、滑らかな勾配ノイズより Worley の F1 のほうが近い。振幅はセル間隔の数倍までに抑える。
- Terrace（段化）: 層状の剥離。ある方向への距離を階段関数に通す。

### 5. Volume Smooth / Sharpen

状態: 未着手。

Gaussian や平均曲率流で角をなまらせる量を、マスクで変える。画像では上面が風化で丸く、側面の割れ口は鋭い。全体を一様に処理するとこの差が消える。

### 6. 形状からマスクを作る

状態: 未着手。色の決め手。

Material Mask は現在、定数と画像だけを持つ。形状由来のソースを足す。

- Cavity / Curvature: 溝に錆の橙、凸稜に明るい欠け色。
- AO: GPU 形状AO が既にある。ベイク結果をマスクとしても使えるようにする。
- Normal 方向（上向き度）: 上面の埃・風化・苔。
- Height / ワールド Y: 接地側の汚れ。
- Piece / Face origin: 「切断面」と「元の外面」で材質を分ける。`Piece::faceOrigins` は既に保持している。割れ口は新鮮な色、外面は風化色という対比は、画像の説得力の大きな要素。

Apply Material は最大8段の合成を持つので、これらがマスク入力へつながれば色の層は組める。

### 7. ディテールの焼き込み（High → Low）

状態: 未着手。

画像の細部はジオメトリではなく法線と Height に入っている。密な格子は各軸192点が上限なので、Micro を形状で出すのは無理がある。

- Height から法線を合成する。Triplanar の Height は現在、表示専用。
- 高解像度の SDF から、簡略化したメッシュへ法線をベイクする。Decimate と合わせると、ゲーム用アセットとして完結する。

## 概念として足したいもの

- **Field（スカラー場）型**: ノイズ、距離、曲率、マスクを Volume にも Material にも渡せる共通の型。6 のマスクと、4 のノイズによる変調（割れ幅、平滑量）が同じ仕組みで書ける。Plane Cuts は Field 型なしの単体ノードとして実装した。ノイズで割れ幅や平滑量を変える 3・4 に着手する段階で、入れるかどうかを判断する。
- **スケールの階層を明示する**: 各ノードの設定をセル間隔の倍数でも指定できるようにして、解像度を変えても見た目を保つ。
- **解像度の天井**: 192³ の密格子では、4 のノイズと 3 の細い割れ目がエイリアスする。[plan](../plan/plan.md) にある OpenVDB / Sparse 導入の条件（解像度100超、レベルセットのフィルタ）に、2〜5 を入れた時点で当たる見込み。まず密格子のまま 1 → 2 → 3 を試し、解像度不足が見えた段階で移行を判断する。

## 想定するグラフ

```text
Random Boxes → To Volume ─┐
                          ├ Volume Boolean（和。角を残す）
Base Shape → To Volume ───┘
   → Plane Cuts（大・少数・主方向2系統）
   → Volume Crack（Scatter Points。幅をノイズで変える）
   → Plane Cuts（小・多数・表面近傍のみ）
   → Volume Displace（warp + Worley）
   → Volume Smooth（上向きの面だけ強く）
   → Volume to Mesh（Dual Contouring。稜線が残る）
   → UV Unwrap → Apply Material ×3〜4（Cavity / 上向き / 切断面のマスク）
   → Material Bake
```

着手順は 1 → 2 → 3。
