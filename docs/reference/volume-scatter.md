# Volume Scatter — 表面の近くに小さな形を散らす

作成日時: 2026-10-01 09:50
更新日時: 2026-10-01 09:50

## 位置付け

Volume の表面の近くに小さな形（球・楕円体・箱）を散らし、和（足す）か差（抜く）で合成するノード。[岩の種類の網羅](rock-catalog.md) の G7。礫岩・角礫岩の埋まった礫、多孔質の溶岩・軽石の気泡の穴を作る。2026-10-01 追加。

```text
… → To Volume → （Volume 系の加工） → Volume Scatter → Volume Clip → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。保存名は `volumeScatter`。

## 設定

| 項目 | 保存名 | 内容 |
| --- | --- | --- |
| 形 | `shape` | 球（`sphere`）/ 楕円体（`ellipsoid`）/ 箱（`box`、角張った礫）。既定は球 |
| 合成 | `operation` | 和（`union`、足す）/ 差（`difference`、抜く）。既定は和 |
| 数 | `count` | 1〜2000、既定 60。表面の近くに置ける場所が足りなければ、置けた分だけになる |
| 半径 最小 / 最大 | `radiusMin` / `radiusMax` | 形の最長辺に対する比。0.005〜0.3、既定 0.03 / 0.07。最小 ≦ 最大 |
| 深さ 最小 / 最大 | `depthMin` / `depthMax` | 中心を置く深さ。表面から内側を正とし、その形の半径に対する比。-1〜4、既定 -0.3 / 0.5。礫は -0.3〜0.5（半分ほど突き出る）、気泡の穴は 0〜1 くらい |
| 細長さ | `elongation` | 楕円体・箱の軸の長さの比の最大。1〜4、既定 1.6 |
| なじませる幅 | `blend` | 形の境をなめらかにつなぐ幅。その形の半径に対する比。0〜1、既定 0.2。和では礫の根元が埋まったように、差では穴の縁が丸くなる |
| Seed | `seed` | |

## 処理

1. 入力の内部の外接箱（最大の半径だけ広げる）の中から乱数で中心の候補を取り、その位置の符号付き距離から表面からの深さを求める。狙いの深さ（半径 × 深さの範囲の乱数）との差がセル 1 つか半径の 1/4 以内なら採る。数の 400 倍まで試す。
2. 形ごとに乱数の向き（一様な回転）と、楕円体・箱なら軸ごとの長さ（細長さの範囲）を決める。箱は半径の 0.8 倍を半分の辺にする。
3. 形が届く範囲の格子点だけを、和なら `min`、差なら `max(値, −形)` で更新する。なじませる幅が 0 より大きければ多項式のなめらかな和・差にする。
4. 和では形が表面から突き出すので、突き出す分だけ格子を広げる（各軸 256 点まで。超えると診断）。差では格子は入力のまま。
5. 浮いた形（入力の塊と重ならない塊）と、穴が切り離した小片を除き（[Plane Cuts と共通の規則](plane-cuts.md#浮いた小片の除去)）、加工でできた閉じた空洞（内部の気泡）は埋める（見えないため）。

## 注意

- 形がセル（最長辺 ÷ To Volume の解像度）の 2 倍より小さいと潰れる。解像度 128 で最長辺 3 m なら、半径は 0.02（6 cm）くらいから。
- 礫と周りの色の違い（基質）は素材で表す（未対応。[岩の種類の網羅](rock-catalog.md) の G6）。
