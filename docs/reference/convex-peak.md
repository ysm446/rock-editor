# 凸岩峰の母岩（Base Shape）

作成日時: 2026-10-02 21:18
更新日時: 2026-10-02 23:10

## 目的

岩峰の大きな輪郭を分割・削除だけに任せず、最初に凸多面体で作る。ユーザーの「ある程度岩峰の形で、Voronoiで割れる凸状のメッシュを最初に置く」という提案に対応する。

独立した新しいノード種類ではなく、既存の **Base Shape → 形状 → 凸岩峰** として追加した。保存名は `baseRock.shape: "convexPeak"`。出力は通常のMeshなので、同じ出力をScatter PointsとVoronoi Fractureへ直接繋ぐ。

## 作り方と範囲

裾・肩・頂に輪郭の候補点を置き、その点群の凸包を取る。候補点を直接結ぶ方法と違い、ばらつきで凹んだ点は凸包の内側へ取り込まれる。倍精度の単位寸法で凸包を作り、最後に外接箱が指定寸法となるように変換する。原点は外接箱の中心。

| 保存項目 | 既定 | 範囲 | 意味 |
| --- | --- | --- | --- |
| `size` | [2,2,2] | 各0.001〜1000 m | 最終外接箱のXYZ寸法 |
| `peakSides` | 7 | 4〜12 | 各輪郭の候補点数。凸包の面数ではない |
| `peakTopWidth` | 0.08 | 0〜0.6 | 裾に対する頂の幅。0なら一点の頂 |
| `peakShoulderHeight` | 0.55 | 0.2〜0.85 | 裾0・頂1とした肩の高さ。肩の基準幅は裾の72% |
| `peakLeanX` | 0.18 | -0.5〜0.5 | 頂のX方向への偏り。単位形状の基準幅に対する比 |
| `peakLeanZ` | -0.08 | -0.5〜0.5 | 頂のZ方向への偏り |
| `peakVariation` | 0.25 | 0〜0.5 | 凸包を取る前の半径・角度・肩の高さのばらつき |
| `seed` | 0 | 既存Seedと共通 | 輪郭の向きとばらつきを再現 |
| `peakRidgeLength` | 0 | 0〜1 | 頂の稜線の長さ（裾の幅に対する比）。頂の点を走向に沿った線分の上に並べ、一点ではなく「のみの刃」の稜線にする。0 で従来どおりの点（乱数の順序も変えない） |
| `peakStrike` | 0 | -90〜90 度 | 走向（Y 軸まわり）。稜線が伸びる向きで、節理面もこの向きを含む。Parallel Planes の回転 Y と同じ。0 で Z 方向 |
| `peakSlabThickness` | 0 | 0〜1 | 節理面の間隔（寸法 X に対する比）。0 より大きいと、走向・傾きの平行な 2 面で凸包の両側を切り、大きな面を節理の向きにそろえた板にする。0 で切らない |
| `peakSlabDip` | 76 | 45〜90 度 | 節理面の傾き（水平から）。Parallel Planes の回転 Z と同じ値にすると、吸着で割る面と母岩の面が平行になる |

節理面で切った後の処理（2026-10-02 追加）:

- 法線は `Ry(走向)·Rz(傾き)·(0,1,0)`。Parallel Planes の `rotation: [0, 走向, 傾き]` と同じ向きなので、同じ値にすれば母岩の広い面と、分割に使う節理面が平行になる。
- 2 面は凸包の法線方向の範囲の中央に置く。間隔が範囲より大きい側は切らない。切ると外接箱は `size` より小さくなる（傾きを実寸で保つため、切った後に寸法へ引き伸ばさない）。
- 面のすぐ外（範囲の 0.1%）の点は面へ投影し、近い頂点（外接寸法の 1%）は中点に統合して凸包を取り直す。近い 2 点を結ぶ細長い面は単精度で向きが狂い、Voronoi の凸の判定を通らないため。同じ理由で、Voronoi / Scatter Points 側の凸の判定の許容差を 2e-7 から 1e-5（外接寸法に対する比）に緩めた。
- 同一平面の三角形は多角形にまとめ、面の内側に残った頂点を外してから扇形に切り直す（quickhull は共面の点を後から足すと、先の点を面の中に残す）。

頂を一点にすると円錐の尖塔に見える。手本（木曽駒ケ岳）の岩峰は、傾いた一枚の節理面が広い壁を作り、頂は稜線になるので、`peakRidgeLength` と `peakSlabThickness` を使う。輪郭の点数を増やしても小さな凹みは作らない。後段のVoronoi・Peel・局所欠けで作る。`subdivisions`、`roundness`、通常の`noiseStrength`と`noiseScale`は凸岩峰では使わない。これらをUIで隠し、凸性を壊さない専用の輪郭設定を表示する。

この母岩だけで完成した岩の自然さを保証しない。複数の塔、オーバーハング、くぼみ、根元の入り組みは凸形状では表現できない。複数の凸岩体を組む場合も、まず個々を分割してからまとめる。

## 推奨する試行の順序

1. 凸岩峰だけを表示し、寸法・肩・頂の幅・偏りで大きなシルエットを決める。
2. Scatter Points → Voronoi Fractureで分割する。必要なら主節理のPlanesを繋ぎ吸着する。
3. Peelを弱く使う。今回の研究例は90点、進行0.15、側面後退0、安定0、変換のずれ0。箱から作った旧例の強い侵食設定をそのまま使わない。
4. ボリューム化・接地・メッシュ化し、4方向と塊・空洞を確認する。

ノードIDもPeelの結果に影響するため、研究例を複製するときはIDを保つ。[研究グラフと比較画像](../research/granite-buttress/joint-study.md#凸多面体を先に作る追加試作)を参照。

## 検証

4・7・12点、8Seed、尖った頂と広い頂、低い肩と高い肩、最大の偏り・ばらつきを含む24例で、閉包・正の体積・指定寸法・各面に対する全頂点の包含・再現をテストする。稜線（6 Seed・走向 -75〜75°）は最高点が 2 点以上で走向に沿って 2 m 以上離れること、節理面（間隔 0.4・傾き 60〜90°）は全頂点が平行な 2 面の間（間隔 3.6 m ± 2 cm）に収まり、両面に 3 点以上が載り、凸・閉包を保ち、Scatter / Voronoi で体積を保って分割できることを確認する。各例をScatter PointsとVoronoi Fractureに通し、24片と体積保存を確認する。設定はGraphIo、Undoの既存スナップショット、NodeParamsカタログ、下流キャッシュに含める。

ボリューム化で接触面由来の筋が出る問題は、この母岩の追加とは別の未解決項目。母岩と分割の凸性が正しくても、その後の距離場の品質は別途検証する。
