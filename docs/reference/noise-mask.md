# Noise Mask

作成日時: 2026-09-26 17:59
更新日時: 2026-09-26 17:59

UV付きMeshの表面位置から3Dノイズを計算し、ムラを白黒のMaskとして出力する。色むら、汚れ、苔などの素材の混合に使う。

## 接続と表示

```text
UV Unwrap ─┬→ Apply Material（下地）→ Apply Material（色むら）→ Mesh Output
           └→ Noise Mask ────────────────↑ Mask
```

ノード追加メニューの Noise Mask を選ぶ。入力はUV付きの生成Meshを1つ、出力はMask。Apply Materialには同じUVを持つMeshを渡す。Noise Maskを選択すると入力Meshへ白黒マスクを貼って表示する。白が今回の素材、黒が下地になる。

[Mask Combine](mask-combine.md)でShape Maskの上向き度やオクルージョンと乗算すれば、「上面にまばらな苔」「溝の中だけに不均一な汚れ」を作れる。素材合成後のSubdivide / Displace / Material Bakeにも既存の画像マスクとして渡す。

## 設定

| 設定 | 内容 |
| --- | --- |
| ムラの大きさ | メートル単位の基準波長。0.001〜1000、既定0.5。大きいほど広いムラ |
| コントラスト | 0〜1、既定0.35。大きいほど白黒がはっきりする |
| Seed | 同じ入力・設定で模様を再現する。UIは0〜1000000 |
| 詳細：細部 | 大きなムラに重ねる細かい濃淡の量。0〜1、既定0.5 |
| 詳細：歪み | 3D空間内でノイズを読む位置を揺らす量。0〜1、既定0.2 |
| 詳細：マスク解像度 | 128〜4096、2のべき乗。既定1024 |
| 詳細：反転 | 白黒を反転。画像は再生成せず使う側で反映 |

更新状況は固定1行に表示し、計算中だけスライダーの位置が変わらないようにする。

## 計算

Shape MaskのUVラスタライズと余白埋めを共用する。各画素で三角形の重心座標から3D表面位置を補間し、その位置で五次補間の値ノイズを評価する。4段階の周波数を重ね、細部の重みを調整する。歪みは3つの低周波ノイズから作る。値を0〜1の画像へ保存する。

模様の座標は入力Meshのローカル3D座標。UVの島の配置・回転に模様は依存しない。実際の表示の細かさや島の境目の誤差は、UV密度・マスク解像度・補間の影響を受ける。形状を変更してから再生成すると、その表面位置に応じて模様が変わる。

グラフの保存名は `noiseMask`。設定を保存し、画像は読み込み時に再生成する。Seed・大きさ・細部・歪み・コントラスト・解像度と入力枝をキャッシュキーに含める。反転は描画・合成・変位・ベイク側で適用する。

## 範囲

- UV Unwrap等で重なりのないUVを用意する。異なる表面が同じUV画素を共有すると、それぞれに異なる3Dノイズを保存できない。
- UVがないMeshや複数の生成Mesh、Model型の入力は対象外。既存のShape Maskと同じ入力条件。
- マスクはCPUで生成する。UV展開・画素数が処理時間に影響する。キャンセルに対応。
- このノードは形状を変位しない。形状に使う場合は素材のハイトとDisplaceを組み合わせる。

サンプル: [noise-mask.rockscene](../../examples/noise-mask/noise-mask.rockscene)。Noise Maskで白黒、後段のApply Materialで灰色と茶色のムラを比較できる。
