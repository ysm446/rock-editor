# Volume Undercut — 高さの帯を削ってくびれを作る

作成日時: 2026-10-01 11:40
更新日時: 2026-10-01 11:40

## 位置付け

Volume の高さの帯を内側へ削り、くびれを作るノード。きのこ岩（台座岩）、フードゥー、波食ノッチ。[岩の種類の網羅](rock-catalog.md) の G2。2026-10-01 追加。

```text
… → To Volume → Volume Clip（接地）→ Volume Undercut → … → Volume to Mesh → Mesh Output
```

右クリックメニューの「ボリューム」にある。入力・出力とも Volume 型。格子は入力のまま。保存名は `volumeUndercut`。

## 設定

| 項目 | 保存名 | 内容 |
| --- | --- | --- |
| 高さ | `height` | 最初の帯の中心。形の高さ（内部の格子点の範囲）に対する位置。底 0、上 1。既定 0.2 |
| 帯の幅 | `width` | 帯の半分の高さ。形の高さに対する比。0.02〜1、既定 0.15 |
| 深さ | `depth` | 帯の中心で内側へ削る深さ。最長辺に対する比。0〜0.4、既定 0.08 |
| 帯の数 | `count` | 帯を上へ繰り返す数（フードゥーの段）。1〜8、既定 1 |
| 間隔 | `spacing` | 帯の間隔。形の高さに対する比。0.05〜1、既定 0.25 |
| ばらつき / ばらつきの細かさ | `noise` / `noiseScale` | 削る深さを水平方向にばらつかせる。0〜1 / 0.5〜16 |
| Seed | `seed` | |

## 処理

- 帯の中で、距離場に「深さ × 帯の山（cos の窓。中心で 1、端で 0）× ばらつき」を足して内側へずらす。帯の外は変えない。
- 高さは形に対する位置なので、先に Volume Clip で接地させてから掛けると、底からの高さで位置を決めやすい。
- **削りすぎを黙って通さない。** 帯で形が上下に切り離されて大きな部分（1% 超）が捨てられる場合と、底の近くを断面ごと削り切って形が浮く（底が上がる）場合は診断を出す。最初の試作では、きのこ岩の台座が断面ごと消えて傘が宙に浮いたまま評価が成功していた。
- 削り落とされた小片は捨て、閉じた空洞は埋める（[Plane Cuts と共通の規則](plane-cuts.md#浮いた小片の除去)）。
