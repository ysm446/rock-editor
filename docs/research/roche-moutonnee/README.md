## 概要

氷河が岩盤の上を通り、擦って磨く作用と岩を剥ぎ取る作用によってできる非対称な岩の隆起。氷河が来る側はなだらかで滑らかになり、去る側には急で粗い面が残る。この研究では、この前後の形の違いと、表面を同じ方向に走る擦痕を特徴として捉える。[参考：NPSの氷河による侵食](https://www.nps.gov/features/romo/feat0001/GlcBasics.html)。
