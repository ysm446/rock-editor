## 今の状態

- 状態: △（構成はできた。見た目はまだ写真から遠い）
- グラフ: [examples/nasu-asahidake/nasu.mountaingraph](../../../examples/nasu-asahidake/nasu.mountaingraph)（岩グラフは同じフォルダの `blades` / `talus`）
- 手本: `docs/references/nasu-asahidake/DSC00363`（主）・`DSC00362`・`DSC00365`（ユーザーの写真。Git の対象外）。65° に傾いた板状節理の刃の列（1 枚 3〜6 m）、褐色の風化土の斜面、拳大〜1 m の破片が刃の根元に密、草の塊。幅 15〜20 m。
- 作り方: 40 m 四方のハイトマップ（奥ほど高い斜面 + 中央の尾根）に、高さの Shape Mask で尾根の頂だけに [nasu-blades](../nasu-blades/README.md) を 2 個（大きさの間隔 0.7 で食い込む、沈める量 0.3 + 浮きの補正）。大の Coverage を「広げる」6 m と反転の min で崖錐の範囲にし、崖錐の破片（`talus-fragment` の 1 倍と 0.45 倍、間隔 0.8 m、倍率 0.3〜1.4）を密に撒く。傾斜のマスクを薄くして斜面全体にまばらな転石。
- 課題:
  - 刃の列が 1 つの塊に見え、写真の「刃が並んで立つ」感じが弱い（[nasu-blades](../nasu-blades/README.md) の課題）。
  - 破片が同じ形の繰り返しで、土に埋まった感じが無い（沈める量を破片ごとに変える、形を数種類）。
  - 地面は定数色の土で、起伏が滑らか。写真の斜面は細かい礫で荒れ、刃の根元にえぐれがある。
  - 草の塊は対象外（植生）。
  - 写真の視点（斜面の下から見上げる）で撮ると地面が暗く沈む。光の向きとカメラの高さを整える。
