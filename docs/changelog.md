# Changelog

## 未リリース

- Piece Select の Peel（接地）に「支えの角度」（`pieces.supportAngle`、既定 60°）を追加。下の片との接触面が真下からこの角度以内なら載っていると数える。急な節理で割った岩では 80〜85 に広げると、板の中の片がまとめて落ちなくなる。`granite-buttress` に適用し、Volume Close の幅も 0.02 にして微小な空洞を消した。
- レシピ `granite-buttress`（花崗岩の岩峰）を、凸岩峰の母岩を先に作る組み方に置き換えた（傾いた板と稜線の頂、節理面への吸着、Peel の稜の効き）。以前の組み方は研究ページの経過に残っている。
- To Volume で、隙間なく接触する片の共有面（表裏とも内部の隠れた面）を最近距離の計算から外した。Pieces to Mesh の分割片をボリューム化したときに接触面に沿って出ていた筋が消え、分割した形が一体の形と同じ距離場になる。
- Piece Select の Peel に「稜の効き」（`pieces.peelEdge`）を追加。元の外面が 2 方向以上を向く片（稜・角・張り出した縁）ほど先に欠け、一つの平面しか向かない片（面の中央）は後回しにする。面の途中に穴を開けずに縁から欠けさせたい岩峰・板状の岩に使う。既定 0 で従来どおり。[仕様](reference/piece-erosion.md)。
- 凸岩峰に「頂の稜線の長さ」「走向」「節理面の間隔」「節理面の傾き」を追加。頂を一点ではなく走向に沿った稜線にし、Parallel Planes と同じ向きの平行な 2 面で両側を切って傾いた板にできる。既定は従来どおり。Voronoi Fracture / Scatter Points の凸の判定の許容差を 2e-7 から 1e-5 に緩めた（細長い面の単精度の誤差を凹形状と誤判定しないため）。[仕様](reference/convex-peak.md)。
- Base Shapeに「凸岩峰」を追加。裾・肩・頂の凸包から、Voronoiへ直接渡せる凸多面体の母岩を作る。頂の幅・肩の高さ・偏り・輪郭のばらつきで大きなシルエットを先に決める。[仕様](reference/convex-peak.md)。
- Voronoi FractureにPlanes専用の「節理の連続枚数」を追加。0は従来の貫通、1以上で第1系統の板の束ごとに横の節理を止める。[岩峰の比較研究](research/granite-buttress/joint-study.md)に再現グラフ・画像・数値を保存した。

- 岩の研究ページを種類ごとのフォルダ（`docs/research/<レシピ名>/`）に分け、状態・作り方・課題・経過の文と、日時付きの経過の画像を置くようにした。`rocks.md` は一覧の入口。「テンプレートから作成」のサムネイルは `docs/research/<id>/latest.jpg` を使う（旧 `docs/research/images/` は廃止）。

- Voronoi Fracture に「節理面への吸着」（`pieces.snap`）を足した。Points と Planes を両方繋いで有効にすると、Planes の最初の系統の構造面で形を板に分け、板の中を点の Voronoi で割る。節理面が複数の片にまたがる一枚の面になる。`granite-buttress` に組み込んだ。仕様は [Voronoi とピース操作](reference/voronoi-pieces.md)。
- Piece Select の Peel に「底の後退」（`peelRetreatBase`）を足した。側面の後退の底での割合で、既定 0 は従来どおり。`granite-buttress` は継ぎ目を Volume Close で閉じ、ブロックのずれを小さくして一枚岩に寄せた。

- Flow Mask ノードを足した。表面を重力で流れ下る水の筋（流れの量）を UV のマスクにする（鉄錆・汚れの流れた筋、濡れ跡）。入力は UV 付きの Mesh と、筋を追う格子の Volume（任意）。仕様は [Flow Mask](reference/flow-mask.md)。レシピ `rust-streaks` を足した。
- レシピ `conglomerate` / `breccia` に、Volume Diff Mask（足した所）で礫だけを基質と別の色に塗る組み方を入れた（Surface の定数色）。
- Volume Noise と Volume Undercut に「向きに集中」「集中する向き」を足した（Volume Smooth / Edge Wear と同じ）。既定 0 で従来と同じ。タフォニを陰の面に集める、波食ノッチを波の当たる側だけ深くする、くぼみを風下に付ける、に使える。レシピ `honeycomb` / `wave-cut-notch` / `wind-erosion` に適用した。

- Volume Erode ノードを足した。向きで削る量を変える侵食で、「さらされた面」（風・波・氷が来る向きを向く面ほど削り、他の部分の陰は削らない。風上の面が後退する）と「流下」（表面を重力で流れ下る筋を追い、流れが集まる所ほど削って溝にする）を選べる。仕様は [Volume Erode](reference/volume-erode.md)。レシピ `wind-erosion` に組み込み、石灰岩の溶食の縦溝 `limestone-rills` を足した。再距離化（`RedistanceInterior`）に、深すぎる値も直す両方向モードを足した（既存の呼び出しは従来どおり）。さらされた面の重みは横向きの面にも弱く効き、陰は風上側 50° の円錐の開放度で決める。

- Volume Scatter に「寝かせる割合」を足した。楕円体・箱の一番短い軸を上へ向ける（0 で従来どおり一様な向き、1 で必ず寝る）。自重で扁平になった枕状溶岩の枕、水底に寝た礫。仕様は [Volume Scatter](reference/volume-scatter.md)。
- Volume Undercut に「帯の基準」を足した。従来の「形の高さに対する位置」に加えて、「ワールドの高さ (m)」で帯の中心を決められる（波食ノッチの水面、砂が当たる地面の近く）。仕様は [Volume Undercut](reference/volume-undercut.md)。
- レシピ（テンプレート）に枕状溶岩 `pillow-lava`、波食ノッチ `wave-cut-notch`、風食 `wind-erosion` を足した（どれも △）。研究ページは [岩の研究ページ](research/rocks.md)。

- ビューポートの表示（シェーディングの切り替え、「Display」メニュー、LOD の切り替え、統計、フライの速さ、ライトの角度）を英語にした。統計に、1 フレームの処理時間（ms）と、ビューポートの描画にかかった GPU の時間（ms）を足した。ステータスバーの右端に、直近の岩グラフの評価にかかった時間（評価の開始から結果をビューポートへ渡し終えるまで）を出し、評価の途中は経過時間を最初から出すようにした。

- ライティングに「スクリーンスペースGI」（有効・半径・強さ）を足した。画面内の光っている面から近くの面への照り返し（岩どうし・岩と土）を表示に足す。表示専用で、テクスチャには焼き込まない。既定はオフ。仕様は [スクリーンスペース GI](reference/screen-space-gi.md)。

- Material Bake に「解像度」を足した（UV と同じ / 512 / 1024 / 2048 / 4096）。UV Unwrap の解像度とは別に、焼く画像の大きさを選べる。UV を展開し直さずに変えられる。既定は従来どおり UV と同じ。

- Volume Diff Mask ノードを足した。後から足した所（または削った所）を白くするマスクで、最後のメッシュの表面で比べる元の Volume（足す・削る前）の距離を読む。Volume Close で埋めた岩と岩の隙間の土、Volume Scatter で足した礫、割れ目を別の素材で塗れる。仕様は [Volume Diff Mask](reference/volume-diff-mask.md)。テンプレートに分類「使い方の例」を足し、最初の例として `soil-filled-gaps`（岩の隙間を土で埋める）を入れた。

- Surface ノードとモデルのマテリアルスロットのコンボに、ルートにある未読み込みのマテリアル（.rockmat / .tglayer）も出すようにした。選ぶと読み込んで割り当てる（テクスチャのコンボと同じ）。一度アセット欄で開かなくても選べる。

- 「テンプレートから作成」で選んだテンプレートを、ファイルを作らずに未保存の文書として開くようにした。保存したときに初めて保存先を聞き、テンプレート名と表示中のフォルダを初期値にする。中身を見るだけならファイルが増えない。

- Scatter Points に「高さの勾配」を足した（上ほど、または下ほど点を密にする）。Piece Select の Peel に「側面の後退」を足した（元の側面から横へ削れる深さを高さに比例させ、上ほど細くする）。どちらも既定 0 で従来と同じ。`granite-buttress` は裾が広く上ほど細い尖塔になった（高さ 12.5 m）。仕様は [ピースの侵食](reference/piece-erosion.md#側面の後退2026-10-02-追加)。

- 板状節理のレシピ（`platy-joints`）を作り直した。扁平な点の Voronoi で不規則な板に割り、接地の Peel で外周から欠く。板が段になって張り出し、石積みの壁に見えなくなった。
- 岩グラフを組む手順（skill `rock-graph`）を `.agents/skills/rock-graph/SKILL.md` へ移し、Codex からも使えるようにした。Claude Code の skill はそこを指す入口にし、AGENTS.md から案内する。
- Piece Select の Peel（接地）に「安定」を足した。下で支える片に載る面積が片の大きさに足りないと転げ落ち、頭でっかちの片が残らない。Voronoi Fracture の構造面で、90° 回した系統の法線の誤差で片が捨てられ失敗していたのを直した。`granite-buttress` は上ほど細く尖る形にした。
- ビューポートの全体表示（A キー）と起動引数 `--frame-all` が、原点ではなくメッシュの範囲の中心を見るようにした。接地した背の高い岩の頂が画面から切れていた。作業グリッドも入れる全体表示は従来どおり原点を見る。
- Scatter Points に「密度のむら」「むらの細かさ」を足した。大きなノイズで点を間引き、割れの多い帯（小さな片）と割れの少ない芯（大きな片）を作る。Piece Select の Peel に「大きさの効き」を足した（小さな片ほど先に欠ける）。どちらも既定 0 で従来と同じ。`granite-buttress` は割れの少ない芯が 1 本の塔として残る形にした。
- 節理で岩体をブロックに割れるようにした。Voronoi Fracture に Planes 入力を足し、構造面の系統で凸な Mesh を節理のブロックに割る（隣接情報が揃うので Peel が使える）。Parallel Planes に Planes 入力を足し、別の Parallel Planes を繋ぐと系統を足して渡す（節理系 1 → 2 → 3）。Volume Crack は連結した全系統を 1 回で彫る（1 系統なら従来と同じ結果）。仕様は [Parallel Planes](reference/parallel-planes.md#系統の連結2026-10-01-追加)、[Voronoi とピース操作](reference/voronoi-pieces.md#構造面で割る2026-10-01-追加)。
- Piece Select の Peel に「接地」を足した。下向きの外面からは欠かず、下のブロックに載っていない片は支えを失って落ちる（地面から生えた岩峰・露頭・崖）。既定はオフ。仕様は [ピースの侵食](reference/piece-erosion.md#接地2026-10-01-追加)。
- レシピ `granite-buttress` を作り直した。ひびを彫るのをやめ、ブロックに割って外側から抜き取る形にした。ブロックは節理の向きに伸ばした Voronoi の多面体で、少しずつずらしてある。
- Piece Transform に片ごとのばらつき（ずれ・傾き。`jitterPosition` / `jitterRotation` / `jitterSeed`）を足した。各片を自分の重心を中心に、乱数で動かして回す。仕様は [Voronoi とピース操作](reference/voronoi-pieces.md#piece-transform-のばらつき2026-10-01-追加)。
- グラフの評価が深い岩グラフ（30 段ほど）でスタックを使い切り、`rock_cli` が何も出力せずに落ちることがあったので、アプリ・テスト・`rock_cli` のスタックを 16 MB にした。
- To Volume が、重なった立体（Random Boxes、重なったメッシュ）の内部の距離を表面から測り直すようにした。これまでは内部の値が隠れた面や一つの箱の中での深さになり浅く歪んでいたので、殻・割れ目の深さ・Undercut など内部の値を使うノードの結果が内部の面に沿って崩れていた。表面の形は変わらないが、Random Boxes を使うグラフは後段の結果が少し変わる（多くは体積の差 1% 未満）。仕様は [直方体の塊とボリューム](reference/box-volume.md#to-volume)。
- Volume Noise が、表面の近くの帯の境で内部の値を跳ばさないようにした（後段の殻の底などが縞になっていた）。表面の形は変わらない。
- Volume Crack の「表面に沿う殻」の不具合を直した。剥がれた跡の面に等高線のような縞（ボクセルの段）が出ていたのと、2 枚目以降の殻が剥がれていなかったのを直した。殻を 3 枚以上使うグラフは剥がれが深くなる（`granite-sheeting` は殻を 2 枚に減らした）。レシピ `spheroidal-weathering`（玉ねぎ状風化）を追加。
- Volume Crack に有限の割れ目を追加（Planes 入力）。「割れ目の長さ」を正にすると、構造面を端から端まで割らずに、先端の閉じた楕円の割れ目を面の上に散らす。「割れている割合」と「段違い」（割れ目ごとに面の法線方向へずらす）を選べる。保存名 `extent` / `coverage` / `stagger`、既定の長さ 0 は従来と同じ結果。仕様は [Volume Crack](reference/volume-crack.md#有限の割れ目2026-10-01-追加)。レシピ `platy-joints` / `granite-buttress` に使った。
- レシピ `granite-buttress`（花崗岩の岩峰）を追加。急傾斜の節理で割れた塔 2〜3 本が根元でつながる。
- 岩のテンプレートから岩グラフを作れるようにした。「ファイル」→「テンプレートから作成…」（アセット欄の右クリックの「テンプレートから岩グラフを作成…」）で、片理・柱状節理・きのこ岩など 20 種を分類ごとのサムネイルから選ぶと、表示中のフォルダへ複製して開く。テンプレートは `examples/ai-recipes/` のレシピそのもので、ビルドで実行ファイルの横の `templates/` にコピーする。開発用の起動引数 `--open-templates` / `--template <id>` を追加。
- 岩の研究ページ [docs/research/rocks.md](research/rocks.md) を追加。岩の種類ごとに 4 方向のスクリーンショット・状態・作り方・課題・改善の履歴を載せ、一つずつ改善していく。画像は `python tools/rock_research_shots.py [名前…]` でレシピから撮り直す。
- Volume Smooth / Volume Edge Wear の「向きに集中」（上向きに集中）の重みを、ぼかした場の法線で決めるようにした。効く面と効かない面の境に薄いヒレが出ていたのを直した。この機能を使う既存のグラフは結果が少し変わる（サンプルの volume-edge-wear / volume-smooth-terrace ではヒレの小さな塊が消えた）。
- Structure Mask ノードを追加。岩の構造から素材の模様のマスクを作る。縞は Parallel Planes の構造面の層ごとに塗り（片麻岩の縞・砂岩の色の層。割れ目と同じ面に揃う）、脈は 3D の網目の細い線（大理石・石英の脈）。仕様は [Structure Mask](reference/structure-mask.md)。レシピ `gneiss` / `marble` を追加。
- Plane Cuts に「曲がり」を追加。平面の代わりに外側に中心を置いた球で切り、えぐれた曲面の切り口にする（黒曜石・フリントの貝殻状断口）。0 で従来の平面。レシピ `obsidian` を追加。
- Volume Smooth と Volume Edge Wear の「上向きに集中」を、任意の向きで指定できるようにした（「集中する向き」、保存名 `focusDirection`、既定は上）。風上や氷河の流れてきた側だけを丸められる（羊背岩・風食）。既存のグラフの結果は変わらない。レシピ `roche-moutonnee` を追加。
- Volume Undercut ノードを追加。形の高さの帯を内側へ削ってくびれを作る（きのこ岩・フードゥー）。帯の高さ・幅・深さ・繰り返しの数と間隔を選べる。削りすぎて形が上下に切り離されたり、底が削り切られて浮いたりした場合はエラーにする。仕様は [Volume Undercut](reference/volume-undercut.md)。レシピ `mushroom-rock` / `hoodoo` を追加。
- Volume Crack に割り方「表面に沿う殻」を追加。Points・Planes を繋がずに、形の表面に平行な殻（板）で割り、外側の板がまだらに剥がれ落ちた段を作る（花崗岩のシーティング・玉ねぎ状の風化）。殻の間隔・枚数・剥がれる割合・なめらかさを選べる。レシピ `granite-sheeting` を追加。
- Volume Scatter ノードを追加。表面の近くに小さな形（球・楕円体・箱）を散らし、和で足す（礫岩・角礫岩の埋まった礫）か差で抜く（多孔質の溶岩の気泡の穴）。数・半径・中心の深さ（表面からの深さを半径に対する比で）・細長さ・なじませる幅を選べる。浮いた形は除く。仕様は [Volume Scatter](reference/volume-scatter.md)。レシピ `conglomerate` / `breccia` / `vesicular-basalt` を追加。
- Volume Noise に種類「くぼみ」を追加。セルの内側をお椀状に削り、セルの境を薄い壁として残す（蜂の巣状の風化・タフォニ・多孔質の岩肌）。これまでのセル状は丸い盛り上がりになり、くぼみは作れなかった。レシピ `honeycomb` を追加。
- レシピに柱状節理・スレート・崖錐の岩片・河原の丸石を追加（計 9 種）。岩の種類ごとに作れる・作れないを試して、足りないノードを整理した [岩の種類の網羅](reference/rock-catalog.md) を追加。
- Volume Clip に「接地」モードを追加。形の底から「埋める割合」の位置で切り、その切り口が指定の高さ（既定 0 = 地面）に来るように形を上下に動かす。原点中心にできる Random Boxes・Base Shape を、Volume Transform で持ち上げなくても地面に据えられる。既定は従来の「ワールド」（保存形式に `mode` と `embed` を追加。無ければ従来どおり）。
- Plane Cuts / Volume Noise / Volume Smooth / Volume Edge Wear / Volume Terrace が、入力の時点で分かれていた大きな塊を消さないようにした。これまでは結果の最大の塊 1 つだけを残していたので、割れ目で分かれた岩を通すと大きな塊まで黙って消えていた（例: 24 個に分かれた岩で体積 3.25 → 0.85）。今はそのノードが削って切り離した小片と、最大の塊の 1% 未満の破片だけを捨てる。手元とサンプルの岩グラフ 35 件の Volume to Mesh は、変更の前後で同じ結果になることを確かめた。
- `tools/rock_shot.py --views 4` で、岩を 4 方向から撮って 1 枚にまとめられるようにした（光もカメラに合わせて回すので裏側も見える）。起動引数 `--camera-yaw` / `--camera-pitch` / `--light-azimuth` を追加。
- 岩の種類ごとのレシピ `examples/ai-recipes/`（片理・塊状・板状節理・丸い転石・層理の段）と、LLM（Claude Code）が岩グラフを組むときの手順 `.claude/skills/rock-graph/SKILL.md` を追加。
- 撮影（`--screenshot` / `--screenshot-ui`）がグラフの評価の完了も待つようにした（途中や前の形が写らない）。起動引数 `--frame-all`（形全体が入るようにカメラを引く）と、撮影をまとめた `tools/rock_shot.py` を追加。
- 岩グラフ（`.rockgraph`）を手で書きやすくした。ピンとリンクの ID・ノードの位置・マテリアルの表を省ける。リンクは `{"from": "3", "to": "6:Geometry"}` のようにノード ID とピンの名前で書ける。Piece Select の mode などの数値の列挙を名前（`"peel"`）で書ける。Surface のマテリアルにパス（`"Materials/rough-rock.rockmat"`）を直接書ける。位置の無いノードは開くときに左から右へ並べる。アプリで保存すると従来の形で書く。`rock_cli` は無いピン・候補に無い名前・型の違う値・見つからないマテリアルを報告する。
- `rock_cli` にノードの項目表を追加。`rock_cli catalog` が項目ごとの範囲・単位・列挙の候補・意味と、ノードの概要・落とし穴（最大の塊だけ残す、など）を出す。`rock_cli check` / `eval` は、知らない設定のキー（打ち間違い）、範囲外の値、候補に無い列挙を、ノードと項目のパスつきで報告する（これまでは黙って無視・既定値・丸めになっていた）。表と評価のコードのずれはテストで検出する。
- UI なしで岩グラフを評価するコンソールの道具 `rock_cli` を追加。`rock_cli eval <グラフ>` でアプリと同じ評価をして、結果を JSON で出す（成否、エラーのノード、三角形数・寸法・閉じているか・塊と空洞の数と体積）。`--node` で途中のノードを評価できる。`rock_cli catalog` は全ノードのピンと既定の設定を出す。LLM などアプリの外の道具がグラフを書いて確かめるための入口。GPU が要るノード（Displace など）の下流は評価できない。仕様は [LLM による岩グラフの作成](reference/ai-authoring.md)。
- グラフの読み込みで、知らない種類のノードや繋げないリンクを捨てたとき、その理由を集められるようにした（アプリの動作は今までどおり。`rock_cli` が報告する）。

- Rock AssetでUVを作り直す段（LOD2以降など）が「1枚のUVアトラスを生成できませんでした」で失敗することがあったのを直した。割れの多い岩はUVの島が数百個になり、小さいアトラス（LOD3で256px）では島ごとの余白で埋まっていた。収まらないときは余白を詰め、それでも駄目なら解像度を上げて展開し直す。

- Rock AssetのLODで、段ごとに「LOD0のUVを共有」を選べるようにした。共有しない段はUVを捨てて減らし、その段だけでUVを展開し直して、テクスチャ（色・法線・粗さなど）をLOD0から転写する。LOD0のUVを保ったまま減らすと、UVの島が多い岩では細かい段が目標の三角形数に届かなかった（例: 目標500に対して3,532で止まる）。既定はLOD1が共有、LOD2以降が作り直し。焼いた岩アセットは、作り直した段のテクスチャを `lodN/` に置く（目録は版2。版1も読める）。山グラフのRock Scatterも段ごとのテクスチャで描く。
- 「岩アセットを焼く」で先にMaterial Bakeが走ったとき、焼き終えたらプレビューをRock Assetへ戻すようにした。

- Rock AssetのLODを切り替えたときの引っかかりを直した。段を変えるたびにシーンを作り直し（材質の評価とGPUへの転送）ていたのをやめ、全ての段を先にGPUへ送って描く段だけを変えるようにした（切り替えは1回0.02 ms以下）。

- 岩グラフと山グラフの拡張子を `.rockscene` → `.rockgraph`、`.rockmountain` → `.mountaingraph` に変えた。画面の呼び名（岩グラフ・山グラフ）と揃えるため。古い拡張子は読まない（サンプルは改名済み。手元のファイルは拡張子を変えれば、中身はそのまま読める。山グラフの Rock が指す岩グラフのパスも書き換える）。焼いた岩アセットの付属フォルダは `<岩グラフ>.rockgraph.bake/` になる。

- 山グラフで岩を撒けるようにした。Rockノードで岩グラフ（焼いた岩アセット）を選び、Rock Scatterで地形に間隔を空けて撒く。Shape Maskの上向き度などをMaskにつなぐと、急な斜面だけに撒ける。複数のRockをつなぐと重みで選ぶ。倍率の範囲、法線に合わせる強さ、地形へ沈める量を変えられる。岩は段（LOD）を持ち、カメラから見た大きさで段を選んでインスタンス描画する（数百個を数回のドローコールで描く）。「LOD（色分け）」では岩も段の色になる。仕様は [Rock と Rock Scatter](reference/rock-scatter.md)。

- FBXなどの外部モデルを包む共有アセットの拡張子を `.rockmodel` から `.model` に変えた。岩グラフが作る岩アセットと紛らわしく、岩以外のモデル（木や小道具など）も取り込めるため、汎用的な名前にした。旧 `.rockmodel` は読まない（リポジトリにも手元のシーンにも使用例が無かったため）。

- Rock Assetに「岩アセットを焼く」を追加。シーンの横の付属フォルダ（`<シーン>.bake`）へ、段ごとのメッシュとMaterial Bakeの結果（テクスチャ4枚）を保存する。Material Bakeが未ベイクなら先にベイクする。設定欄に焼いた結果が最新か古いかを出す。アセット欄でシーンの名前を変えたり移したり削除したりすると、付属フォルダも一緒に扱う。

- 山グラフ（`.rockmountain`）を追加。「ファイル」→「新規山グラフ」で作り、ハイトマップから岩山の下地を組み立てる。岩グラフと同じアプリで、開いたファイルの種類によって右クリックメニューのノードが変わる。アセット欄の右クリックの「岩グラフを作成」「山グラフを作成」でも、表示中のフォルダに作って開ける。仕様は [山グラフと Heightmap](reference/heightmap.md)、サンプルは `examples/mountain/`。

- Heightmapノードを追加（山グラフ）。ノイズの山か画像（16bit PNG推奨、8bit、EXR）から、実寸（既定200 m四方・高さ0〜80 m）の地形のメッシュを作る。地形はUV付きのメッシュなので、Shape Maskの上向き度で傾斜のマスクを作るなど、今の材質・マスクのノードがそのまま使える。

- Material Bakeにハイポリからの転写（High → Low のベイク）を追加。3本目の入力「High」にDecimate前の高密度のメッシュを繋ぐと、ベイクのときにその細部を法線マップとハイトへ焼き込む。素材の法線は細部として重ね、ハイトにはハイポリまでの距離を足す。探す距離は「ケージ距離」（既定0.1 m）。未接続なら従来どおり。形状AOは今のところローポリで計算する。仕様は [UVとベイク](reference/uv-bake.md)、サンプルは `examples/high-low-bake/`。

- Rock Assetノードを追加（岩グラフの最終段）。入力のメッシュから段階的なLOD（既定4段、LOD0に対して50 / 25 / 12.5%）を作る。どの段も同じUVを持つので、Apply MaterialやMaterial Bakeの結果をそのまま使える。選ぶとビューポート左上に「LOD 自動 / 0 / 1 …」が出て、段を固定するか、カメラから見た大きさで自動で切り替えて確かめられる。出力はLOD0。付属フォルダへの保存と変種は未実装。仕様は [Rock Asset](reference/rock-asset.md)、サンプルは `examples/rock-asset/`。

- 表示モードに「LOD（色分け）」を追加（terrain-graphから移植。UE5と同じ配色）。クレイと同じ陰影で、Rock AssetのLODを段ごとの色で塗る。

- DecimateがUVの島の境界（継ぎ目）に沿っても三角形を減らせるようにした。これまでは継ぎ目に触れる辺を全て残していたので、UV展開済みで島の多いメッシュは途中で減らなくなっていた（例: 4,200三角形の岩で約1,870が下限だったのが、目標の525まで減る）。両側の島のUVをそろえて動かすので、模様の境目はそろったまま。UV展開済みのメッシュを減らしている既存のシーンは、結果の形が変わる。

- 開発用の起動引数 `--rock-asset-lod <n>`（-1で自動）と `--view <番号>`（表示モード）を追加。

- ビューポートにフライ操作を追加（terrain-graph / UE5 と同じ）。右ボタンを押している間はマウスで見回し、W / S で前後、A / D で左右、Q / E で下 / 上に動く。Shiftで4倍速。押している間のホイールで速さを変え（0.01〜100倍、放しても覚えておく）、変えた直後は下の中央に速さを出す。基準の速さは被写体の半径の半分。Alt + 右ドラッグのドリーはそのまま。フライ中はF / Aの視点のショートカットとW / Eのギズモ切り替えを止める。

- 全体レビューに基づく不具合の修正と整理。レイヤーマテリアルで上の層の名前や素材を変えると、未設定のマスクが被覆量0で保存されてその層が消える問題を修正。マテリアルを削除すると、後ろの項目を消しても選択が1つ前へずれる問題を修正。不透明度マップのリンク切れに印が付かなかった問題を修正。ビューポートのDeleteでモデルのノードを消したとき、プレビューが消えたノードを指したまま残る問題を修正。65個以上のノードを枠で選ぶとコピーから漏れる問題を修正。モデル（.rockmodel）のサムネイルが、スロットのマテリアルやFBXを差し替えても更新されない問題を修正。改名・削除した取り込み済みの画像を、以前のパスのまま参照し続ける問題を修正。UVの島番号が欠けたメッシュをRemeshへ渡すと範囲外を読む問題を、入力エラーとして止めるようにした。壊れたシーンファイルで、範囲外の番号や重複したピンの番号を読んだときに別のピンへつながる問題を修正。Piece Selectの集計は入力か設定が変わったときだけ計算し直す。Voronoi分割・Remesh・Dual Contouringの内側の繰り返しでの確保を減らし、グリッドの描画は使う分の定数だけ送る。使われていないコード（旧レイヤーパネルの名残など）を削除し、READMEの撤去済みノードの説明を現在のノード一覧に差し替えた。

- コピーしたノードを別のファイルへ貼れるようにした。これまではファイルを開くとコピーが消えていた。別のファイルへ貼るときは、コピーした範囲の外へのつながりを外し（範囲の中どうしは保つ）、マテリアル・Material Mask の画像・モデルの参照を元のファイルのパスから開いた先の番号へ置き換える。開いた先に無ければ読み込み、見つからなければ「なし」にしてログに出す。Material Bake の結果は持ち越さず、貼った先で焼き直す。メモ・位置・その他の設定はそのまま。

- ノードにメモを書けるようにした（terrain-graph と同じ作法）。ノードを選ぶとプロパティ欄の先頭に「メモ」欄が出て、欄の外をクリックで確定する。メモはシーンに保存され、コピー＆ペーストとアンドゥにも乗る。評価には使わないので、書き換えても形状は再計算しない。グラフではノード名の横に印を付け、メモの先頭をノードの上に吹き出しで最大3行出す（全文はツールチップ）。グラフパネルの「メモを表示」で吹き出しを切り替えられる（アプリ設定に保存）。

- Apply Materialに「不透明度」（0〜1、既定1）を追加。マスク（とハイトで合成）で決めた重みに最後に掛け、素材を薄くかけられる。Mask未接続でも1未満なら全面置換せず、上流の素材の上に重ねる。仕様は [素材の適用](reference/material-application.md)。

- ビューポートの「表示」に人のシルエット（サイズ比較）を追加。既定は非表示・身長1.7 m。岩メッシュの右端・底面を基準に置く直立2Dビルボードで、身長とXYZ位置補正を調整できる。設定はアプリに保存し、生成メッシュには含めない。Blenderや外部画像は不要。輪郭は標準的な成人の比率（約7.5頭身、指先が太ももの中ほど、腕は体側に沿って下ろす）で描く。

- Volume Clipノードを追加。水平な平面でボリュームを切り、片側を捨てる。既定は高さ0（原点）で下を捨て、平らな底面を作る。「反転」で上を捨てる。仕様は [Volume Clip](reference/volume-clip.md)。

- Layered Boxesに「位置」を追加し、ビューポートの移動ギズモで積み重ね全体を動かせるようにした。ノードを選んでいるときにWで移動、Eで回転のギズモに切り替える。ギズモは積み重ねの中心（位置）に出る。

- 表示の「スムーズシェーディング」と「折れ角」を変えても、Deposition Mask・Displace・Pieces系などを含むグラフではビューポートに反映されなかった問題を修正。設定を変えたら評価し直した結果を受け取るまで待つ。

- Layered Boxesの「向き」をビューポートの回転ギズモで変えられるようにした。ノードを選ぶと積み重ねの中心にX / Y / Zの輪が出て、ドラッグで積み重ね全体を回す。Ctrlで15度刻み、ドラッグ中のEscで元に戻す。倍率は持たないので、倍率のギズモは出さない。

- ビューポートの表示「ハイト」「ハイト（ローカル）」が、Apply Materialを無視して下地の素材のハイトだけを映していた問題を修正。Apply Materialがあるときは、ハイトで合成したあとの値を映す。ローカルは周りの8点でも合成をやり直して平均を引く。陰影（通常の表示）でのハイト合成はもともと行われていた。

- Mask Filterノードを追加。種類「ぼかし」「シャープ」「レベル」で1つのマスクを加工する。ぼかし・シャープは岩の表面の3D距離（半径 m）で計算し、UVの継ぎ目をまたいでつながる。レベルは入力の黒・白、カーブ、出力の黒・白。Shape Mask・Mask Combineなどの後ろに直列につなぎ、選択時は白黒でプレビューする。サンプルは `examples/mask-filter/`。

- マテリアルプレビューで、レイヤーマテリアルを出しているときは左右2区画に分けるようにした。左にプレビューと表示の設定、右にレイヤー一覧と選んだ層の設定を置き、スクロールするのは右だけ。境界はドラッグで動かせる。窓の幅の下限もそのときだけ広げる。

- マテリアルプレビューの平面で、変位を付けたときの側面と底面を描かないようにした。上の面だけを描き、縁からは凹凸の断面が見える。

- Shape Maskに「曲率（谷）」「曲率（山）」を追加。符号で凹凸を分け、平面は両方で黒。曲率スケールと既存の下限・上限・ガンマで調整する。

- マテリアルプレビューに「形（球／平面）」「大きさ (m)」「変位 (m)」を追加。変位を付けると素材のハイト（レイヤーマテリアルは合成後のハイト）で形を凸凹させ、輪郭と太陽の影で高さが読める。普通のPBRマテリアルとレイヤーマテリアルの両方で使える。プレビューだけの表示設定で、マテリアルには保存せず、ノードの計算やビューポートの形にも影響しない。

- Deposition Maskノードを追加。UV付きMeshの受け面・近傍の遮蔽・上方の開口から土の堆積候補を生成。基本UIは堆積量・隙間の範囲・許容傾斜とし、Apply Material、Mask Combine、白黒プレビュー、保存、Undo / Redoに対応。

- レイヤーマテリアルの層一覧をterrain-graphと同じ形に変更。各行に目のアイコン・素材のサムネイル・合成後にその層が見えている範囲の白黒画像・名前を並べ、上の行を上の層にした。並べ替えは行のドラッグ（上へ／下へボタンは廃止）、マテリアル一覧から行へ素材をドロップして割り当てられる。「合成（通常／高さ）」と「境界の幅」を詳細から出し、新しく追加する層は高さで合成する。

- terrain-graphのレイヤーマテリアルを岩用に移植。最大4層のPBR素材／単色を、均一またはムラの被覆で重ねて`.tglayer`へ保存できる。層一覧から選んで編集し、球・サムネイル・Surface・Apply Material・ベイク・Displaceへ反映。道路専用のマスクや座標設定は含めない。

- Layered Boxesを含む全ノードの処理状況を、設定スクロール領域の外にある固定1行へ統一。設定欄内で出入りする進捗バーや更新中の説明を廃止し、長いエラー、メッシュ数、プレビュー見出し、スクロールバーの変化でもパラメータ欄を押し下げないようにした。

- Noise Maskノードを追加。UV付きMeshの3D座標からムラを作り、Apply MaterialやMask Combineへ渡せる。基本設定はムラの大きさ・コントラスト・Seed。細部・歪み・解像度・反転は詳細設定へまとめ、選択中は白黒プレビューを表示する。

- Piece Selectのプリセットボタンを削除し、選別方法の切り替えをプルダウンに統一。選択肢を「外周から順に欠く」など動作が伝わる日本語に整理した。

- Piece Select / Peelに上下の重なり面積による支持を追加。中間層が両面を覆われている間は残し、全層で1片ずつ欠けるようにした。進行・ばらつき・別の欠け方を基本操作とし、Seedや対象層を詳細設定へ整理。旧Peelの層別減衰を廃止したため、既存シーンのPeel結果は変わる。
