# Changelog

作成日時: 2026-09-20 20:05
更新日時: 2026-09-22 17:57

## 未リリース

- Voronoi Fractureの「表示」に「ワイヤーフレーム」「ポイント」を追加。選んでいる間、オンにすると岩の面を隠し、分割片の稜線と母点だけを表示する。
- Piece Filterの「表示」に「除外した片」を追加。オンにすると、除外した分割片をワイヤーフレームで重ねる。残った片はそのまま面で表示する。

- Plane Cutsを選んでいる間、切り口を囲む平面の枠をビューポートに深度付きの線で表示するようにした。平面ごとに色を変え、枠は実際の切り口の大きさに合わせる。切り口の残らない平面は出さない。設定欄の「表示」でオン/オフできる（ノードの設定には保存しない）。
- Plane Cutsの「表示」に「断面を色分け」を追加。表示中のメッシュのうち各平面の切り口に乗る面を、枠と同じ色の半透明で塗る。

- Apply Materialに「ハイトで合成」を追加。マスクを基準に、その素材のハイトが下地より高い所を前に出す。なだらかさを調整できる。

- Shape Maskを選択中に「反転」を切り替えても、貼ったマスクの表示が更新されない問題を修正。

- Shape Maskに「カーブ（ガンマ）」を追加。下限/上限で伸ばした後の中間の階調を寄せられる。

- ビューポートの統計表示で、三角形数が影の描画ぶん（最大5倍）を含んで表示されていたのを、「描画三角形（影を含む）」と「メッシュ三角形」に分けた。

- SubdivideにMask入力を追加。白い面だけを割り、隣の面は共有辺に合わせて2〜4分割して閉じたまま保つ。Shape Mask（反転したオクルージョンで見える場所だけ、上向き度で上面だけなど）や画像マスクを使える。しきい値を設定できる。

- To Volumeの解像度の上限を96から128へ引き上げた。ボリューム系ノードの内部格子の上限は各軸192点から256点へ。

- Shape Maskの向きを面の法線から補間した頂点法線へ変更。上向き度やオクルージョンが三角形の辺で段にならず、面をまたいでなめらかにつながる。

- 参照している .rockmat が無いシーンを開けるようにした。無いマテリアルは外し、割り当ては「なし」になる（旧版が自動保存した Baked 材質を消した後のシーンなど）。

- アセット欄で Del キーで選んだファイルを削除（退避）できるようにした。複数選んだときは1件ずつ確認する（キャンセルで残りも止まる）。
- アセット欄が、表示中のフォルダの変更（エクスプローラでの削除など）を1秒ごとに確かめて一覧を作り直すようにした。消したファイルが幽霊のように残らない。
- シーンを開いたとき、ファイルが無く、どこからも使われていないテクスチャを自動で外すようにした。使われているリンク切れは残し、テクスチャ欄の右クリックメニュー「リンク切れをすべて削除」でまとめて消せる。

- Decimateで展開済みUVを保持するよう修正。UVの島の境界を保護して内部を補間し、マスクで塗り分けた素材を削減後も表示できるようにした。

- ライティングにスクリーンスペースAOのチェックボックス、半径、強さを追加。GPUで深度から表示用の陰影を計算し、設定をシーンに保存する。既定はオフ。

- Shape Maskを追加。UV付きのメッシュから、形状に応じた材質マスクを作ってApply MaterialのMaskへつなぐ。種類はオクルージョン（溝・割れ目・入隅）/ 上向き度 / 高さ。マスク解像度、下限/上限、反転を調整でき、Material BakeとDisplaceでも同じマスクが使われる。ノードを選ぶと、マスクを白黒で貼った状態でプレビューする。サンプルは `examples/shape-mask/`。

- Displaceとその下流のDecimateのキャッシュを修正。上流が同じ場合は計算結果を再利用し、下流の編集で素材ハイトのGPU生成・読戻しを繰り返さない。画像の再読込、ハイト・投影・マスク・形状の変更時は更新する。

- SubdivideとDisplaceを追加。Apply Materialの合成ハイトとマスクで実メッシュに凹凸を付ける。UV/Triplanar、共有頂点、面数予測と100万面上限、保存/Undoに対応。サンプルは `examples/displace/`。

- Scatter Pointsをプレビューしたとき、点を小さな立体ではなく画面上の2Dの点で表示するようにした。形の内側にある点も隠れずに見え、ズームしても大きさが変わらない。
- ベイクしたNormalも、UVの島が無い部分を最も近い島の縁の向きで全面埋めるようにした（ほかの3枚と同じエッジパディング）。
- ベイクしたBase Color / Roughness・Metallic・AO / Heightの、UVの島が無い部分を、最も近い島の縁の色で全面埋めるようにした（エッジパディング）。以前は余白の幅の外が透明で、黒く見えていた。
- Material Bakeの結果を、プロジェクトの `Bakes/` へ自動で保存しないようにした。結果は一時的なもので、シーンにも保存しない。残すには設定欄の「テクスチャを出力…」でフォルダを選んで書き出す。シーンを開き直したら再ベイクする。旧版が保存したベイク結果は従来どおり読める。
- ベイクしたNormalの、UVの島が無い部分を既定の法線色（128, 128, 255）の不透明で埋めるようにした（以前は透明で、黒く見えていた）。
- Material Bakeの設定欄に、ベイク結果をBase Color / Normal / Roughness / Metallic / AO / Heightの6枚のタイルで表示。1枚に詰めて焼いているRoughness・Metallic・AOはチャンネルごとに分けて出す。クリックでテクスチャプレビューを開く。
- Decimateを追加。形を保ったままメッシュの三角形を減らす（QEMによる辺の縮約）。UV Unwrapの前に置くと展開が大幅に速くなる（6.4万三角形を1万へ減らして、展開が17.0秒から1.2秒）。閉じた形・連結成分を保ち、針のような三角形を作らない。
- 評価中のノードを分かりやすく表示。ステータスバーに「更新中（UV Unwrap: 島へ分割中・12秒）」のようにノード名・段階・経過時間を出し、グラフのノードに「計算中」、UV Unwrapの設定欄に進捗バーを出す。
- UV Unwrapだけを含むグラフでも評価を別スレッドで行い、展開中にアプリが固まらないようにした。展開の途中でのキャンセルにも対応。
- Volume Noiseを追加。ボリュームの表面をノイズ（なめらか / セル状 / 小面）で削り、歪みでサンプル位置をずらして平面や直線的な割れ目を崩す。浮いた小片と閉じた空洞は自動で除く。サンプルは `examples/volume-noise/`。
- Volume Crackを追加。Scatter Pointsの点が作るVoronoiの境界面に沿って、ボリュームの表面から割れ目を彫る。断面はV字で、割れ目ごとの幅のばらつきと、割れ目に沿ったゆらぎを付けられる。深さ1で形を分ける。サンプルは `examples/volume-crack/`。
- Plane Cutsを追加。平面の群でボリュームを切り落とし、角張った面を作る。「全体」は少ない枚数の大きな面取り、「局所」は稜線と角を平面の小面で欠く。法線は等方か、節理のような主方向（1〜3系統）を選べる。浮いた小片は自動で除く。サンプルは `examples/plane-cuts/`。
- Volume Booleanを追加。2つのボリュームの和・交差・差を取り、なめらかさでつなぎ目を丸められる。結果はAの格子を引き継ぐ。サンプルは `examples/volume-boolean/`。
- 形状の評価中に出る「更新中…前回の結果を表示しています」を、ビューポート上からステータスバーへ移動。
- ボリューム系の評価を高速化。To Volume（一般メッシュ）・Random Boxesのボリューム化・Volume Transform・Voronoi Fractureを並列化し、BVHの探索とメッシュ検証を軽くした。出力は従来とビット単位で同じ。解像度96のTo Volumeは約30倍、512点のVoronoiは約15倍速い。
- Apply Materialより下流のTo Volumeが、変更がなくても毎回作り直される問題を修正。
- 原点から遠い入力で、Scatter Pointsの出した点がVoronoi Fractureに「入力の外」と拒否されることがある問題を修正。
- テクスチャ削除時に不透明度スロットの参照が残る問題と、使用箇所の一覧・件数に不透明度とMaterial Maskが含まれない問題を修正。
- ベイク状態の表示で、エラー文に「%」が含まれると不正な表示やクラッシュを起こし得る問題を修正。
- 評価中にアプリを閉じるとプロセスがしばらく残る問題、評価スレッドの例外でアプリが終了する問題、ノードの選択を変えただけで実行中の重い評価をやり直す問題を修正。
- 別のシーンを開いた後に、前のシーンでコピーしたノードを貼り付けると無関係なピンへつながり得る問題を修正。
- UVの面積が0になる面があると岩全体が表示されなくなる問題を修正。
- 設定ファイルを一時ファイル経由で保存し、書き込み途中の異常終了で設定が失われないようにした。
- DebugのD3D12検証で出ていたStructuredBuffer初期状態の警告を解消。
- ビルドに `/MP` を追加し、コンパイルを並列化。

- 形状AOのレイ判定をGPUへ移行。ベイク進捗率とキャンセルを追加し、計算中の入力変更では古い結果を破棄する。BVH準備はCPUで実行。

- Apply MaterialとMaterial Maskを追加。マスクによる素材の積み重ねをプレビュー・UVベイクに対応させ、Material Bakeへ形状AOの生成と素材AOへの乗算を追加。サンプルは `examples/material-layers/`。

- Dual Contouringで曖昧な共有面の輪郭が1辺にまとめられ、閉じた表面を抽出できなくなる問題を修正。Voronoi内部ピースをボリューム化したケースの解像度64/96で確認。

- Scatter Pointsの最大点数を128から512へ拡張。Voronoi Fractureも同じ上限に対応。

- Random BoxesをMesh出力、To VolumeをMesh入力へ統一。Base ShapeやPieces to Meshから閉じたメッシュをボリューム化できる。直方体の高速経路を維持し、一般メッシュのBVH距離計算、凹形状・穴・空洞・重複・分離ピース、非同期評価と上流キャッシュ無効化に対応。旧シーンの接続は維持する。

- Scatter Points / Voronoi Fracture / Piece Select / Piece Filter / Piece Transform / Pieces to Meshを追加。凸形状を方向付きVoronoiで分割し、色分け、外面・範囲・体積・ランダム・手動による選別、削除/抽出、個別配置、UV/ベイクへ接続できる。重い分割は非同期評価とキャッシュを使用。選択IDの保存・Undoと、上流変更時の無効化に対応。サンプルは `examples/voronoi-pieces/`。

- 基本形状ノードの表示名をBase RockからBase Shapeへ変更。既存シーンの保存識別子と設定は維持する。

- Joint Set / Crack / Fracture ノードを削除。部分切断・平面分割・Chunk の選択と移動、亀裂/Bridge のガイド表示もあわせて取り除いた。旧シーンに含まれるこれらのノードは読み込み時に捨てられる。

- UV Unwrapのテクスチャ解像度を128〜4096の2のべき乗から選ぶ方式へ変更。旧シーンの任意値は読み込み時に切り上げる。

- UVチェッカーを16×16マスのPNGへ変更。Houdiniの参考画像に合わせ、明るいマスに行名A〜P、暗いマスに列番号1〜16を表示する。UV確認中も天球・照明・影・露出・被写界深度を通常どおり適用し、背景が白くなる描画の例外を削除した。

- UV UnwrapとMaterial Bakeを追加。生成メッシュを自動展開し、選択時にUVチェッカーを表示する。「UVビュー」タブでUV島のワイヤーフレームを確認できる。ベイク実行で色・法線・Roughness/Metallic/AO・HeightをPNGへ保存して適用し、上流変更時は再ベイクを案内する。サンプルは `examples/uv-bake/`。

- Mesh OutputにMaterial入力を追加し、Surfaceの材質を生成メッシュへ適用できるようにした。SurfaceにUV／Triplanarの方式、反復サイズ・位置・回転・混合の鋭さを追加。シーン保存・Undo/Redoに対応。TriplanarはUVのないSDFメッシュへ色・法線・ラフネス・Metallic・AOを投影する。検証用サンプルを `examples/triplanar/` に追加。

- 「プレビュー設定」に「SDFプレビュー（共通）」を追加。To Volume / Volume Transform などの Volume 直接表示に使う変換方式を選べる。設定はアプリに保存し、切り替え時は内部SDFを再利用する。Volume to Mesh の出力は引き続きノード側の方式に従う。

- Volume to Mesh に「変換方式」を追加。従来の Marching Tetrahedra と Dual Contouring を選択できる。方式の保存・読込・Undo/Redo・キャッシュ更新に対応し、旧シーンは従来方式を維持する。比較用シーンを `examples/volume-meshing/` に追加。

- ビューポートの「表示」メニューに**スムーズシェーディング（折れ角 40 度）**を追加。岩メッシュの法線を、向きが40度以内で揃う隣の面だけ面積で重み付けして平均する。既定はオフ（従来どおり面法線）。
- ワイヤーフレーム表示（分割前 / 分割後）を削除。道路エディタ由来の機能で、テセレーションを使わない岩メッシュでは分割前後の区別に意味がないため、設定・レンダラの分岐・`PsWireframe` シェーダまで含めて取り除いた。

- Volume Transform の回転で外接箱が広がり、格子の旧上限を超えて表示が消える問題を修正。内部格子の上限を各軸102点から192点へ拡張し、To Volume の最大解像度96を維持したまま単一の任意方向回転を扱う。生成できない場合の理由もビューポート内に表示する。

- Volume Transform 操作時に、変更していない上流の直方体・SDFを再利用するよう最適化。ボリューム系の設定・接続変更に応じてキャッシュを破棄し、Undo/Redoにも追従する。メッシュ検証の辺照合も軽量化し、解像度や形状の検証条件は維持する。

- Volume Transform をビューポートのギズモで操作できるようにした。Model / Transform と同じ W 移動 / E 回転 / R 倍率、Ctrl の刻み、Esc の取り消しに対応する。
- Volume Transform ノードを追加。Volume を受けて、倍率 → 回転 → 平行移動の順に動かした Volume を返す。格子を作り直して再サンプルし、セル間隔は倍率に比例させる。設定の保存/読込と Undo/Redo に対応。
- グラフの右クリックメニューを扱う型ごとに整理し、「メッシュ（ポリゴン）」「ボリューム」「モデル」「共通」「材質」の見出しで分けた。

- Volume to Mesh ノードを追加。To Volume のグリッドから表面を通常の Mesh 型へ変換し、Mesh Output や Merge に渡せる。既存の Volume 直接プレビューも維持する。

- Random Boxes ノードを追加。個数・基準寸法・サイズばらつき・配置・回転・Seed を指定し、重なった直方体の塊を生成する。
- To Volume ノードを追加。直方体集合を内外の符号を持つ3次元グリッドへ変換し、和集合の外皮を表示する。解像度16～96、設定保存/読込・Undo/Redo に対応。
- Boxes / Volume ピンを追加し、Mesh Output で変換前後を表示。試せるサンプルを `examples/random-boxes/` に追加。

- 曲面の部分溝を有限長へ拡張。U 半幅で両端/片端が岩の途中で止まる切り込みを作り、長さ方向の終端壁を生成する。断面の三角形化と共有辺の接続を改善した。

- Crack の「Mesh 有限溝」で、曲面や斜め方向に、奥で止まる実形状の溝を作れるようにした。U 半幅で長さを指定し、+V 側の外面を覆う単一パッチ、4096三角形以下に限定する。
- 閉じた1連結体、両側の亀裂壁・終端、除去体積と残存体積の整合を確認し、未破断部を残す。設定の保存/読込と Undo/Redo に対応。
- 既存の Box 専用方式と旧シーンを維持。Mesh 有限溝の Bridge 断面計測/表示、交差する複数亀裂は後続。

- Fracture の「Joint Set で分割」で、上流の複数節理を無限平面として使う多片の完全分割に対応。有限範囲・深さとは区別し、初期設定は従来の単一平面モードを維持する。
- 多片の色分け・選択・Locked・移動/回転・保存/Undo に対応。半空間キーで変換を保持し、平面集合の変更で別キーの片へ設定を移さない。最終片どうしの共有断面と面積を生成する。
- 32平面・128片・合計20万三角形を上限とし、極小片・複数断面ループ・不正な閉包は診断する。曲面/交差パッチの部分亀裂は引き続き未対応。

- Joint Set ノードを追加。方向・間隔・本数・位置/角度ばらつき・Seed と有限範囲を設定し、パッチ列をガイド表示する。複数系統の直列接続・合流、保存/読込、Undo/Redo に対応。実分割は Fracture で明示的に有効にする。

- Base Rock に RoundedBox / Sphere / Ellipsoid を追加。丸み・面分割数・弱い形状ノイズの強度/細かさを編集でき、Seed で凹凸を再現する。
- 曲面とノイズ付き母岩を Fracture の入力へ接続できる。形状とノイズ設定は保存/読込・Undo/Redo に対応。旧シーンはノイズなしの Box として維持する。
- 部分切断は引き続きノイズなしの Box 専用。Joint Set からの有限範囲の部分切断は後続。

- Fracture ノードを追加。Box または部分切断済みの岩を平面で2つの閉じた Chunk に分ける。斜めの平面と凹んだ単純断面に対応し、穴・複数ループ・極小片・面の重なりは診断する。
- Chunk を色分けし、クリック/設定欄で選択、移動・回転のギズモと数値編集、Locked による配置固定に対応。Chunk ID・親・分割面の関係を生成し、設定は保存/読込・Undo/Redo で復元する。
- 参考写真 DSC02801.JPG に対する外観目標と、細かな分岐亀裂・剥離などの不足を資料に記録。

- Crack の「部分切断 (Box)」で、軸に沿った単一の有限切り込みを実際のメッシュに生成できるようにした。亀裂壁・終端を閉じ、奥の Rock Bridge を残す。未破断断面の緑色表示と厚さ・面積の確認に対応。
- 加工前の Box と加工後の枝を分離して評価する。切断・Bridge 表示の設定は保存/読込と Undo/Redo に対応。旧シーンはガイド表示を維持する。
- 部分切断は未加工 Box 1個・90度単位の向き・切り込み1回に限定。任意角度、内部空洞、Bridge の消失、複数切断は診断する。

- Crack ノードを追加。位置・回転・有限範囲・Depth・Persistence・Aperture を編集し、候補面と到達範囲を半透明で透視表示できる。設定の保存/読み込み、Undo/Redo、表示切り替えに対応。ガイドのみのモードでは母岩の形状を変更しない。
