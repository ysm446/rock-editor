# Changelog

作成日時: 2026-09-20 20:05
更新日時: 2026-09-26 19:51

## 未リリース

- マテリアルプレビューでL＋左ドラッグすると、光源の方位角・仰角を変えられるようにした。動かしている間はビューポートと同じライトのギズモを重ねる。変わるのはプレビューの光源の向きだけで、シーンの太陽やビューポートには影響しない（強さと色はシーンに合わせる）。「光源を戻す」でシーンの太陽の向きへ戻す。

- Shape Maskに「曲率（谷）」「曲率（山）」を追加。符号で凹凸を分け、平面は両方で黒。曲率スケールと既存の下限・上限・ガンマで調整する。

- マテリアルプレビューに「形（球／平面）」「大きさ (m)」「変位 (m)」を追加。変位を付けると素材のハイト（レイヤーマテリアルは合成後のハイト）で形を凸凹させ、輪郭と太陽の影で高さが読める。普通のPBRマテリアルとレイヤーマテリアルの両方で使える。プレビューだけの表示設定で、マテリアルには保存せず、ノードの計算やビューポートの形にも影響しない。

- Deposition Maskノードを追加。UV付きMeshの受け面・近傍の遮蔽・上方の開口から土の堆積候補を生成。基本UIは堆積量・隙間の範囲・許容傾斜とし、Apply Material、Mask Combine、白黒プレビュー、保存、Undo / Redoに対応。

- レイヤーマテリアルの層一覧をterrain-graphと同じ形に変更。各行に目のアイコン・素材のサムネイル・合成後にその層が見えている範囲の白黒画像・名前を並べ、上の行を上の層にした。並べ替えは行のドラッグ（上へ／下へボタンは廃止）、マテリアル一覧から行へ素材をドロップして割り当てられる。「合成（通常／高さ）」と「境界の幅」を詳細から出し、新しく追加する層は高さで合成する。

- terrain-graphのレイヤーマテリアルを岩用に移植。最大4層のPBR素材／単色を、均一またはムラの被覆で重ねて`.tglayer`へ保存できる。層一覧から選んで編集し、球・サムネイル・Surface・Apply Material・ベイク・Displaceへ反映。道路専用のマスクや座標設定は含めない。

- Layered Boxesを含む全ノードの処理状況を、設定スクロール領域の外にある固定1行へ統一。設定欄内で出入りする進捗バーや更新中の説明を廃止し、長いエラー、メッシュ数、プレビュー見出し、スクロールバーの変化でもパラメータ欄を押し下げないようにした。

- Noise Maskノードを追加。UV付きMeshの3D座標からムラを作り、Apply MaterialやMask Combineへ渡せる。基本設定はムラの大きさ・コントラスト・Seed。細部・歪み・解像度・反転は詳細設定へまとめ、選択中は白黒プレビューを表示する。

- Piece Selectのプリセットボタンを削除し、選別方法の切り替えをプルダウンに統一。選択肢を「外周から順に欠く」など動作が伝わる日本語に整理した。

- Piece Select / Peelに上下の重なり面積による支持を追加。中間層が両面を覆われている間は残し、全層で1片ずつ欠けるようにした。進行・ばらつき・別の欠け方を基本操作とし、Seedや対象層を詳細設定へ整理。旧Peelの層別減衰を廃止したため、既存シーンのPeel結果は変わる。

- Voronoi分割の点数の上限を512から1024へ引き上げ、単体の岩をより細かく割れるようにした。各片を近い点から切って遠い点で打ち切るようにし、約1.2万三角形の凸形状で512点の分割が0.44秒から0.21秒、1024点でも0.29秒になった。分割結果は従来と同じ。Piecesの再分割は保存済みのピースIDを保つため1枚あたり512点のまま（合計は1024点まで）。Piece Selectの集計も片数の2乗にならないようにした。

- Piece Selectの設定欄を「選び方 → 条件 → 結果 → 表示 → 出力」の順に整理。選別方法とプリセットを先頭にまとめ、Peelの「欠けの進行」は幅いっぱいのスライダーをやめて他の設定と同じ行の形にした（既定値の丸で0%へ戻せるので「最初に戻す」は廃止）。反転・外面の指定もプロパティの行に入れ、集計はラベル付きの値で表示する。層ごとの棒グラフも1層1行の表にし、棒はスライダーと同じ長さまでに抑えて選択数を右に並べた。

- Piece Selectのスライダー操作中に設定欄が上下する問題を修正。更新状況とエラーを固定の1行にし、更新中も集計と層一覧を保持する。全片がワイヤーフレームになった場合も見出しを維持し、スクロールバーによる幅の変化を防いだ。

- Piece Select / Peelの最上部に「欠けの進行」スライダー（0〜100%）を配置。ばらつき・Seedを近くにまとめ、「最初に戻す」「別の欠け方を試す」を追加した。同じSeedのまま進行を前後させて欠けを調整できる。

- Piece SelectにPeel（外周から侵食）を追加。Voronoi分割の隣接関係と共有面積を使い、露出した部分から支持の弱い片を順に選ぶ。削除量、Seed、ばらつき、中心保護、外側の層指定に対応。削除した隣から次の候補へ進み、Piece Filter後も継続できる。サンプルは `examples/layered-pieces/progressive-peel.rockscene`。

- Piece Selectの選択片を、面の塗りつぶしからオレンジのワイヤーフレームへ変更。残る形と欠ける部分を同時に見やすくした。手動編集中はクリックで解除できるよう面も表示する。

- Piece Select を選ぶと選択結果を自動表示し、選択片・未選択の候補・対象外を色分けするようにした。境界線、層別の選択数、削除後の比較、表示上だけ板を離す操作を追加。Rim で上側・下側・両側から対象層数を指定し、内側ほど欠けを弱くできる。サンプルは `examples/layered-pieces/outer-layer-chipping.rockscene`。

- Layered Boxes を追加し、薄板を並べた Pieces から岩を作れるようにした。Scatter Points / Voronoi Fracture の複数ピース入力、面内の点配置、Piece Select の側縁（Rim）・層指定に対応。板ごとの輪郭を欠いて、ボリューム化せずに出力できる。サンプルは `examples/layered-pieces/`。

- Parallel Planesを追加。向き・間隔(m)・位置・間隔のばらつき・Seedで平行な構造面を定義し、選択時に面の枠を表示する。Volume CrackにPlanes入力を追加し、Voronoi以外の板状・複数方向の割れ方を作れるようにした。既存のPoints入力と保存データは維持する。サンプルは `examples/parallel-planes/`。

- ノードのピンの丸をノードの縁に置き、リンクが丸に刺さって見えるようにした。これまではピンがノードの内側にあり、リンクがノードの下へ潜ってから届くので、どのピンに繋がっているか分かりにくかった。リンクの端も丸の中心に揃えた（terrain-graph と同じ修正）。

- マテリアルとMaterial Maskのテクスチャのプルダウンに、ルートフォルダにある未読み込みの画像も「未読み込み」として出すようにした。アセットの帯で一度開かなくても、プルダウンから選べばその場で割り当てて読み込む。ホバーでルートからの相対パスを表示する。アセットの帯から未読み込みの画像をテクスチャの欄へドラッグ＆ドロップしても、同じように読み込んで割り当てる。

- ビューポートの「表示」メニューで、スムーズシェーディングの折れ角（度）をスライダーで変えられるようにした（0〜180）。既定を 40 度から 60 度へ変更した。隣の面との角度がこれ以上の辺は折れ目を残す。設定は保存し、変えるとメッシュの法線を作り直す。

- Volume Edge Wearノードを追加。ボリュームの凸な稜線と角だけを削り、平らな面と凹な隅は動かさない（角の摩耗）。半径（稜線を見つける範囲）・量（削る深さ）・ばらつき（稜線に沿った削れ方の変化。欠けた角になる）・上向きに集中を設定できる。Volume Smoothと違い面がなまらないので、Plane Cutsの切り口を保ったまま角だけを摩耗させられる。サンプルは `examples/volume-edge-wear/`。

- ビューポートの「表示」メニューに「ワイヤーフレームを重ねる」を追加。陰影の上に三角形の辺を黒い線で重ねて表示する。表示モードは変えず、テセレーションや変位を反映した実際の三角形の形が見える。設定は保存する。

- 三角形数の上限を100万面から400万面へ引き上げた（Subdivide / Displace の出力合計、Remesh の出力、Decimate の入力）。Remeshの辺の長さの下限を0.002から0.001へ下げた。

- Remeshノードを追加。Meshの三角形を一様な大きさの正三角形に近い形へ作り直す（等方リメッシュ）。辺の長さ・繰り返し・特徴辺の角度を設定でき、稜線は保つ。Volume to Meshの不揃いな三角形を揃え、Subdivideなしで均一なDisplaceができる。UV付きの入力はUVの島の境界を固定して内部を補間して引き継ぐので、UV Unwrapの後に置ける（展開を重くせずにDisplaceのための密度を稼げる）。サンプルは `examples/remesh/`。

- Volume Closeノードを追加。外から見えない隙間（割れ目の奥、狭い入口の奥、細い切れ込み）を埋め、見えない奥の壁にメッシュが作られないようにする。モードは「遮蔽」（表面近くの点から全方向へレイを飛ばし、形に当たった割合がしきい値以上の点を埋める。浅いくぼみは残る。既定）と「幅」（幅より狭い隙間を埋めるクロージング）。外形と元から内部だった所は変わらない。サンプルは `examples/volume-close/`。

- Volume Smoothノードを追加。ボリュームの表面をガウスぼかしでなまらせる（なめらか）か、ぼかしとの差を足して角を立てる（シャープ）。「上向きに集中」で上を向いた面だけに効かせ、上面は丸く側面の割れ口は鋭いまま、という差を作れる。
- Volume Terraceノードを追加。ある方向に層をなす段（棚）を刻む。段の間隔・深さ・へこむ割合・なだらかさ・層ごとのばらつき・境のゆらぎ・向きを設定できる。削る方向にだけ効き、形は広がらない。サンプルは `examples/volume-smooth-terrace/`。

- Mask Combineノードを追加。2つのマスク（Shape Mask / Mask Combine）を画素ごとに合成する。演算は乗算 / 最大 / 最小 / 差 / 混合。合成した値に下限 / 上限 / カーブ（ガンマ）/ 反転を掛けられる。「溝のうち上面を除く」のように種類を組み合わせた条件をApply MaterialやSubdivideのMaskへ渡せる。選択中は合成したマスクを白黒で貼って表示する。サンプルは `examples/mask-combine/`。

- Voronoi Fractureの「表示」に「ワイヤーフレーム」「ポイント」を追加。選んでいる間、オンにすると岩の面を隠し、分割片の稜線と母点だけを表示する。
- Piece Filterの「表示」に「除外した片」を追加。オンにすると、除外した分割片をワイヤーフレームで重ねる。残った片はそのまま面で表示する。

- Plane Cutsを選んでいる間、切り口を囲む平面の枠をビューポートに深度付きの線で表示するようにした。平面ごとに色を変え、枠は実際の切り口の大きさに合わせる。切り口の残らない平面は出さない。設定欄の「表示」でオン/オフできる（ノードの設定には保存しない）。
- Plane Cutsの「表示」に「断面を色分け」を追加。表示中のメッシュのうち各平面の切り口に乗る面を、枠と同じ色の半透明で塗る。

- Apply Materialに「ハイトで合成」を追加。マスクを基準に、その素材のハイトが下地より高い所を前に出す。なだらかさを調整できる。

- Shape Maskを選択中に「反転」を切り替えても、貼ったマスクの表示が更新されない問題を修正。

- Shape Maskに「カーブ（ガンマ）」を追加。下限/上限で伸ばした後の中間の階調を寄せられる。

- ビューポートの統計表示で、三角形数が影の描画ぶん（最大5倍）を含んで表示されていたのを、「描画三角形（影を含む）」と「メッシュ三角形」に分けた。

- SubdivideにMask入力を追加。白い面だけを割り、隣の面は共有辺に合わせて2〜4分割して閉じたまま保つ。Shape Mask（反転したオクルージョンで見える場所だけ、上向き度で上面だけなど）や画像マスクを使える。しきい値を設定できる。

- To Volumeの解像度の上限を96から128へ引き上げた。ボリューム系ノードの内部格子の上限は各軸192点から256点へ。

- Shape Maskの向きを面の法線から補間した頂点法線へ変更。上向き度やオクルージョンが三角形の辺で段にならず、面をまたいでなめらかにつながる。

- 参照している .rockmat が無いシーンを開けるようにした。無いマテリアルは外し、割り当ては「なし」になる（旧版が自動保存した Baked 材質を消した後のシーンなど）。

- アセット欄で Del キーで選んだファイルを削除（退避）できるようにした。複数選んだときは1件ずつ確認する（キャンセルで残りも止まる）。
- アセット欄が、表示中のフォルダの変更（エクスプローラでの削除など）を1秒ごとに確かめて一覧を作り直すようにした。消したファイルが幽霊のように残らない。
- シーンを開いたとき、ファイルが無く、どこからも使われていないテクスチャを自動で外すようにした。使われているリンク切れは残し、テクスチャ欄の右クリックメニュー「リンク切れをすべて削除」でまとめて消せる。

- Decimateで展開済みUVを保持するよう修正。UVの島の境界を保護して内部を補間し、マスクで塗り分けた素材を削減後も表示できるようにした。

- ライティングにスクリーンスペースAOのチェックボックス、半径、強さを追加。GPUで深度から表示用の陰影を計算し、設定をシーンに保存する。既定はオフ。

- Shape Maskを追加。UV付きのメッシュから、形状に応じた材質マスクを作ってApply MaterialのMaskへつなぐ。種類はオクルージョン（溝・割れ目・入隅）/ 上向き度 / 高さ。マスク解像度、下限/上限、反転を調整でき、Material BakeとDisplaceでも同じマスクが使われる。ノードを選ぶと、マスクを白黒で貼った状態でプレビューする。サンプルは `examples/shape-mask/`。

- Displaceとその下流のDecimateのキャッシュを修正。上流が同じ場合は計算結果を再利用し、下流の編集で素材ハイトのGPU生成・読戻しを繰り返さない。画像の再読込、ハイト・投影・マスク・形状の変更時は更新する。

- SubdivideとDisplaceを追加。Apply Materialの合成ハイトとマスクで実メッシュに凹凸を付ける。UV/Triplanar、共有頂点、面数予測と100万面上限、保存/Undoに対応。サンプルは `examples/displace/`。

- Scatter Pointsをプレビューしたとき、点を小さな立体ではなく画面上の2Dの点で表示するようにした。形の内側にある点も隠れずに見え、ズームしても大きさが変わらない。
- ベイクしたNormalも、UVの島が無い部分を最も近い島の縁の向きで全面埋めるようにした（ほかの3枚と同じエッジパディング）。
- ベイクしたBase Color / Roughness・Metallic・AO / Heightの、UVの島が無い部分を、最も近い島の縁の色で全面埋めるようにした（エッジパディング）。以前は余白の幅の外が透明で、黒く見えていた。
- Material Bakeの結果を、プロジェクトの `Bakes/` へ自動で保存しないようにした。結果は一時的なもので、シーンにも保存しない。残すには設定欄の「テクスチャを出力…」でフォルダを選んで書き出す。シーンを開き直したら再ベイクする。旧版が保存したベイク結果は従来どおり読める。
- ベイクしたNormalの、UVの島が無い部分を既定の法線色（128, 128, 255）の不透明で埋めるようにした（以前は透明で、黒く見えていた）。
- Material Bakeの設定欄に、ベイク結果をBase Color / Normal / Roughness / Metallic / AO / Heightの6枚のタイルで表示。1枚に詰めて焼いているRoughness・Metallic・AOはチャンネルごとに分けて出す。クリックでテクスチャプレビューを開く。
- Decimateを追加。形を保ったままメッシュの三角形を減らす（QEMによる辺の縮約）。UV Unwrapの前に置くと展開が大幅に速くなる（6.4万三角形を1万へ減らして、展開が17.0秒から1.2秒）。閉じた形・連結成分を保ち、針のような三角形を作らない。
- 評価中のノードを分かりやすく表示。ステータスバーに「更新中（UV Unwrap: 島へ分割中・12秒）」のようにノード名・段階・経過時間を出し、グラフのノードに「計算中」、UV Unwrapの設定欄に進捗バーを出す。
- UV Unwrapだけを含むグラフでも評価を別スレッドで行い、展開中にアプリが固まらないようにした。展開の途中でのキャンセルにも対応。
- Volume Noiseを追加。ボリュームの表面をノイズ（なめらか / セル状 / 小面）で削り、歪みでサンプル位置をずらして平面や直線的な割れ目を崩す。浮いた小片と閉じた空洞は自動で除く。サンプルは `examples/volume-noise/`。
- Volume Crackを追加。Scatter Pointsの点が作るVoronoiの境界面に沿って、ボリュームの表面から割れ目を彫る。断面はV字で、割れ目ごとの幅のばらつきと、割れ目に沿ったゆらぎを付けられる。深さ1で形を分ける。サンプルは `examples/volume-crack/`。
- Plane Cutsを追加。平面の群でボリュームを切り落とし、角張った面を作る。「全体」は少ない枚数の大きな面取り、「局所」は稜線と角を平面の小面で欠く。法線は等方か、節理のような主方向（1〜3系統）を選べる。浮いた小片は自動で除く。サンプルは `examples/plane-cuts/`。
- Volume Booleanを追加。2つのボリュームの和・交差・差を取り、なめらかさでつなぎ目を丸められる。結果はAの格子を引き継ぐ。サンプルは `examples/volume-boolean/`。
- 形状の評価中に出る「更新中…前回の結果を表示しています」を、ビューポート上からステータスバーへ移動。
- ボリューム系の評価を高速化。To Volume（一般メッシュ）・Random Boxesのボリューム化・Volume Transform・Voronoi Fractureを並列化し、BVHの探索とメッシュ検証を軽くした。出力は従来とビット単位で同じ。解像度96のTo Volumeは約30倍、512点のVoronoiは約15倍速い。
- Apply Materialより下流のTo Volumeが、変更がなくても毎回作り直される問題を修正。
- 原点から遠い入力で、Scatter Pointsの出した点がVoronoi Fractureに「入力の外」と拒否されることがある問題を修正。
- テクスチャ削除時に不透明度スロットの参照が残る問題と、使用箇所の一覧・件数に不透明度とMaterial Maskが含まれない問題を修正。
- ベイク状態の表示で、エラー文に「%」が含まれると不正な表示やクラッシュを起こし得る問題を修正。
- 評価中にアプリを閉じるとプロセスがしばらく残る問題、評価スレッドの例外でアプリが終了する問題、ノードの選択を変えただけで実行中の重い評価をやり直す問題を修正。
- 別のシーンを開いた後に、前のシーンでコピーしたノードを貼り付けると無関係なピンへつながり得る問題を修正。
- UVの面積が0になる面があると岩全体が表示されなくなる問題を修正。
