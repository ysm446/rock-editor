### 2026-09-21 Volume Transform とメニューの型別整理

- Volume 入力を、倍率 → 回転 → 平行移動の順に原点まわりで動かして Volume を返す `Volume Transform` を追加。回転は右手系 Z → X → Y で Crack / Model と同じ規約。
- 格子を作り直す実装。出力の各点を逆変換して入力をトリリニア補間で読み、倍率を掛け戻して距離の単位を保つ。格子の外は外周の正値へ外に出た距離を足し、符号を外部のまま保つ。
- セル間隔を倍率に比例させ、拡大・縮小でセル数を変えない。範囲は入力格子の8隅の AABB + 2セル。回転で各軸102を超える場合は上流の解像度を下げるよう診断する。0倍率・非有限値・空の格子・内部が残らない場合も診断する。
- グラフの右クリックメニューを型別に再編。「メッシュ（ポリゴン）」「ボリューム」「モデル」「共通」「材質」の見出しで分け、変換ノードは変換後の型の側に置く（Volume to Mesh はメッシュ側、Random Boxes はボリュームの素材としてボリューム側）。
- 保存名 `volumeTransform`、プロパティ UI、保存/読込、Undo/Redo に接続。サンプルは `examples/volume-transform/`。
- Debug / Release ビルドと CTest（1/1、21.14秒）、単体テスト全項目が成功。識別変換・移動・45度回転・倍率2/0.5・連続適用の体積と外接箱、再現性、上限と不正設定の診断、型の接続制約、評価とプレビューへの伝播、Undo/Redo を確認。
- Debug の実行ファイルで、移動のみ・回転のみ・縮小のみのシーンを描画し、形を保ったまま位置・向き・大きさだけが変わることを目視確認。保存→読込→再保存でグラフが一致。検証素材は `build/volume-transform-validation/`。
